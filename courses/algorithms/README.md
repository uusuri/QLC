# Курс «Алгоритмы и структуры данных»

[Программа курса](PROGRAM.md) · [Открытые источники](SOURCES.md) · [Отчёт проверки](reports/QA.md) · [Индекс кодовых задач](task-index.json)

24 модуля, 49 уроков (24 учебных, практика по асимптотике и 24 с доказательствами), 108 заданий и 324 подсказки.

## Состав

- `lessons/`: учебный текст, доказательства и проверяемые вопросы с объяснениями.
- `tasks/<slug>/statement.md`: условие и проверенный пример.
- `tasks/<slug>/solution.cpp`: эталон C++23.
- `tasks/<slug>/wrong.cpp`: намеренно ошибочный вариант для проверки силы тестов; не учебный эталон.
- `tasks/<slug>/slow.cpp`: медленное решение, если у задачи есть содержательный более медленный алгоритм.
- `tasks/<slug>/tests.json`: воспроизводимые приватные тесты (генерируются, исключены из Git из-за размера).
- `tasks/<slug>/editorial.md`, `hints.json`: разбор преподавателя и ступенчатые подсказки.
- `authoring/`: исходники материалов, независимые оракулы, генераторы, сборка, проверка и импорт.
- `reports/validation.json`: фактические результаты запусков в песочнице QLC, с контрольными суммами исходников и тестов.
- `bundle.json`: собранный приватный пакет для импорта, исключён из Git.

## Воспроизведение

Из корня репозитория:

```sh
python3 courses/algorithms/authoring/validate.py --prepare
python3 courses/algorithms/authoring/validate.py
python3 courses/algorithms/authoring/build.py
python3 courses/algorithms/authoring/audit.py
python3 courses/algorithms/authoring/import_course.py
```

Для реальной проверки требуется Docker и существующий образ `qlc-cpp-runner:dev`, собранный из `sandbox/`. Проверяются все эталоны и намеренно ошибочные решения, а медленные варианты сначала проходят небольшие примеры и затем испытываются на больших входах. Проверяющая система получает тесты через stdin; у решения нет доступа к приватному набору на диске контейнера. Лимиты и параметры контейнера повторяют `DockerCppRunner`.

После применения миграций до V10 включительно импорт выполняется командой:

```sh
python3 courses/algorithms/authoring/import_course.py --apply
```

Импорт добавляет только новый курс в локальную PostgreSQL, в одной транзакции, включая 10 доступных языков и 490 версий теории. Если курс с таким названием уже есть, операция прекращается; существующие курсы, их задачи и пользовательский прогресс не обновляются. Пароли используются только внутри штатного контейнера и не печатаются. Результат находится в `reports/import.json`.

Для ранее импортированной версии с 48 уроками и 96 заданиями есть отдельное обновление первого модуля:

```sh
python3 courses/algorithms/authoring/update_asymptotics.py --apply
```

Оно расширяет вводную теорию, добавляет урок с 12 тестами по асимптотике перед доказательствами и сохраняет все существующие ID задач и результаты учеников. Повторный запуск прекращается без изменений. Новый импорт уже включает этот урок; после него обновление выполнять не нужно.

## Проверка качества и границы гарантии

Малые случаи сверяются с независимыми определениями: перебором пар/подмножеств/перестановок, удалением рёбер и вершин, поиском путей, перебором разрезов. Генератор воспроизводим по фиксированным seed. Большие семейства проверяют асимптотику, переполнение, длинные цепи, повторяющиеся строки и крайние значения. Эталонный код не генерирует ожидаемые ответы.

Условия допускают любой корректный алгоритм в лимитах. Тесты не контролируют стиль, понимание или обязательное использование конкретной структуры и не доказывают отсутствие всех возможных ошибок. Время и память эталонов обоснованы в разборах; оценки рандомизированных структур явно названы ожидаемыми. Для потоков и экспоненциального ДП не заявляется недоказанная абсолютная оптимальность среди всех алгоритмов.

Разборы, исходники решений, правильные ответы и приватные тесты нельзя переносить в `frontend/public`. Ученик получает условия и подсказки через уже защищённый доступ к уроку; приватные поля остаются в административном API.


## Теория по выбранному языку

В `theory/<language>/` находятся полные версии всех 49 уроков для 10 языков.
Математика и доказательства общие; отличаются фрагменты кода, числовые типы,
стандартные контейнеры, работа со строками и стоимость операций. Источник этих
различий — `authoring/theory_languages.py`. Текст выбирается на сервере по
`user_courses.selected_language`, без подмены слов в браузере.

После изменения базовых уроков пересоберите и проверьте версии:

```sh
python3 courses/algorithms/authoring/theory_languages.py
python3 courses/algorithms/authoring/validate_theory.py
python3 courses/algorithms/authoring/import_theory.py --apply
```

Импорт требует миграции V10 и уже созданного мультиязычного курса. Он проверяет
структуру и точное совпадение базовых текстов, затем одной транзакцией обновляет
только языковые версии. Задачи, прогресс и выбранные пользователями языки не меняются.
Повторный запуск безопасен. Админка также позволяет редактировать версии вручную;
повторный импорт заменяет их материалами из файлов.

`reports/theory-validation.json` показывает фактически запущенные среды. Сейчас
семь фрагментов из вводных уроков проверены на C++, Java, Python, JavaScript,
TypeScript, C, Go и Rust: 995 проверок на язык, включая полный перебор коротких
массивов, счёт повторений циклов и рекурсивных вызовов. C# и PHP не запускались:
их сред нет на локальной машине. Условия, подсказки и C++-фрагменты в тестовых
заданиях пока общие; это обновление касается теории.
