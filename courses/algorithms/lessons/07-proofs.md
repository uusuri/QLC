# Почему это работает: Куча, множество и дерево поиска

Необязательный раздел. Он не содержит зачётных задач. Лучше читать после собственной попытки: здесь раскрываются идеи решений.

## 13. Слияние архивов

Дерево слияний имеет стоимость Σ(size[i]·depth[i]). Два наименьших веса можно обменами поместить в пару самых глубоких листьев без увеличения стоимости. Сжав эту пару, получаем меньшую задачу того же вида.

Оценка ресурсов: O(n log n) времени, O(n) памяти.

## 14. Ближайший свободный номер

Инвариант: дерево содержит ровно элементы, добавленные и не удалённые последующими операциями. lower_bound возвращает первую позицию, на которой предикат value<x перестаёт выполняться.

Оценка ресурсов: O(q log q) времени, O(q) памяти; сбалансированное дерево поиска.

## Проверьте границы утверждений

Куча не предоставляет быстрый поиск произвольного ключа. set не хранит повторы. У priority_queue проверьте направление сравнения.

Попробуйте изменить одну предпосылку и найти минимальный контрпример: знак чисел, строгость сравнения, направление ребра или допустимость пустого ответа. Сверьте полученный пример с формальным условием, а затем с независимым перебором.
