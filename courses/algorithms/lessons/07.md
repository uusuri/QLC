# Куча, множество и дерево поиска

## Что вы научитесь делать

Выбирать структуру по набору операций; различать минимум, точный поиск и поиск по порядку.

Предпосылки: Предыдущие модули, 01–06.

## Идея и алгоритм

Структура данных — обещание о поддерживаемых операциях и их стоимости. Массив удобен для доступа по индексу, но вставка в начало требует сдвига. Хеш-таблица подходит для поиска по точному ключу, но не знает ближайшего большего элемента. Сбалансированное дерево хранит порядок, куча — только отношение каждого родителя к детям.

В min-heap минимум лежит в корне. Вставка поднимает элемент, извлечение заменяет корень последним и просеивает его вниз. Высота двоичной кучи O(log n), поэтому изменения логарифмические; посмотреть минимум можно за O(1). Остальной массив кучи не отсортирован. В C++ priority_queue по умолчанию выдаёт максимум; для минимума укажите greater.

При объединении архивов нужно многократно получать два минимума, а затем вставлять их сумму. Сортировать весь список на каждом шаге дорого. Куча выражает нужный интерфейс напрямую. Сумма размеров возвращается в структуру, потому что новый архив участвует в следующих слияниях. Если архив один, операций нет и ответ 0.

Дерево поиска соблюдает порядок ключей: слева меньшие, справа большие. Наивное дерево может превратиться в цепочку и дать O(n) на поиск. std::set поддерживает сбалансированную реализацию: insert, erase и lower_bound логарифмичны. lower_bound(x) ищет первый ключ ≥x, upper_bound(x) — первый >x. Указатель end() означает отсутствие ответа, разыменовывать его нельзя.

Множество игнорирует повторную вставку, мультимножество хранит кратности. Удаление по ключу в multiset может удалить все копии; для удаления одной сначала найдите итератор. Хеш-таблица имеет ожидаемое постоянное время, но не гарантированное в худшем случае. В задачах с требованием порядка предпочитайте дерево, а не линейный просмотр unordered_set. Позже добавим дереву размеры поддеревьев и научимся искать k-й элемент.

## Разберём пример

Архивы 2,3,8: объединяем 2+3=5, затем 5+8=13, суммарная цена 18. Если начать с 3+8, получится 11+13=24. В множестве {2,7,11} lower_bound(7)=7, upper_bound(7)=11.

## Где ошибаются

Куча не предоставляет быстрый поиск произвольного ключа. set не хранит повторы. У priority_queue проверьте направление сравнения.

## Практика

- 13. Слияние архивов: За одну операцию можно объединить два архива размеров x и y, заплатив x+y; новый архив имеет размер x+y. Найдите минимальную суммарную стоимость объединения всех архивов в один.
- 14. Ближайший свободный номер: Поддерживайте множество целых чисел. Операции: `+ x` добавляет x; `- x` удаляет x, если он есть; `? x` запрашивает минимальный элемент не меньше x. Повторное добавление ничего не меняет. Для каждого запроса выведите число либо слово NONE.

Решайте задачи по порядку. Если застряли, сначала сформулируйте медленный корректный способ, затем откройте одну подсказку. После решения объясните оценку времени и памяти и придумайте контрпример к своей первой неверной идее. Доказательства вынесены в следующий необязательный урок; для перехода дальше читать их не требуется.
