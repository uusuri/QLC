# Почему это работает: Два указателя и монотонное окно

Необязательный раздел. Он не содержит зачётных задач. Лучше читать после собственной попытки: здесь раскрываются идеи решений.

## 09. Короткий запас

Для каждого правого конца цикл проверяет самые короткие допустимые окна. Уже удалённая левая граница для более позднего правого конца даст только более длинный участок, поэтому её возврат не нужен.

Оценка ресурсов: Θ(n) времени, O(n) памяти для массива.

## 10. Близкие показания

Каждая пара учитывается ровно в момент обработки большего по позиции элемента отсортированного массива. Монотонность значений позволяет удалять неподходящих партнёров навсегда.

Оценка ресурсов: O(n log n) времени с сортировкой, O(n) памяти.

## Проверьте границы утверждений

Не добавляйте сам элемент как пару с собой. Для количества пар нужен long long. Условие ≤K включает равенство; K=0 проверяет дубликаты.

Попробуйте изменить одну предпосылку и найти минимальный контрпример: знак чисел, строгость сравнения, направление ребра или допустимость пустого ответа. Сверьте полученный пример с формальным условием, а затем с независимым перебором.
