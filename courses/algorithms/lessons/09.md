# ДП: состояние и последний шаг

## Что вы научитесь делать

Задавать смысл состояния, порядок вычисления и переход; сжимать доминируемые состояния.

Предпосылки: Предыдущие модули, 01–08.

## Идея и алгоритм

Динамическое программирование сохраняет ответы на повторяющиеся подзадачи. Начинать нужно со смысла состояния, а не с массива dp. Запишите словами, что означает dp[i], какие решения оно допускает и какое значение соответствует невозможности. Затем опишите последний шаг оптимального решения.

Для монет dp[s] — минимальное число монет для точной суммы s. Последняя монета c оставляет сумму s−c, поэтому переход dp[s]=min(dp[s−c]+1). База dp[0]=0. Суммы обрабатываются по возрастанию, ведь номиналы положительны. INF должен быть достаточно большим, но не переполняться при +1. Номинал больше s в переход не участвует. Если dp[S] осталось INF, сумма недостижима.

Такое время O(nS) зависит от числового значения S, а не от длины его записи. Его называют псевдополиномиальным. При S=10^9 даже сто номиналов сделали бы эту динамику непрактичной. Ограничения подсказывают, является ли выбранное пространство состояний разумным.

Для возрастающей подпоследовательности простой вариант хранит dp[i] — лучшую длину с концом в i и перебирает j<i с a[j]<a[i]. Он работает за O(n²). Чтобы ускориться, заметим доминирование: среди подпоследовательностей одной длины меньший последний элемент никогда не хуже большего. Храним минимальный хвост каждой длины в отсортированном tails.

Для нового x первый хвост ≥x можно заменить на x, не изменив длину; если такого нет, длина увеличивается. Это lower_bound и O(n log n) времени. tails не обязательно является одной реальной подпоследовательностью: это набор лучших характеристик для разных длин. Для восстановления пути потребовались бы индексы предшественников, но задача курса просит только длину. Для неубывающей версии вместо строгой используется upper_bound — различие проверяется повторяющимися числами.

## Разберём пример

Монеты 1,3,4, сумма 6: жадность даёт 4+1+1, а оптимум 3+3. Для [3,1,2,2,5] состояния tails: [3], [1], [1,2], [1,2], [1,2,5]; строгая LIS имеет длину 3.

## Где ошибаются

Недостижимость — не нулевая стоимость. Значения tails могут относиться к разным подпоследовательностям. Равные элементы не удлиняют строгую LIS.

## Практика

- 17. Неразменный запас: Доступны монеты заданных положительных номиналов в неограниченном количестве. Найдите минимальное число монет для суммы S. Если сумму собрать нельзя, выведите −1.
- 18. Растущая подпоследовательность: Найдите длину наибольшей строго возрастающей подпоследовательности. Выбранные элементы должны сохранять исходный порядок, но не обязаны идти подряд.

Решайте задачи по порядку. Если застряли, сначала сформулируйте медленный корректный способ, затем откройте одну подсказку. После решения объясните оценку времени и памяти и придумайте контрпример к своей первой неверной идее. Доказательства вынесены в следующий необязательный урок; для перехода дальше читать их не требуется.
