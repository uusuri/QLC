# Разбор: 38. Монтаж последовательности

## Идея

Обычное дерево по значениям не сохраняет порядок элементов массива.

Используйте декартово дерево с неявным ключом — позицией, вычисляемой по размерам поддеревьев.

Разрежьте по r и l−1, выделив участок. Для R переключите ленивый флаг rev; для S прочитайте сумму. Перед спуском push, после изменения pull; затем склейте части.

## Корректность

Размер левого поддерева задаёт ранг корня. Два split выделяют ровно нужные позиции. Разворот меняет порядок, но сохраняет сумму и размер; ленивый флаг композиционно складывается по XOR.

## Время и память

Ожидаемое O((n+q) log n) времени, O(n) памяти. Линейное построение также возможно.

## Проверка качества

В tests.json находятся примеры, независимые проверки малых входов и большие специально подобранные семейства. wrong.cpp содержит намеренную ошибку; slow.cpp, если есть, — корректный на малых данных неэффективный вариант. Подробные фактические результаты находятся в reports.
