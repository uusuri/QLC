# 18. Растущая подпоследовательность

Найдите длину наибольшей строго возрастающей подпоследовательности. Выбранные элементы должны сохранять исходный порядок, но не обязаны идти подряд.

## Входные данные

n; затем n целых чисел.

## Ограничения

1 ≤ n ≤ 200000; −10^9 ≤ a[i] ≤ 10^9.

## Пример

Ввод:

```text
2
-5 -5
```

Вывод:

```text
1
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
