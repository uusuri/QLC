# 03. Архив измерений

Для каждого запроса l, r найдите сумму a[l] + … + a[r]. Массив не меняется. Печатайте ответ на каждый запрос в отдельной строке.

## Входные данные

n q; затем n чисел массива; затем q строк l r. Индексы начинаются с 1.

## Ограничения

1 ≤ n,q ≤ 200000; −10^9 ≤ a[i] ≤ 10^9; 1 ≤ l ≤ r ≤ n.

## Пример

Ввод:

```text
2 12
-5 -5
1 1
1 1
2 2
1 1
1 2
1 2
1 2
1 1
1 2
2 2
1 2
1 2
```

Вывод:

```text
-5
-5
-5
-5
-10
-10
-10
-5
-10
-5
-10
-10
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
