# 36. Массовая коррекция

Операция + l r x прибавляет x всем значениям на [l,r]. Операция ? l r запрашивает максимум на [l,r]. Все отрезки включают обе границы.

## Входные данные

n q; затем n исходных значений; затем q операций указанных форматов.

## Ограничения

1 ≤ n,q ≤ 200000; |a[i]|,|x| ≤ 10^9; 1 ≤ l ≤ r ≤ n; хотя бы один запрос ?.

## Пример

Ввод:

```text
2 15
-5 -5
+ 1 1 3
+ 1 2 0
? 1 1
+ 1 2 4
+ 1 2 -4
+ 2 2 -3
? 1 2
+ 1 2 5
? 1 2
+ 1 2 3
+ 1 2 -5
? 1 1
+ 1 1 0
+ 2 2 -1
? 1 1
```

Вывод:

```text
-2
-2
3
1
1
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
