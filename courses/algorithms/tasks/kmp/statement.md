# 29. Все совпадения

Найдите количество вхождений образца p в текст t. Перекрывающиеся вхождения учитываются. Строки непустые, содержат строчные латинские буквы.

## Входные данные

Первая строка — p, вторая — t.

## Ограничения

1 ≤ |p|,|t| ≤ 500000.

## Пример

Ввод:

```text
baacbc
abaabccaccccbabbaca
```

Вывод:

```text
0
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
