# 10. Близкие показания

Посчитайте пары различных индексов i<j, для которых |a[i]−a[j]|≤K. Одинаковые значения на разных позициях образуют разные пары.

## Входные данные

n K; затем n чисел.

## Ограничения

1 ≤ n ≤ 200000; 0 ≤ K ≤ 2000000000; −10^9 ≤ a[i] ≤ 10^9.

## Пример

Ввод:

```text
2 3
-5 -5
```

Вывод:

```text
1
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
