# 01. Контрольная сумма

Найдите сумму всех чисел в последовательности. Выведите одно целое число.

## Входные данные

Первая строка — n. Вторая — n целых чисел a[i].

## Ограничения

1 ≤ n ≤ 200000; −10^9 ≤ a[i] ≤ 10^9.

## Пример

Ввод:

```text
2
-5 -5
```

Вывод:

```text
-10
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
