# 12. Минимум в движении

Для каждого непрерывного окна длины k выведите минимальный элемент. Окна рассматриваются слева направо, каждый ответ с новой строки.

## Входные данные

n k; затем n чисел.

## Ограничения

1 ≤ k ≤ n ≤ 200000; −10^9 ≤ a[i] ≤ 10^9.

## Пример

Ввод:

```text
2 1
-5 -5
```

Вывод:

```text
-5
-5
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
