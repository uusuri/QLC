# 41. Хрупкие связи

Найдите количество мостов: рёбер, удаление одного из которых увеличивает число компонент связности неориентированного графа. Кратные рёбра считаются отдельными рёбрами.

## Входные данные

n m; затем m строк u v. Граф может быть несвязным, с петлями и кратными рёбрами.

## Ограничения

1 ≤ n ≤ 200000; 0 ≤ m ≤ 300000; вершины от 1 до n.

## Пример

Ввод:

```text
4 13
2 1
1 3
4 2
2 2
4 1
3 2
4 2
2 1
3 3
3 2
3 1
4 3
3 1
```

Вывод:

```text
0
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
