# Разбор: 16. Точный баланс

## Идея

Два указателя с отрицательными числами теряют монотонность.

Сумма участка равна разности двух префиксов. Для текущего p нужен предыдущий префикс p−K.

Храните частоты уже встреченных префиксов; начните с частоты 0, равной 1. Сначала добавьте freq[p−K] к ответу, затем увеличьте freq[p].

## Корректность

При обработке правого конца карта содержит каждый допустимый левый префикс с его кратностью. Обновление после подсчёта не допускает пустого участка.

## Время и память

O(n log n) гарантированного времени, O(n) памяти с map. Хеш-таблица даёт ожидаемое O(n), но без гарантии на худший случай.

## Проверка качества

В tests.json находятся примеры, независимые проверки малых входов и большие специально подобранные семейства. wrong.cpp содержит намеренную ошибку; slow.cpp, если есть, — корректный на малых данных неэффективный вариант. Подробные фактические результаты находятся в reports.
