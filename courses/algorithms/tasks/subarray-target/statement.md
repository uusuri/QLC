# 16. Точный баланс

Посчитайте непустые непрерывные участки массива с суммой ровно K. Числа могут быть отрицательными. Выведите количество участков.

## Входные данные

n K; затем n чисел.

## Ограничения

1 ≤ n ≤ 200000; −10^9 ≤ a[i] ≤ 10^9; |K| ≤ 10^14.

## Пример

Ввод:

```text
2 -1
-5 -5
```

Вывод:

```text
0
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
