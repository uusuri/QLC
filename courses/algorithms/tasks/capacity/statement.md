# 07. Доставка по дням

Грузы идут в заданном порядке. Разбейте последовательность на не более k непустых непрерывных групп. Минимизируйте максимальную сумму одной группы. Выведите этот минимум.

## Входные данные

n k; затем n положительных весов.

## Ограничения

1 ≤ k ≤ n ≤ 200000; 1 ≤ a[i] ≤ 10^9.

## Пример

Ввод:

```text
2 1
10 4
```

Вывод:

```text
14
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
