# Разбор: 07. Доставка по дням

## Идея

Проверьте более простой вопрос: хватит ли грузоподъёмности C?

Для фиксированного C заполняйте текущий день до тех пор, пока следующий груз помещается.

Проверка монотонна. Ищите первую допустимую C от max(a) до sum(a); суммы и границы — long long.

## Корректность

Жадная группа при заданной ёмкости заканчивается не раньше первой группы любого допустимого разбиения. Повторение аргумента минимизирует количество групп. Увеличение ёмкости не ухудшает допустимость.

## Время и память

O(n log(sum a)) времени, O(n) памяти.

## Проверка качества

В tests.json находятся примеры, независимые проверки малых входов и большие специально подобранные семейства. wrong.cpp содержит намеренную ошибку; slow.cpp, если есть, — корректный на малых данных неэффективный вариант. Подробные фактические результаты находятся в reports.
