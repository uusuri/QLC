# 43. Поиск по словарю

Для каждого образца посчитайте число его вхождений в общий текст. Перекрытия учитываются. Одинаковые образцы во входе требуют отдельных одинаковых ответов. Ответы в порядке образцов, по одному в строке.

## Входные данные

k; затем k непустых образцов; затем непустой текст. Все символы — a…z.

## Ограничения

1 ≤ k ≤ 200000; суммарная длина образцов ≤ 200000; длина текста ≤ 500000.

## Пример

Ввод:

```text
6
abb
cca
aabccc
cbba
caccbc
b
abaabccaccccbabbaca
```

Вывод:

```text
1
1
0
0
0
5
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
