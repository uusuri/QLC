# 48. Плитка для галереи

Посчитайте способы полностью покрыть прямоугольник n×m неперекрывающимися домино 1×2. Домино можно поворачивать; повороты и отражения всего покрытия считаются разными, если занятые пары клеток различаются. Выведите ответ по модулю 1000000007.

## Входные данные

Два числа n m.

## Ограничения

1 ≤ n ≤ 10; 1 ≤ m ≤ 1000.

## Пример

Ввод:

```text
2 5
```

Вывод:

```text
8
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
