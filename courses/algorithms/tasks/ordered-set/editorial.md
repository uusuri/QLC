# Разбор: 14. Ближайший свободный номер

## Идея

Запрос требует порядка, а не только проверки наличия.

В std::set поиск первого элемента ≥x выполняет lower_bound(x).

Проверьте результат на end(). Дубликаты не увеличивают множество, удаление отсутствующего элемента допустимо.

## Корректность

Инвариант: дерево содержит ровно элементы, добавленные и не удалённые последующими операциями. lower_bound возвращает первую позицию, на которой предикат value<x перестаёт выполняться.

## Время и память

O(q log q) времени, O(q) памяти; сбалансированное дерево поиска.

## Проверка качества

В tests.json находятся примеры, независимые проверки малых входов и большие специально подобранные семейства. wrong.cpp содержит намеренную ошибку; slow.cpp, если есть, — корректный на малых данных неэффективный вариант. Подробные фактические результаты находятся в reports.
