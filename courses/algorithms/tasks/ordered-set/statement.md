# 14. Ближайший свободный номер

Поддерживайте множество целых чисел. Операции: `+ x` добавляет x; `- x` удаляет x, если он есть; `? x` запрашивает минимальный элемент не меньше x. Повторное добавление ничего не меняет. Для каждого запроса выведите число либо слово NONE.

## Входные данные

q; далее q строк с символом операции и числом x. Множество изначально пусто.

## Ограничения

1 ≤ q ≤ 200000; −10^9 ≤ x ≤ 10^9; есть хотя бы один запрос ?.

## Пример

Ввод:

```text
30
? -1
? -3
? -7
+ 3
- -1
+ -4
? 5
? -7
? 1
? -2
? 6
? -3
+ -5
? 2
- 0
+ 2
+ 5
- 0
? -8
+ -3
? 4
? 7
? -3
- -5
? -4
- -4
+ -3
? -2
+ 3
? -7
```

Вывод:

```text
NONE
NONE
NONE
NONE
-4
3
3
NONE
3
3
-5
5
NONE
-3
-4
2
-3
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
