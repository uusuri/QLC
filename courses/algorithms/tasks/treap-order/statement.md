# 37. Рейтинг с повторами

Поддерживайте мультимножество. + x добавляет одно вхождение; - x удаляет одно вхождение, если оно есть; ? k возвращает k-й по возрастанию элемент с учётом повторений. Для недопустимого k выведите NONE.

## Входные данные

q; затем q операций. Изначально мультимножество пусто.

## Ограничения

1 ≤ q ≤ 200000; |x| ≤ 10^9; 1 ≤ k ≤ 200000; хотя бы один запрос ?.

## Пример

Ввод:

```text
30
? 1
? 1
- 7
+ -1
+ 5
? 3
? 4
? 2
+ 8
- 3
- -1
- -8
- 3
? 1
+ -3
? 4
? 4
? 5
+ 4
+ -3
+ -2
+ 3
+ -7
- -1
- 1
- -7
? 3
- -5
+ -7
? 4
```

Вывод:

```text
NONE
NONE
NONE
NONE
5
5
NONE
NONE
NONE
-2
-2
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
