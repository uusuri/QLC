# Разбор: 33. Живые измерения

## Идея

Префиксные суммы устаревают после каждого изменения.

Дерево Фенвика хранит суммы блоков, определяемых младшим установленным битом индекса.

При изменении двигайтесь i+=i&−i; при сумме префикса i−=i&−i. Ответ [l,r] — prefix(r)−prefix(l−1).

## Корректность

Каждая ячейка дерева содержит сумму блока длины lowbit(i). Префикс разбивается на непересекающиеся такие блоки; изменение посещает ровно блоки, содержащие позицию.

## Время и память

O((n+q) log n) времени, O(n) памяти; возможна линейная первоначальная сборка.

## Проверка качества

В tests.json находятся примеры, независимые проверки малых входов и большие специально подобранные семейства. wrong.cpp содержит намеренную ошибку; slow.cpp, если есть, — корректный на малых данных неэффективный вариант. Подробные фактические результаты находятся в reports.
