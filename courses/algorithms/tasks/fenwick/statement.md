# 33. Живые измерения

Поддерживайте массив. Операция + i x прибавляет x к a[i], операция ? l r требует сумму включённого отрезка. Каждый ответ выведите отдельно.

## Входные данные

n q; n исходных чисел; q операций одного из двух форматов.

## Ограничения

1 ≤ n,q ≤ 200000; |a[i]|,|x| ≤ 10^9; 1 ≤ i,l ≤ r ≤ n для соответствующих операций; хотя бы один запрос ?.

## Пример

Ввод:

```text
2 15
-5 -5
+ 1 3
+ 1 0
? 1 1
+ 1 4
+ 1 -4
+ 2 -3
? 1 2
+ 1 5
? 1 2
+ 1 3
+ 1 -5
? 1 1
+ 1 0
+ 2 -1
? 1 1
```

Вывод:

```text
-2
-10
-5
1
1
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
