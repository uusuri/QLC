# 24. Зоны взаимной доступности

Найдите число компонент сильной связности ориентированного графа. Две вершины принадлежат одной компоненте тогда и только тогда, когда каждая достижима из другой.

## Входные данные

n m; затем m ориентированных рёбер u v. Петли и повторения допустимы.

## Ограничения

1 ≤ n ≤ 200000; 0 ≤ m ≤ 300000; 1 ≤ u,v ≤ n.

## Пример

Ввод:

```text
4 13
2 1
1 3
4 2
2 2
4 1
3 2
4 2
2 1
3 3
3 2
3 1
4 3
3 1
```

Вывод:

```text
2
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
