# 06. Занятая полоса

Даны полуинтервалы [l,r) на числовой прямой. Найдите длину их объединения: каждую покрытую точку учитывайте один раз. Выведите целое число.

## Входные данные

n; затем n строк l r.

## Ограничения

1 ≤ n ≤ 200000; −10^9 ≤ l < r ≤ 10^9.

## Пример

Ввод:

```text
2
9 11
2 13
```

Вывод:

```text
11
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
