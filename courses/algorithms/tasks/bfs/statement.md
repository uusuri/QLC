# 21. Число пересадок

В неориентированном невзвешенном графе найдите расстояние от вершины s до каждой вершины. Расстояние — число рёбер; для недостижимой вершины выведите −1. Ответы в порядке вершин 1…n, каждый с новой строки.

## Входные данные

n m s; затем m строк u v. Возможны петли и повторяющиеся рёбра.

## Ограничения

1 ≤ n ≤ 200000; 0 ≤ m ≤ 300000; 1 ≤ s,u,v ≤ n.

## Пример

Ввод:

```text
4 13 1
2 1
1 3
4 2
2 2
4 1
3 2
4 2
2 1
3 3
3 2
3 1
4 3
3 1
```

Вывод:

```text
0
1
1
1
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
