# Разбор: 34. Разнообразие на отрезке

## Идея

Все запросы известны заранее: их можно временно переставить.

Обрабатывайте запросы по возрастанию r. Для каждого значения оставляйте единицу только в его последнем вхождении.

Перед установкой единицы в r удалите предыдущую единицу того же значения. Сумма Фенвика на [l,r] даст число различных; сохраняйте ID запроса.

## Корректность

Значение встречается в [l,r] тогда и только тогда, когда его последнее вхождение среди первых r позиций не левее l. Поэтому каждой различной величине соответствует ровно одна единица в запросе.

## Время и память

O((n+q) log n) времени, O(n+q) памяти.

## Проверка качества

В tests.json находятся примеры, независимые проверки малых входов и большие специально подобранные семейства. wrong.cpp содержит намеренную ошибку; slow.cpp, если есть, — корректный на малых данных неэффективный вариант. Подробные фактические результаты находятся в reports.
