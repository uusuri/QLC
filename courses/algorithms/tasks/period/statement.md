# 30. Сжатие повторением

Найдите длину кратчайшего непустого блока, повторением которого целое число раз можно получить всю строку s. Один повтор допустим.

## Входные данные

Одна непустая строка из строчных латинских букв.

## Ограничения

1 ≤ |s| ≤ 500000.

## Пример

Ввод:

```text
abaabccaccccbabbaca
```

Вывод:

```text
19
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
