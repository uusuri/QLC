# Разбор: 05. Цена перестановки

## Идея

Разделите пары на лежащие в левой половине, правой и пересекающие границу.

При слиянии отсортированных половин справа можно взять элемент раньше оставшихся слева.

Если a[i]>a[j], этот правый элемент образует инверсии со всеми m−i оставшимися элементами слева. При равенстве берите слева.

## Корректность

Пары внутри половин считаются рекурсивно. При выборе меньшего правого элемента ровно все ещё не перенесённые левые элементы больше него. Ни одна перекрёстная пара не учитывается дважды.

## Время и память

O(n log n) времени, O(n) дополнительной памяти. Это стандартная эффективная оценка для произвольных сравнимых значений.
