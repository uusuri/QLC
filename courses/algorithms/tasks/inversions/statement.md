# 05. Цена перестановки

Посчитайте пары индексов i < j, для которых a[i] > a[j]. Равные элементы инверсии не образуют. Выведите число пар.

## Входные данные

n; затем n целых чисел массива.

## Ограничения

1 ≤ n ≤ 200000; −10^9 ≤ a[i] ≤ 10^9.

## Пример

Ввод:

```text
2
-5 -5
```

Вывод:

```text
0
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
