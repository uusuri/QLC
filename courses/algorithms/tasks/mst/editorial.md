# Разбор: 28. Цена общей сети

## Идея

Обрабатывайте рёбра в порядке возрастания веса.

Добавляйте ребро, только если оно соединяет разные компоненты текущего леса.

Используйте DSU; накопите вес в long long. Для остова из n вершин должны быть выбраны ровно n−1 ребро.

## Корректность

Минимальное ребро, соединяющее текущие компоненты, безопасно по свойству разреза: в любом остове его можно обменять с не более лёгким ребром, пересекающим тот же разрез.

## Время и память

O(m log m + n) времени, O(n+m) памяти.

## Проверка качества

В tests.json находятся примеры, независимые проверки малых входов и большие специально подобранные семейства. wrong.cpp содержит намеренную ошибку; slow.cpp, если есть, — корректный на малых данных неэффективный вариант. Подробные фактические результаты находятся в reports.
