# 13. Слияние архивов

За одну операцию можно объединить два архива размеров x и y, заплатив x+y; новый архив имеет размер x+y. Найдите минимальную суммарную стоимость объединения всех архивов в один.

## Входные данные

n; затем n размеров.

## Ограничения

1 ≤ n ≤ 200000; 1 ≤ a[i] ≤ 10^9.

## Пример

Ввод:

```text
5
4 9 3 11 1
```

Вывод:

```text
57
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
