# Разбор: 25. Доставка с тарифами

## Идея

Очередь BFS не учитывает разные веса; нужен минимум текущего расстояния.

В min-heap храните пары расстояние, вершина. Улучшения добавляйте новой записью.

Если извлечённое расстояние уже не совпадает с d[u], пропустите его. Для каждой дуги релаксируйте d[v] через d[u]+w.

## Корректность

Для извлечённой вершины с минимальной меткой любой ещё неизвестный путь должен пройти через вершину с не меньшей меткой и неотрицательное ребро. Он не может улучшить расстояние.

## Время и память

O((n+m) log(n+m)) времени, O(n+m) памяти с ленивой очередью.

## Проверка качества

В tests.json находятся примеры, независимые проверки малых входов и большие специально подобранные семейства. wrong.cpp содержит намеренную ошибку; slow.cpp, если есть, — корректный на малых данных неэффективный вариант. Подробные фактические результаты находятся в reports.
