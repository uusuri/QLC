# Разбор: 19. Экспедиционный рюкзак

## Идея

Отношение ценности к весу не решает неделимый рюкзак.

dp[c] хранит лучшую ценность при вместимости c после уже обработанных предметов.

Для одного предмета перебирайте c от W к w: dp[c]=max(dp[c],dp[c−w]+v). Возрастание позволило бы брать предмет много раз.

## Корректность

Оптимум либо не содержит текущий предмет, либо содержит его один раз и оптимальный набор предыдущих предметов для c−w. Обратный порядок сохраняет значения предыдущего слоя.

## Время и память

O(nW) времени, O(W) памяти.

## Проверка качества

В tests.json находятся примеры, независимые проверки малых входов и большие специально подобранные семейства. wrong.cpp содержит намеренную ошибку; slow.cpp, если есть, — корректный на малых данных неэффективный вариант. Подробные фактические результаты находятся в reports.
