# 19. Экспедиционный рюкзак

Каждый из n предметов можно взять не более одного раза. Его вес w и ценность v известны. Максимизируйте суммарную ценность при весе не больше W. Можно не брать ничего.

## Входные данные

n W; затем n строк w v.

## Ограничения

1 ≤ n ≤ 100; 0 ≤ W ≤ 100000; 1 ≤ w ≤ 100000; 0 ≤ v ≤ 10^9.

## Пример

Ввод:

```text
2 18
4 27
9 26
```

Вывод:

```text
53
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
