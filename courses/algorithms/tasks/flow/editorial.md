# Разбор: 46. Пропускная способность

## Идея

После отправки потока важно уметь отменять часть прежнего выбора.

Каждой дуге сопоставьте отдельную обратную дугу остаточной сети.

Диниц строит уровни BFS и отправляет блокирующий поток по рёбрам следующего уровня. Используйте указатели текущего ребра и long long для потока.

## Корректность

Каждое увеличение сохраняет ограничения ёмкостей и баланс внутренних вершин. Если пути в остаточной сети нет, множество достижимых из истока образует разрез с ёмкостью текущего потока — значит, больший поток невозможен.

## Время и память

O(n²m) времени в общем случае для Диница, O(n+m) памяти. Это не утверждение об абсолютной оптимальности среди всех потоковых алгоритмов.

## Проверка качества

В tests.json находятся примеры, независимые проверки малых входов и большие специально подобранные семейства. wrong.cpp содержит намеренную ошибку; slow.cpp, если есть, — корректный на малых данных неэффективный вариант. Подробные фактические результаты находятся в reports.
