# 46. Пропускная способность

Найдите максимальный поток из вершины 1 в вершину n в ориентированной сети. У каждой дуги задана неотрицательная целая пропускная способность. Параллельные и встречные дуги независимы.

## Входные данные

n m; затем m строк u v c. Петель нет.

## Ограничения

2 ≤ n ≤ 500; 0 ≤ m ≤ 10000; 1 ≤ u,v ≤ n, u≠v; 0 ≤ c ≤ 10^9.

## Пример

Ввод:

```text
6 3
5 2 15
6 1 7
1 3 7
```

Вывод:

```text
0
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
