# 42. Узлы отказа

Найдите количество точек сочленения: вершин, после удаления которых вместе со всеми инцидентными рёбрами число компонент связности увеличивается. Удалённая вершина отдельной компонентой не считается.

## Входные данные

n m; затем m строк u v неориентированного графа; петли и кратные рёбра допустимы.

## Ограничения

1 ≤ n ≤ 200000; 0 ≤ m ≤ 300000; вершины от 1 до n.

## Пример

Ввод:

```text
4 13
2 1
1 3
4 2
2 2
4 1
3 2
4 2
2 1
3 3
3 2
3 1
4 3
3 1
```

Вывод:

```text
0
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
