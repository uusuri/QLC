# 26. Таблица маршрутов

Найдите расстояния для заданных пар вершин ориентированного графа. Веса могут быть отрицательными; отрицательных циклов во входе нет. Для недостижимой пары выведите INF, иначе целое расстояние.

## Входные данные

n m q; затем m строк u v w; затем q строк s t. Петли и кратные рёбра допустимы.

## Ограничения

1 ≤ n ≤ 400; 0 ≤ m ≤ 160000; 1 ≤ q ≤ 200000; |w| ≤ 10^9; вершины от 1 до n.

## Пример

Ввод:

```text
4 13 10
2 1 8
1 3 22
4 2 2
2 2 2
4 1 -7
3 2 3
4 2 -9
2 1 5
3 3 2
3 2 -1
3 1 -8
4 3 -1
3 1 -8
2 1
3 1
1 4
2 3
3 4
1 1
2 3
1 1
1 2
2 4
```

Вывод:

```text
5
-8
INF
27
INF
0
27
0
21
INF
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
