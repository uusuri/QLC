# Разбор: 26. Таблица маршрутов

## Идея

Много запросов на небольшом графе оправдывают таблицу всех расстояний.

Пусть k ограничивает множество разрешённых промежуточных вершин.

Цикл по k должен быть внешним: d[i][j]=min(d[i][j],d[i][k]+d[k][j]). Не складывайте INF, диагональ инициализируйте нулём, кратные рёбра — минимумом.

## Корректность

Оптимальный путь с промежуточными вершинами из 1…k либо не проходит k, либо разбивается в k на два пути с внутренними вершинами из 1…k−1. Отсутствие отрицательных циклов позволяет выбрать путь без повторений.

## Время и память

O(n³+m+q) времени, O(n²) памяти.

## Проверка качества

В tests.json находятся примеры, независимые проверки малых входов и большие специально подобранные семейства. wrong.cpp содержит намеренную ошибку; slow.cpp, если есть, — корректный на малых данных неэффективный вариант. Подробные фактические результаты находятся в reports.
