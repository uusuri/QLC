# 22. Два канала

Можно ли раскрасить все вершины неориентированного графа в два цвета так, чтобы концы каждого ребра имели разные цвета? Выведите YES или NO. Граф может быть несвязным.

## Входные данные

n m; затем m строк u v. Петли и повторяющиеся рёбра разрешены.

## Ограничения

1 ≤ n ≤ 200000; 0 ≤ m ≤ 300000; 1 ≤ u,v ≤ n.

## Пример

Ввод:

```text
4 13
2 1
1 3
4 2
2 2
4 1
3 2
4 2
2 1
3 3
3 2
3 1
4 3
3 1
```

Вывод:

```text
NO
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
