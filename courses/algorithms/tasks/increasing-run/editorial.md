# Разбор: 02. Полоса роста

## Идея

Достаточно сравнивать текущее число с предыдущим.

Храните длину возрастающего участка, который заканчивается именно сейчас.

Если prev < x, увеличьте длину; иначе начните участок длины 1. Обновляйте максимум на каждом шаге.

## Корректность

Любой возрастающий участок, заканчивающийся в i, продолжает участок в i−1, если a[i−1]<a[i]; иначе содержит только a[i]. Максимум по всем окончаниям перебирает все кандидаты.

## Время и память

Θ(n) времени, O(1) дополнительной памяти.

## Проверка качества

В tests.json находятся примеры, независимые проверки малых входов и большие специально подобранные семейства. wrong.cpp содержит намеренную ошибку; slow.cpp, если есть, — корректный на малых данных неэффективный вариант. Подробные фактические результаты находятся в reports.
