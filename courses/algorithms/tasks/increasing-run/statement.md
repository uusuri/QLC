# 02. Полоса роста

Найдите максимальную длину непустого непрерывного строго возрастающего участка массива. Равные соседние элементы прерывают рост. Выведите длину.

## Входные данные

Первая строка — n, вторая — массив a из n чисел.

## Ограничения

1 ≤ n ≤ 200000; −10^9 ≤ a[i] ≤ 10^9.

## Пример

Ввод:

```text
2
-5 -5
```

Вывод:

```text
1
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
