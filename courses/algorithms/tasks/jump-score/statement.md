# 32. Маршрут по платформам

Стоя на платформе 1, нужно дойти до платформы n, каждый раз прыгая вперёд на 1…k позиций. При посещении i получаете a[i], включая первую и последнюю. Найдите максимальную сумму; пропустить достижение n нельзя.

## Входные данные

n k; затем n чисел a[i].

## Ограничения

1 ≤ k ≤ n ≤ 200000; −10^9 ≤ a[i] ≤ 10^9.

## Пример

Ввод:

```text
2 1
-5 -5
```

Вывод:

```text
-10
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
