# Разбор: 09. Короткий запас

## Идея

Из-за положительности добавление справа увеличивает сумму, удаление слева уменьшает.

Двигайте правую границу и, пока сумма достаточна, сжимайте окно слева.

Обновляйте ответ до удаления левого элемента. Каждый указатель проходит массив один раз.

## Корректность

Для каждого правого конца цикл проверяет самые короткие допустимые окна. Уже удалённая левая граница для более позднего правого конца даст только более длинный участок, поэтому её возврат не нужен.

## Время и память

Θ(n) времени, O(n) памяти для массива.

## Проверка качества

В tests.json находятся примеры, независимые проверки малых входов и большие специально подобранные семейства. wrong.cpp содержит намеренную ошибку; slow.cpp, если есть, — корректный на малых данных неэффективный вариант. Подробные фактические результаты находятся в reports.
