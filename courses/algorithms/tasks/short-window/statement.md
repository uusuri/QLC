# 09. Короткий запас

Найдите длину кратчайшего непустого непрерывного участка с суммой не меньше S. Если такого участка нет, выведите 0.

## Входные данные

n S; затем n положительных чисел.

## Ограничения

1 ≤ n ≤ 200000; 1 ≤ a[i] ≤ 10^9; 1 ≤ S ≤ 10^18.

## Пример

Ввод:

```text
2 17
10 4
```

Вывод:

```text
0
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
