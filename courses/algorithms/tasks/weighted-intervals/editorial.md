# Разбор: 31. Проекты с прибылью

## Идея

Жадность по времени окончания максимизирует число встреч, но не прибыль.

Отсортируйте проекты по окончанию. dp[i] — лучший ответ на первых i проектах.

Либо пропустите проект i, либо добавьте его прибыль к dp[j], где j — число предыдущих проектов с окончанием ≤l[i]. j ищется upper_bound.

## Корректность

В оптимальном наборе среди первых i проектов последний проект либо отсутствует, либо все другие выбранные заканчиваются не позже его начала. Два случая исчерпывают решения.

## Время и память

O(n log n) времени, O(n) памяти.

## Проверка качества

В tests.json находятся примеры, независимые проверки малых входов и большие специально подобранные семейства. wrong.cpp содержит намеренную ошибку; slow.cpp, если есть, — корректный на малых данных неэффективный вариант. Подробные фактические результаты находятся в reports.
