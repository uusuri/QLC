# 31. Проекты с прибылью

У проекта есть время начала l, окончания r и прибыль v. Выберите непересекающиеся проекты с максимальной суммарной прибылью. Интервалы полуоткрытые [l,r), проекты с общей границей совместимы. Можно не выбирать ничего.

## Входные данные

n; затем n строк l r v.

## Ограничения

1 ≤ n ≤ 200000; 0 ≤ l < r ≤ 10^9; 0 ≤ v ≤ 10^9.

## Пример

Ввод:

```text
2
9 11 16
2 13 1
```

Вывод:

```text
16
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
