# 47. Замкнутый маршрут

Найдите минимальную стоимость маршрута, который начинается в городе 1, посещает каждый другой город ровно один раз и возвращается в 1. Матрица стоимости ориентированная и полная; для одного города ответ 0.

## Входные данные

n; затем n строк по n целых чисел c[i][j]. Диагональ нулевая.

## Ограничения

1 ≤ n ≤ 18; 0 ≤ c[i][j] ≤ 10^9.

## Пример

Ввод:

```text
5
0 7 16 5 20
1 0 3 11 15
7 7 0 4 13
1 9 17 0 19
6 18 19 14 0
```

Вывод:

```text
36
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
