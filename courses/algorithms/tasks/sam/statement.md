# 44. Словарь подстрок

Найдите количество различных непустых подстрок строки. Одинаковые подстроки, встречающиеся в разных местах, учитываются один раз.

## Входные данные

Непустая строка из a…z.

## Ограничения

1 ≤ n ≤ 200000.

## Пример

Ввод:

```text
abaabccaccccbabbaca
```

Вывод:

```text
164
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
