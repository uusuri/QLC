# 17. Неразменный запас

Доступны монеты заданных положительных номиналов в неограниченном количестве. Найдите минимальное число монет для суммы S. Если сумму собрать нельзя, выведите −1.

## Входные данные

n S; затем n номиналов. Номиналы могут повторяться.

## Ограничения

1 ≤ n ≤ 100; 0 ≤ S ≤ 100000; 1 ≤ c[i] ≤ 100000.

## Пример

Ввод:

```text
5 3
4 9 3 11 1
```

Вывод:

```text
1
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
