# 08. Расстановка станций

Выберите k из n заданных различных координат. Максимизируйте минимальное расстояние между соседними выбранными точками. Выведите расстояние.

## Входные данные

n k; затем n координат в произвольном порядке.

## Ограничения

2 ≤ k ≤ n ≤ 200000; −10^9 ≤ x[i] ≤ 10^9; координаты различны.

## Пример

Ввод:

```text
5 4
12 -9 20 -18 -13
```

Вывод:

```text
8
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
