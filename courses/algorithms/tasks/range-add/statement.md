# 04. Пакет изменений

Изначально массив из n чисел заполнен нулями. Каждая операция l r x прибавляет x ко всем элементам с l по r включительно. Выполните все операции, затем выведите итоговые элементы по одному в строке.

## Входные данные

n q; далее q строк l r x. Индексы с 1.

## Ограничения

1 ≤ n,q ≤ 200000; 1 ≤ l ≤ r ≤ n; −10^9 ≤ x ≤ 10^9.

## Пример

Ввод:

```text
2 12
1 1 5
1 1 0
1 2 -2
1 2 -5
1 2 4
1 2 -2
1 2 0
1 2 0
1 2 0
1 2 -4
1 2 5
1 2 1
```

Вывод:

```text
2
-3
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
