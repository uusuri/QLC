# Разбор: 04. Пакет изменений

## Идея

Ответы нужны только после всех изменений.

Отметьте начало и конец действия прибавления в разностном массиве.

Сделайте d[l]+=x, d[r+1]−=x. Префиксная сумма d восстанавливает итоговый массив.

## Корректность

В префикс для i попадёт +x ровно при i≥l, а −x при i≥r+1. Поэтому вклад операции равен x только внутри [l,r].

## Время и память

Θ(n+q) времени, O(n) памяти.

## Проверка качества

В tests.json находятся примеры, независимые проверки малых входов и большие специально подобранные семейства. wrong.cpp содержит намеренную ошибку; slow.cpp, если есть, — корректный на малых данных неэффективный вариант. Подробные фактические результаты находятся в reports.
