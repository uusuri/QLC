# Разбор: 20. Редактор команд

## Идея

Рассмотрите задачу для двух префиксов.

Последняя операция удаляет, вставляет или совмещает два последних символа.

dp[i][j]=min(dp[i−1][j]+1,dp[i][j−1]+1,dp[i−1][j−1]+(a[i−1]!=b[j−1])). Достаточно двух строк.

## Корректность

Любое выравнивание префиксов заканчивается одним из трёх перечисленных действий. База dp[0][j]=j и dp[i][0]=i соответствует удалению или вставке всего префикса.

## Время и память

O(|a|·|b|) времени, O(min(|a|,|b|)) памяти для двух строк ДП.

## Проверка качества

В tests.json находятся примеры, независимые проверки малых входов и большие специально подобранные семейства. wrong.cpp содержит намеренную ошибку; slow.cpp, если есть, — корректный на малых данных неэффективный вариант. Подробные фактические результаты находятся в reports.
