# 20. Редактор команд

Найдите минимальное число вставок, удалений и замен одного символа для превращения строки a в b. Каждая операция стоит 1; перестановка соседних символов отдельной операцией не является.

## Входные данные

Две строки a и b в отдельных строках; обе непусты, содержат только a…z.

## Ограничения

1 ≤ |a|,|b| ≤ 3000.

## Пример

Ввод:

```text
abaab
ca
```

Вывод:

```text
4
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
