# 11. Ближайший спад

Для каждой позиции найдите индекс первого строго меньшего элемента справа. Если его нет, ответ −1. Печатайте n ответов, каждый в отдельной строке.

## Входные данные

n; затем n чисел. Индексы с 1.

## Ограничения

1 ≤ n ≤ 200000; −10^9 ≤ a[i] ≤ 10^9.

## Пример

Ввод:

```text
2
-5 -5
```

Вывод:

```text
-1
-1
```

Печатайте только ответ в формате условия, без поясняющих подписей. Принимается любой корректный алгоритм, укладывающийся в лимиты.
