# Почему это работает: Дополнение: Ахо—Корасик и суффиксный автомат

Необязательный раздел. Он не содержит зачётных задач. Лучше читать после собственной попытки: здесь раскрываются идеи решений.

## 43. Поиск по словарю

Состояние после символа соответствует самому длинному суффиксу текста, который есть в боре. Все более короткие совпадающие образцы лежат на цепочке суффиксных ссылок. Обратный BFS передаёт каждый счётчик ровно к этим предкам.

Оценка ресурсов: O(26·P+T+k) времени и O(26·P+T+k) памяти с плотными переходами, P — суммарная длина образцов, T — длина текста.

## 44. Словарь подстрок

Состояние представляет все длины от len(link(v))+1 до len(v), и для каждой длины — ровно одну строку. Клоны разделяют классы при нарушении этой границы, сохраняя язык подстрок.

Оценка ресурсов: O(26n) времени и O(26n) памяти — линейно при фиксированном алфавите.

## Проверьте границы утверждений

В Ахо не забывайте накопление по ссылкам и повторяющиеся образцы. В автомате ответ может быть порядка n², нужен int в 64-битной сборке PHP. Обычный бор всех подстрок квадратичен.

Попробуйте изменить одну предпосылку и найти минимальный контрпример: знак чисел, строгость сравнения, направление ребра или допустимость пустого ответа. Сверьте полученный пример с формальным условием, а затем с независимым перебором.
