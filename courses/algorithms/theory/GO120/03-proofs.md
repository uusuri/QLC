# Почему это работает: Сортировка как преобразование задачи

Необязательный раздел. Он не содержит зачётных задач. Лучше читать после собственной попытки: здесь раскрываются идеи решений.

## 05. Цена перестановки

Пары внутри половин считаются рекурсивно. При выборе меньшего правого элемента ровно все ещё не перенесённые левые элементы больше него. Ни одна перекрёстная пара не учитывается дважды.

Оценка ресурсов: O(n log n) времени, O(n) дополнительной памяти. Это стандартная эффективная оценка для произвольных сравнимых значений.

## 06. Занятая полоса

При l>R ни один последующий отрезок уже не соединится с текущим блоком: их начала не меньше l. Пересекающийся отрезок меняет только правую границу блока.

Оценка ресурсов: O(n log n) времени на сортировку, O(n) памяти для входа.

## Проверьте границы утверждений

Компаратор должен задавать строгий порядок: используйте <, а не ≤. Пересчёт инверсий после сортировки теряет исходную задачу. Вложенный отрезок не сужает объединение.

Попробуйте изменить одну предпосылку и найти минимальный контрпример: знак чисел, строгость сравнения, направление ребра или допустимость пустого ответа. Сверьте полученный пример с формальным условием, а затем с независимым перебором.
