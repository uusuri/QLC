# Почему это работает: Бинарный поиск по ответу

Необязательный раздел. Он не содержит зачётных задач. Лучше читать после собственной попытки: здесь раскрываются идеи решений.

## 07. Доставка по дням

Жадная группа при заданной ёмкости заканчивается не раньше первой группы любого допустимого разбиения. Повторение аргумента минимизирует количество групп. Увеличение ёмкости не ухудшает допустимость.

Оценка ресурсов: O(n log(sum a)) времени, O(n) памяти.

## 08. Расстановка станций

Замена первой станции любой допустимой расстановки самой левой не мешает последующим. То же верно для каждого следующего самого раннего допустимого выбора.

Оценка ресурсов: O(n log n + n log D) времени, O(n) памяти, D=max(x)−min(x).

## Проверьте границы утверждений

Не переполняйте сумму весов. Для расстояния равенство допустимо. Сначала сортируйте координаты. Обновление lo=mid при lo+1=hi может зациклить включённый поиск.

Попробуйте изменить одну предпосылку и найти минимальный контрпример: знак чисел, строгость сравнения, направление ребра или допустимость пустого ответа. Сверьте полученный пример с формальным условием, а затем с независимым перебором.
