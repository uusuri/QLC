# ДП по двум измерениям и экономия памяти

## Что вы научитесь делать

Различать 0/1 и неограниченные предметы; сжимать слои без изменения зависимостей.

Предпосылки: Предыдущие модули, 01–09.

## Идея и алгоритм

В рюкзаке состояние dp[i][c] описывает лучший результат среди первых i предметов при вместимости c. Оптимальный набор либо не берёт предмет i, либо берёт его и добавляет v[i] к результату предыдущих предметов при c−w[i]. Это два исчерпывающих случая, а не эвристика по отношению цены к весу.

Если требуется вес не больше c и можно взять пустой набор, базовые значения равны нулю. Для задачи о точном весе база иная: только вес 0 достижим, остальные состояния должны иметь −∞. Фраза «не больше» в условии меняет не только финальный ответ, но и инициализацию.

Весь двумерный массив хранить не нужно: слой i зависит лишь от i−1. Для 0/1-рюкзака достаточно одного массива с обходом вместимостей по убыванию. Тогда dp[c−w] ещё относится к предыдущему слою. При обходе по возрастанию значение уже может включать текущий предмет, и алгоритм незаметно решит неограниченный рюкзак. Экономия памяти требует доказательства, какие старые ячейки ещё нужны.

Редакционное расстояние — другой пример двумерного состояния: dp[i][j] — стоимость превращения первых i символов a в первые j символов b. Последнее действие — удалить, вставить или совместить пару последних символов; совпадение стоит 0, замена 1. Пустой префикс преобразуется в префикс длины j за j вставок.

Для расстояния нужны предыдущая строка и уже вычисленная левая ячейка текущей. Храните две строки, выбрав более короткую строку по горизонтали: память O(min(n,m)), время O(nm). Такое сжатие сохраняет значение оптимума, но не весь путь редактирования. Если требуется восстановить операции, понадобится дополнительный приём или таблица предшественников. Не добавляйте перестановку соседних символов, если её нет среди допустимых операций.

## Реализация на Java

Храните два соседних слоя ДП, если переход использует только предыдущий. При копировании слоя проверьте, создаются ли новые данные: `int[] copy = a.clone();` создаёт отдельный массив и копирует n элементов: Θ(n) времени и Θ(n) памяти. Присваивание `int[] copy = a;` копирует только ссылку — массив остаётся общим.

## Разберём пример

Один предмет веса 2 и ценности 7, W=4: правильный ответ 7. Возрастающий проход по c ошибочно получит 14. Для a=ab и b=ba редакционное расстояние равно 2: одна перестановка не разрешена.

## Где ошибаются

Нулевую вместимость нужно поддерживать. Сумма ценностей может превышать диапазон 32-битного целого; оцените её максимум заранее. В редакционном расстоянии каждый новый слой начинается с dp[i][0]=i.

## Практика

- 19. Экспедиционный рюкзак: Каждый из n предметов можно взять не более одного раза. Его вес w и ценность v известны. Максимизируйте суммарную ценность при весе не больше W. Можно не брать ничего.
- 20. Редактор команд: Найдите минимальное число вставок, удалений и замен одного символа для превращения строки a в b. Каждая операция стоит 1; перестановка соседних символов отдельной операцией не является.

Решайте задачи по порядку. Если застряли, сначала сформулируйте медленный корректный способ, затем откройте одну подсказку. После решения объясните оценку времени и памяти и придумайте контрпример к своей первой неверной идее. Доказательства вынесены в следующий необязательный урок; для перехода дальше читать их не требуется.
