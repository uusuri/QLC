# Почему это работает: Кратчайшие пути и отрицательные веса

Необязательный раздел. Он не содержит зачётных задач. Лучше читать после собственной попытки: здесь раскрываются идеи решений.

## 25. Доставка с тарифами

Для извлечённой вершины с минимальной меткой любой ещё неизвестный путь должен пройти через вершину с не меньшей меткой и неотрицательное ребро. Он не может улучшить расстояние.

Оценка ресурсов: O((n+m) log(n+m)) времени, O(n+m) памяти с ленивой очередью.

## 26. Таблица маршрутов

Оптимальный путь с промежуточными вершинами из 1…k либо не проходит k, либо разбивается в k на два пути с внутренними вершинами из 1…k−1. Отсутствие отрицательных циклов позволяет выбрать путь без повторений.

Оценка ресурсов: O(n³+m+q) времени, O(n²) памяти.

## Проверьте границы утверждений

Не запускайте обычную Дейкстру с отрицательными рёбрами. Не заменяйте минимум последним кратным ребром. Не переставляйте внешний цикл k у Флойда.

Попробуйте изменить одну предпосылку и найти минимальный контрпример: знак чисел, строгость сравнения, направление ребра или допустимость пустого ответа. Сверьте полученный пример с формальным условием, а затем с независимым перебором.
