# Жадность, контрпример и частоты

## Что вы научитесь делать

Отличать доказуемый локальный выбор от правдоподобной эвристики; применять частоты префиксов.

Предпосылки: Предыдущие модули, 01–07.

## Идея и алгоритм

Жадный алгоритм принимает локальное решение и больше его не пересматривает. Скорость и простота привлекательны, но локальное правило нужно обосновать. Прежде чем писать код, попробуйте построить контрпример из трёх–пяти объектов. «Похоже, это выгодно» — гипотеза, а не доказательство.

Для максимального числа непересекающихся встреч выбирайте встречу с самым ранним окончанием. Такой выбор оставляет максимально большой остаток времени. Любое оптимальное расписание можно преобразовать так, чтобы первой стояла наша встреча: она заканчивается не позже прежней первой и не мешает остальным. После замены возникает та же задача на оставшихся встречах. Это аргумент обмена.

Выбор самой короткой встречи или самой ранней по началу не обладает тем же свойством. Если у встреч есть разные прибыли, правило по окончанию тоже перестаёт решать задачу: одну дорогую встречу иногда лучше выбрать вместо нескольких дешёвых. Финальный модуль основы вернётся к этому примеру и заменит жадность динамикой.

Задача о точной сумме участка показывает другой способ уходить от квадратичного перебора. Для префиксов p[j] и p[i] условие суммы K означает p[i]=p[j]−K. Просматривайте правые концы и храните частоты предыдущих префиксов. Значения могут повторяться; нужен счётчик, не множество. Перед чтением есть пустой префикс 0 с частотой 1.

Порядок действий важен: сначала прибавьте частоту p−K к ответу, затем зарегистрируйте текущий p. Иначе при K=0 будет ошибочно учтён пустой участок. Сбалансированное дерево даёт O(n log n); хеш-таблица обычно позволяет получить ожидаемое O(n). Сама идея не зависит от контейнера. Ключи и число ответов требуют int64_t, поскольку префиксы и количество участков могут быть большими.

## Реализация на C

В стандартной библиотеке C нет словаря. Возможный вариант без собственной хеш-таблицы: заранее вычислить все префиксы, отсортировать и сжать их координаты. Частоты храните в массиве, нужный ключ ищите бинарным поиском. Получится O(n log n).

## Разберём пример

У [1,−1,1] префиксы 0,1,0,1. Для K=0 совпадающие пары префиксов дают два непустых участка: позиции [1,2] и [2,3]. Для встреч [0,2), [1,5), [2,4) правило раннего конца выберет две.

## Где ошибаются

Не переносите жадное правило на задачу с другими целями. Не теряйте кратность одинаковых префиксов. Отрицательные числа исключают простую монотонность суммы окна.

## Практика

- 15. Один переговорный зал: Выберите максимальное число встреч [l,r), которые не пересекаются. Встреча, начинающаяся ровно в момент окончания предыдущей, допустима. Выведите количество.
- 16. Точный баланс: Посчитайте непустые непрерывные участки массива с суммой ровно K. Числа могут быть отрицательными. Выведите количество участков.

Решайте задачи по порядку. Если застряли, сначала сформулируйте медленный корректный способ, затем откройте одну подсказку. После решения объясните оценку времени и памяти и придумайте контрпример к своей первой неверной идее. Доказательства вынесены в следующий необязательный урок; для перехода дальше читать их не требуется.
