# Два указателя и монотонное окно

## Что вы научитесь делать

Доказывать, что границу можно двигать только вперёд; считать пары без двойного учёта.

Предпосылки: Предыдущие модули, 01–04.

## Идея и алгоритм

Два указателя ускоряют перебор только при наличии монотонности. Недостаточно просто завести l и r: нужно объяснить, почему отброшенные позиции никогда не понадобятся. В задаче о положительных числах расширение окна увеличивает сумму, а сужение уменьшает. Поэтому для каждого правого конца можно двигать левый, пока условие выполняется.

Для кратчайшего окна с суммой не меньше S добавьте a[r], затем пока сумма достаточна, обновляйте ответ и удаляйте a[l]. Ответ записывается до удаления. Если после удаления окно стало недопустимым, дальнейшее сжатие его не исправит. Когда придёт новый правый конец, продолжайте с сохранённого l.

С отрицательными числами эти рассуждения неверны. Например, удаление отрицательного элемента увеличивает сумму. Для точной суммы позже понадобятся частоты префиксов, а для других условий — более сложные структуры. Проверка ограничений на знаки — часть выбора метода.

В задаче о близких парах сначала отсортируйте значения. Для каждого r найдите минимальный l с a[r]−a[l]≤K. Все индексы между l и r−1 подходят, их ровно r−l. Каждая неупорядоченная пара учитывается один раз, когда обрабатывается её правый элемент в отсортированном порядке. Равные значения на разных позициях не должны схлопываться в множество.

Почему вложенный while не делает решение квадратичным? Правый указатель увеличивается n раз, левый — не более n раз за весь алгоритм. Работа распределена между итерациями неравномерно, но суммарно линейна. С сортировкой общий алгоритм подсчёта пар занимает O(n log n), само окно — O(n). Такой анализ движения состояния будет использоваться и для стеков, очередей и строковых алгоритмов.

## Реализация на JavaScript

Перемещайте границы индексами по исходному массиву. Создание копии каждого окна добавляет работу, которой нет в доказательстве O(n). `const copy = a.slice();` копирует n элементов массива: Θ(n) времени и Θ(n) дополнительной памяти в обычной модели массивов. `const copy = a` копирует ссылку. Если элементы — объекты, сами объекты при `slice()` не копируются.

## Разберём пример

Для [2,1,3,2] и S=5 при r=3 сумма 6: сначала окно длины 3, после удаления 2 сумма 4. При r=4 сумма 6: окно [1,3,2] длины 3, затем [3,2] длины 2. Ответ 2.

## Где ошибаются

Не добавляйте сам элемент как пару с собой. Для количества пар нужен Number или BigInt. Условие ≤K включает равенство; K=0 проверяет дубликаты.

## Практика

- 09. Короткий запас: Найдите длину кратчайшего непустого непрерывного участка с суммой не меньше S. Если такого участка нет, выведите 0.
- 10. Близкие показания: Посчитайте пары различных индексов i<j, для которых |a[i]−a[j]|≤K. Одинаковые значения на разных позициях образуют разные пары.

Решайте задачи по порядку. Если застряли, сначала сформулируйте медленный корректный способ, затем откройте одну подсказку. После решения объясните оценку времени и памяти и придумайте контрпример к своей первой неверной идее. Доказательства вынесены в следующий необязательный урок; для перехода дальше читать их не требуется.
