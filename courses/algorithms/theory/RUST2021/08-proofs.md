# Почему это работает: Жадность, контрпример и частоты

Необязательный раздел. Он не содержит зачётных задач. Лучше читать после собственной попытки: здесь раскрываются идеи решений.

## 15. Один переговорный зал

Первую встречу оптимального расписания можно заменить самой ранней по окончанию: она освобождает зал не позже. После замены остаётся такая же задача для встреч, начинающихся после её конца.

Оценка ресурсов: O(n log n) времени, O(n) памяти.

## 16. Точный баланс

При обработке правого конца карта содержит каждый допустимый левый префикс с его кратностью. Обновление после подсчёта не допускает пустого участка.

Оценка ресурсов: O(n log n) гарантированного времени, O(n) памяти со сбалансированным деревом. Хеш-таблица даёт ожидаемое O(n), но без гарантии на худший случай.

## Проверьте границы утверждений

Не переносите жадное правило на задачу с другими целями. Не теряйте кратность одинаковых префиксов. Отрицательные числа исключают простую монотонность суммы окна.

Попробуйте изменить одну предпосылку и найти минимальный контрпример: знак чисел, строгость сравнения, направление ребра или допустимость пустого ответа. Сверьте полученный пример с формальным условием, а затем с независимым перебором.
