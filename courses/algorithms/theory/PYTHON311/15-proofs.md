# Почему это работает: Строки: границы, поиск и хеширование

Необязательный раздел. Он не содержит зачётных задач. Лучше читать после собственной попытки: здесь раскрываются идеи решений.

## 29. Все совпадения

j — длина максимального префикса образца, совпадающего с суффиксом уже прочитанного текста. Цепочка префикс-функции перечисляет все меньшие допустимые длины. Суммарно j увеличивается линейное число раз.

Оценка ресурсов: Θ(|p|+|t|) времени, O(|p|) дополнительной памяти.

## 30. Сжатие повторением

n−pi[n−1] — минимальный период в смысле совпадения символов при сдвиге. Чтобы строка была конкатенацией полных блоков, длина должна делиться на этот период.

Оценка ресурсов: Θ(n) времени, O(n) памяти.

## Проверьте границы утверждений

Не обращайтесь к p[j], когда j уже равно длине образца: сначала обработайте совпадение. Не включайте всю строку в собственный префикс. Проверяйте делимость при полном повторении.

Попробуйте изменить одну предпосылку и найти минимальный контрпример: знак чисел, строгость сравнения, направление ребра или допустимость пустого ответа. Сверьте полученный пример с формальным условием, а затем с независимым перебором.
