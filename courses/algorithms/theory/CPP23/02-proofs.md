# Почему это работает: Префиксы и отложенные изменения

Необязательный раздел. Он не содержит зачётных задач. Лучше читать после собственной попытки: здесь раскрываются идеи решений.

## 03. Архив измерений

Префикс до r содержит искомый отрезок и первые l−1 элементов. Вычитание последнего префикса оставляет каждый элемент отрезка ровно один раз.

Оценка ресурсов: Θ(n+q) времени, O(n) памяти. Запрос после подготовки — O(1).

## 04. Пакет изменений

В префикс для i попадёт +x ровно при i≥l, а −x при i≥r+1. Поэтому вклад операции равен x только внутри [l,r].

Оценка ресурсов: Θ(n+q) времени, O(n) памяти.

## Проверьте границы утверждений

Закрытие прибавления ставится в r+1. Префиксы и изменения должны быть 64-битными. Пустой префикс существует, даже если пустые запросы запрещены.

Попробуйте изменить одну предпосылку и найти минимальный контрпример: знак чисел, строгость сравнения, направление ребра или допустимость пустого ответа. Сверьте полученный пример с формальным условием, а затем с независимым перебором.
