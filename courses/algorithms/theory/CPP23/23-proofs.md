# Почему это работает: Дополнение: паросочетания и потоки

Необязательный раздел. Он не содержит зачётных задач. Лучше читать после собственной попытки: здесь раскрываются идеи решений.

## 45. Распределение наставников

Переворот увеличивающего пути увеличивает паросочетание на один. Если увеличивающих путей нет, симметрическая разность с гипотетически большим паросочетанием дала бы такой путь — противоречие. BFS-фазы ограничивают число проходов.

Оценка ресурсов: O((e+n+m)√(n+m)) времени, O(e+n+m) памяти для Хопкрофта—Карпа.

## 46. Пропускная способность

Каждое увеличение сохраняет ограничения ёмкостей и баланс внутренних вершин. Если пути в остаточной сети нет, множество достижимых из истока образует разрез с ёмкостью текущего потока — значит, больший поток невозможен.

Оценка ресурсов: O(n²m) времени в общем случае для Диница, O(n+m) памяти. Это не утверждение об абсолютной оптимальности среди всех потоковых алгоритмов.

## Проверьте границы утверждений

Обратная дуга получает отправленный поток, а не исходную ёмкость. Не объединяйте независимые встречные дуги по одному индексу. Суммарный поток может превышать int.

Попробуйте изменить одну предпосылку и найти минимальный контрпример: знак чисел, строгость сравнения, направление ребра или допустимость пустого ответа. Сверьте полученный пример с формальным условием, а затем с независимым перебором.
