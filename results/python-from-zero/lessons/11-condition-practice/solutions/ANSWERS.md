## Задание 2

## Задание 3

Все три строгих неравенства необходимы. Равенство исключается.

```python
a = int(input())
b = int(input())
c = int(input())
if a < b + c and b < a + c and c < a + b:
    print('ДА')
else:
    print('НЕТ')
```

## Задание 4

Используем or для четырёх номеров месяцев, затем отдельную ветвь февраля.

```python
month = int(input())
if month == 4 or month == 6 or month == 9 or month == 11:
    print(30)
elif month == 2:
    print(28)
else:
    print(31)
```
