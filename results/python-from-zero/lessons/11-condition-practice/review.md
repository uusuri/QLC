# Проверка урока 11

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: Остаток, and, or, if/else

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Определить, високосный ли год в григорианском календаре. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Перевести правило с исключением в программу и подобрать проверки. |
| Сквозной пример | Первый пример main: Исключённое столетие. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: Выбрать отрицательный ответ; результат: НЕТ |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | Промежуточные bool позволяют проверить каждую часть отдельно. В финальном выражении скобки показывают, что запрет столетий относится только к ветви делимости на 4, а кратность 400 образует самостоятельный разрешённый случай. |
| Корректность | Выражение дословно кодирует два разрешённых случая и запрещает остальные; оно не зависит от удачности одного примера. Выполняется три остатка и несколько логических действий, хранится фиксированное число значений. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: Для другой календарной системы нужен другой алгоритм: исходное правило применимости изменилось. Для этой задачи номера года положительны.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
