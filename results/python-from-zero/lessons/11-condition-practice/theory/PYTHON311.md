# 11. Составляем решение: календарь и проверка правил

После урока вы сможете: Перевести правило с исключением в программу и подобрать проверки.

Нужные знания: Остаток, and, or, if/else

## От задачи к способу решения

Этот урок учит не новому знаку, а работе с условием. Правило задачи: год високосный, если делится на 400, либо делится на 4, но не делится на 100. Здесь правило задано для всех разрешённых номеров года; исторические даты перехода стран на календарь не рассматриваются.

Начните с примеров. 2024 делится на 4, не делится на 100 — подходит. 1900 делится на 4, но столетний и не делится на 400 — не подходит. 2000 делится на 400 — подходит. Один пример 2024 не обнаружил бы решение «проверять только делимость на 4».

Разделим правило на вопросы. `by_four` означает нулевой остаток от деления на 4. Аналогично зададим `by_hundred` и `by_four_hundred`. Теперь словесное правило превращается в `by_four_hundred or (by_four and not by_hundred)`. Имена здесь сохраняют результаты сравнений, то есть значения bool.

Правильность проверяем по группам. Если год делится на 400, первая часть допускает его. Если не делится на 400, ответ определяется второй частью: он должен делиться на 4 и не быть исключённым столетием. Если не делится на 4, не пройдёт ни один допустимый случай. Нам не нужно перечислять тысячи годов.

Так же переводятся геометрические и бытовые правила. Например, три положительные длины a, b, c образуют невырожденный треугольник, если каждая меньше суммы двух других. Невырожденный означает, что вершины не лежат на одной прямой и площадь не нулевая. Длины 2, 3, 5 дают равенство, поэтому не подходят. Проверка одной суммы недостаточна: с 10, 2, 3 самая длинная сторона нарушает другое неравенство.

Общий порядок работы: выписать правила словами → найти примеры для каждого случая → назвать логические части → соединить их → проверить границы. Условия становятся проще, когда мы знаем, какое требование проверяет каждая часть. Укорачивание строки не является целью.

## Задача и формат данных

Определить, високосный ли год в григорианском календаре.

**Ввод:** Один целый номер года.

**Вывод:** ДА для високосного, иначе НЕТ.

**Допустимые данные:** Годы от 1 до 9999; используется указанное правило календаря.

Вход сквозного примера:

```text
1900
```

Ожидаемый вывод:

```text
НЕТ
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | Прочитать год | year = 1900 |
| 2 | Получить три результата делимости | by_four = True, by_hundred = True, by_four_hundred = False |
| 3 | Столетний год не прошёл исключение про 400 | False or (True and False) = False |
| 4 | Выбрать отрицательный ответ | НЕТ |

## Полная программа

```python
year = int(input())
by_four = year % 4 == 0
by_hundred = year % 100 == 0
by_four_hundred = year % 400 == 0
if by_four_hundred or (by_four and not by_hundred):
    print('ДА')
else:
    print('НЕТ')
```

## Как читать реализацию

Промежуточные bool позволяют проверить каждую часть отдельно. В финальном выражении скобки показывают, что запрет столетий относится только к ветви делимости на 4, а кратность 400 образует самостоятельный разрешённый случай.

## Почему работает и сколько действий требуется

Выражение дословно кодирует два разрешённых случая и запрещает остальные; оно не зависит от удачности одного примера. Выполняется три остатка и несколько логических действий, хранится фиксированное число значений.

## Границы и частые ошибки

Для другой календарной системы нужен другой алгоритм: исходное правило применимости изменилось. Для этой задачи номера года положительны.
