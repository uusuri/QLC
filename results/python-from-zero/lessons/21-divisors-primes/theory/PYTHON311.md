# 21. Перебор кандидатов: делители и простые числа

После урока вы сможете: Проверять кандидатов по правилу и вывести границу перебора.

Нужные знания: Остаток, циклы, break и bool

## От задачи к способу решения

**Делитель** положительного числа n — положительное целое d, на которое n делится без остатка. У 12 делители 1, 2, 3, 4, 6, 12. **Простое число** — целое больше 1, у которого ровно два положительных делителя: 1 и оно само. Ноль и единица простыми не являются.

Понятный способ проверки: перебрать все числа от 2 до n − 1 и спросить, делит ли каждое n. Если нашли хотя бы одно — число составное. Если не нашли — простое. Это корректно, но для большого n выполняет почти n проверок.

Сократим повторяющуюся работу. Делители идут парами: если n = a * b, то a и b — делители. В паре хотя бы одно число не больше квадратного корня из n. Иначе оба были бы больше корня, и произведение оказалось бы больше n. Поэтому при наличии нетривиального делителя есть такой делитель не выше корня.

Не будем вычислять приближённый корень. Проверка `divisor * divisor <= n` использует целые и означает тот же предел. Начинаем с divisor = 2, последовательно увеличиваем на 1. Если остаток ноль, ставим `is_prime = False` и выходим через break: одного свидетеля достаточно.

Сквозной пример 49 особенно полезен. Кандидаты 2, 3, 4, 5, 6 не делят 49. Кандидат 7 делит, поэтому число не простое. Если ошибочно написать `< n` вместо `<= n` в условии квадрата, проверка 7 пропадёт и квадрат простого будет признан простым.

Изначально is_prime = n >= 2. Это **флаг** — логическая переменная, обозначающая состояние. У нуля и единицы флаг сразу ложный; цикл не запускается. У остальных число считается кандидатом в простые, пока не найден делитель. Такой флаг не является доказательством сам по себе: его смысл поддерживается проверками.

## Задача и формат данных

Определить, является ли целое n простым.

**Ввод:** Одно целое n.

**Вывод:** ДА для простого, иначе НЕТ.

**Допустимые данные:** 0 <= n <= 1000000.

Вход сквозного примера:

```text
49
```

Ожидаемый вывод:

```text
НЕТ
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 0 | 49 >= 2: допускаем кандидата, начинаем с 2 | is_prime = True, divisor = 2 |
| 1 | 2, 3, 4, 5, 6 проверены, остатки ненулевые | is_prime = True, divisor = 7 |
| 2 | 7 * 7 <= 49 и 49 % 7 = 0: найден делитель | is_prime = False |
| 3 | break завершает поиск свидетеля | НЕТ |

## Полная программа

```python
n = int(input())
is_prime = n >= 2
divisor = 2
while is_prime and divisor * divisor <= n:
    if n % divisor == 0:
        is_prime = False
        break
    divisor += 1
if is_prime:
    print('ДА')
else:
    print('НЕТ')
```

## Как читать реализацию

is_prime хранит текущий результат проверки, divisor — очередной кандидат. Порядок and не запускает цикл для уже отвергнутых 0 и 1. Если делитель найден, дальнейший перебор не изменит ответ, поэтому break безопасен. Если кандидаты кончились, ни одного малого делителя нет.

## Почему работает и сколько действий требуется

Любой составной n >= 2 имеет делитель от 2 до квадратного корня, и цикл проверяет все такие кандидаты. Поэтому отсутствие свидетеля означает простоту. divisor растёт на каждом не завершающем шаге. Не больше примерно корня из n проверок, постоянное число переменных. В пределах заданного n целочисленные операции малы.

## Границы и частые ошибки

Алгоритм предназначен для одного числа, не для списка миллионов запросов. Для очень больших целых потребуются другие методы. Отрицательные числа не разрешены.
