# 21. Перебор кандидатов: делители и простые числа: ответы

## Задание 1

У него только один положительный делитель, а определение требует ровно два и значение больше 1.

## Задание 2

Квадрат простого, например 49, имеет единственный малый нетривиальный делитель ровно на границе: 7.

## Задание 3

Проверяем все кандидаты от 1 до n включительно.

```python
n = int(input())
for divisor in range(1, n + 1):
    if n % divisor == 0:
        print(divisor)
```

## Задание 4

Последний кандидат n исключаем границей range(1, n). Для единицы сумма пустая и равна 0.

```python
n = int(input())
total = 0
for divisor in range(1, n):
    if n % divisor == 0:
        total += divisor
print(total)
```
