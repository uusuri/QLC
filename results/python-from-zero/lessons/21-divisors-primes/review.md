# Проверка урока 21

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: Остаток, циклы, break и bool

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Определить, является ли целое n простым. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Проверять кандидатов по правилу и вывести границу перебора. |
| Сквозной пример | Первый пример main: Квадрат простого. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: break завершает поиск свидетеля; результат: НЕТ |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | is_prime хранит текущий результат проверки, divisor — очередной кандидат. Порядок and не запускает цикл для уже отвергнутых 0 и 1. Если делитель найден, дальнейший перебор не изменит ответ, поэтому break безопасен. Если кандидаты кончились, ни одного малого делителя нет. |
| Корректность | Любой составной n >= 2 имеет делитель от 2 до квадратного корня, и цикл проверяет все такие кандидаты. Поэтому отсутствие свидетеля означает простоту. divisor растёт на каждом не завершающем шаге. Не больше примерно корня из n проверок, постоянное число переменных. В пределах заданного n целочисленные операции малы. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: Алгоритм предназначен для одного числа, не для списка миллионов запросов. Для очень больших целых потребуются другие методы. Отрицательные числа не разрешены.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
