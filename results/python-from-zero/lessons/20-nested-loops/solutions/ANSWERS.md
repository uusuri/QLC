# 20. Вложенные циклы и таблицы: ответы

## Задание 1

20: пять печатаний для каждого из четырёх рядов.

## Задание 2

Каждый символ завершится переносом строки; прямоугольник распадётся на отдельные звёздочки.

## Задание 3

Внутренний диапазон зависит от номера текущего ряда, который считаем с 1.

```python
n = int(input())
for row in range(1, n + 1):
    for column in range(row):
        print('*', end='')
    print()
```

## Задание 4

Перенос нужен после каждой пары, поэтому один обычный print находится во внутреннем теле.

```python
n = int(input())
m = int(input())
for row in range(1, n + 1):
    for column in range(1, m + 1):
        print(row, column)
```
