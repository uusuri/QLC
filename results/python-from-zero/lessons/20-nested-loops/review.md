# Проверка урока 20

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: for, range, print с end

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Напечатать прямоугольник из звёздочек заданной высоты и ширины. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Отличать внешний шаг от внутренних и считать общее число повторений. |
| Сквозной пример | Первый пример main: Два ряда. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: Второй ряд повторяет три печатания и перенос; результат: Вторая строка: *** |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | row — номер повторения ряда, column — номер позиции. Здесь их значения не влияют на символ; в таблице умножения влияли бы. Внутренний диапазон проходит заново при каждом внешнем шаге, это не один общий проход по width. |
| Корректность | Каждый ряд содержит ровно width звёздочек и один перевод строки, рядов height. Циклы конечны. Для h рядов и w столбцов работа и размер вывода пропорциональны h * w; программа не хранит таблицу, поэтому дополнительная память постоянна. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: break внутри внутреннего цикла закончит только текущий ряд, а внешний продолжится. Для большой таблицы надо учитывать объём результата, даже если код короткий.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
