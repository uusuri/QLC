# 20. Вложенные циклы и таблицы

После урока вы сможете: Отличать внешний шаг от внутренних и считать общее число повторений.

Нужные знания: for, range, print с end

## От задачи к способу решения

Один цикл печатает последовательность. Для таблицы нужно повторять действия внутри каждого ряда. **Вложенный цикл** — цикл, расположенный в теле другого. Внешний выбирает строку, внутренний — позиции внутри неё.

Для высоты 2 и ширины 3 ожидаем две строки по три звёздочки. После выбора первой строки внутренний цикл проходит три позиции: печатает `*`, затем `*`, затем `*`. После него один print без аргументов переводит вывод на новую строку. Только потом внешний цикл выбирает вторую строку, и внутренний снова начинает с первой позиции.

`print('*', end='')` не добавляет ни пробел, ни перенос. Поэтому звёздочки соединяются. `print()` с пустыми скобками печатает только стандартное завершение — перенос строки. Его отступ должен совпасть с внутренним for, чтобы он относился к внешнему телу, но находился после внутреннего цикла.

Если перенос поставить внутрь второго цикла, каждая звёздочка окажется на новой строке. Если вынести за оба цикла, все ряды сольются. Отступы здесь показывают, что должно повториться для каждой ячейки, а что — один раз после каждого ряда.

Число итераций не равно height + width. На каждую из height строк приходится width внутренних шагов, значит всего height * width печатаний звёздочки. При 2 и 3 это шесть ячеек. Если обе стороны равны n, работа растёт как n²: удвоение стороны даёт вчетверо больше ячеек.

Прямоугольник можно напечатать и без внутреннего цикла: строка `'*' * width` повторяет текст width раз. Это полезное сокращение, но не отменяет размер вывода. Вложенные циклы нужны для более сложных таблиц, где значение зависит от номера строки и столбца, например таблицы умножения.

## Задача и формат данных

Напечатать прямоугольник из звёздочек заданной высоты и ширины.

**Ввод:** Высота и ширина отдельными строками.

**Вывод:** height строк, в каждой width звёздочек.

**Допустимые данные:** 1 <= height, width <= 30.

Вход сквозного примера:

```text
2
3
```

Ожидаемый вывод:

```text
***
***
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | Внешний цикл выбирает первый ряд | row = 0 |
| 2 | Внутренний цикл печатает три символа без переноса | *** |
| 3 | После внутреннего цикла завершить ряд | Первая строка готова |
| 4 | Второй ряд повторяет три печатания и перенос | Вторая строка: *** |

## Полная программа

```python
height = int(input())
width = int(input())
for row in range(height):
    for column in range(width):
        print('*', end='')
    print()
```

## Как читать реализацию

row — номер повторения ряда, column — номер позиции. Здесь их значения не влияют на символ; в таблице умножения влияли бы. Внутренний диапазон проходит заново при каждом внешнем шаге, это не один общий проход по width.

## Почему работает и сколько действий требуется

Каждый ряд содержит ровно width звёздочек и один перевод строки, рядов height. Циклы конечны. Для h рядов и w столбцов работа и размер вывода пропорциональны h * w; программа не хранит таблицу, поэтому дополнительная память постоянна.

## Границы и частые ошибки

break внутри внутреннего цикла закончит только текущий ряд, а внешний продолжится. Для большой таблицы надо учитывать объём результата, даже если код короткий.
