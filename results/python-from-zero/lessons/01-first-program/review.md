# Проверка урока 01

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: Никаких знаний программирования не требуется.

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Показать две строки: сообщение о начале учёбы и название языка. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Сохранить файл Python, запустить его и отличить код от результата. |
| Сквозной пример | Первый пример main: Два последовательных действия без ввода. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: Выполнить следующий print после первого; результат: Ниже появляется: Python |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | Python выполняет эти команды сверху вниз. Каждая команда по умолчанию заканчивает свою строку вывода. Если поменять команды местами, поменяется и порядок сообщений. Цвета в редакторе помогают читать код, но не являются частью программы. |
| Корректность | Два требуемых действия записаны в нужном порядке, поэтому результат совпадает с заданием. Количество команд фиксировано; выводятся только два коротких сообщения, дополнительного хранения данных нет. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: Нет ввода и вычислений. Добавление новой строки вывода требует новой команды. Если окно закрывается сразу после запуска двойным щелчком, запускайте через редактор, чтобы успеть прочитать результат.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
