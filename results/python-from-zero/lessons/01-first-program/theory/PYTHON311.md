# 01. Что такое программа и как её запустить

После урока вы сможете: Сохранить файл Python, запустить его и отличить код от результата.

Нужные знания: Никаких знаний программирования не требуется.

## От задачи к способу решения

Программирование начинается с точного описания действий. Представьте просьбу «приготовь чай». Человек сам догадается взять чашку, но программе нужны конкретные команды. **Алгоритм** — понятная последовательность шагов для получения результата. **Программа** — запись этих шагов на языке, который умеет исполнять компьютер. Python — один из таких языков. **Интерпретатор** — программа, которая выполняет команды Python.

Пока достаточно следующей картины: вы пишете текст → сохраняете его в файл → запускаете Python → видите результат. Текст программы называется **исходным кодом**. Результат на экране называется **выводом**. Написанная в редакторе строка ещё не означает, что компьютер её выполнил.

### Подготовьте место для работы

Откройте [официальную страницу Python](https://www.python.org/downloads/), выберите Python 3 для своей системы и установите его. Номер Python 3 может отличаться от номера в примерах; в этом курсе нет возможностей новее Python 3.11. В Windows можно включить пункт добавления Python в PATH, если установщик его предлагает. Он нужен для запуска из терминала, но для первого урока хватит IDLE. В macOS установщик с python.org обычно включает IDLE. В Linux IDLE иногда устанавливается отдельным пакетом средствами системы. Не нужно менять системный Python.

Найдите приложение IDLE. Его окно **Shell** показывает приглашение `>>>`: это место для немедленного выполнения отдельных команд. Через File → New File откройте другое окно — редактор. Вставьте туда программу ниже. Сохраните файл с именем `first.py` в отдельную папку учебных работ. Расширение `.py` помогает узнать файл программы Python. Выберите Run → Run Module; обычное сочетание клавиш — F5. Результат появится в Shell.

Если Python уже доступен в вашем учебном редакторе, создайте там файл `.py` и воспользуйтесь кнопкой запуска. В терминале из папки файла можно выполнить `python3 first.py`; в Windows часто используется `py first.py`. Терминал — окно для команд операционной системе. Эти команды запуска не надо вставлять внутрь файла Python.

### Первая команда

`print` означает «вывести». Скобки содержат то, что нужно показать. Текст в кавычках называется **строкой**. Кавычки обозначают границы текста и сами не печатаются. В примерах используются обычные прямые кавычки, а не типографские «ёлочки».

Хотим получить два сообщения. На бумаге алгоритм состоит из двух действий: вывести первое сообщение, затем второе. Две команды `print` записывают именно этот алгоритм. Здесь не нужно понимать все возможности `print`: сначала научимся запускать небольшой понятный файл.

## Задача и формат данных

Показать две строки: сообщение о начале учёбы и название языка.

**Ввод:** Ввод не требуется.

**Вывод:** Две строки в указанном порядке.

**Допустимые данные:** Никаких исходных данных нет.

Вход сквозного примера — пустой, программа не запрашивает данные:

```text

```

Ожидаемый вывод:

```text
Я начинаю учиться
Python
```

## Полная программа

```python
print('Я начинаю учиться')
print('Python')
```

## Как читать реализацию

Python выполняет эти команды сверху вниз. Каждая команда по умолчанию заканчивает свою строку вывода. Если поменять команды местами, поменяется и порядок сообщений. Цвета в редакторе помогают читать код, но не являются частью программы.

Не копируйте `>>>` в файл: это приглашение Shell. Если в Shell показана ошибка, сравните файл с двумя строками образца: кавычки должны быть парными, скобки — закрытыми. После изменения сохраните файл и запустите его заново. Результат предыдущего запуска сам не обновится.

## Почему работает и сколько действий требуется

Два требуемых действия записаны в нужном порядке, поэтому результат совпадает с заданием. Количество команд фиксировано; выводятся только два коротких сообщения, дополнительного хранения данных нет.

## Границы и частые ошибки

Нет ввода и вычислений. Добавление новой строки вывода требует новой команды. Если окно закрывается сразу после запуска двойным щелчком, запускайте через редактор, чтобы успеть прочитать результат.
