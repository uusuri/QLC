# Проверка урока 23

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: Индексы строк, if и len

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Определить, одинаково ли читается строка слева направо и справа налево. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Получать часть строки и понимать исключённую правую границу. |
| Сквозной пример | Первый пример main: Нечётный палиндром. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: Все символы и порядок совпали; результат: ДА |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | reversed_text содержит обратную запись, а == сравнивает значения строк. Неизменяемость исходной строки сохраняется: срез не переставляет её символы на месте. Отдельное имя помогает увидеть обе записи перед сравнением. |
| Корректность | Строка является палиндромом по определению ровно тогда, когда равна обратной. Создание среза и сравнение требуют не больше L шагов для длины L. Хранится исходный текст и до L символов новой строки; дополнительная память линейна. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: Срез копирует нужное содержание и не становится бесплатным из-за короткой записи. Если памяти мало, пары можно сравнивать без полной обратной строки, но в этом диапазоне срез удобен.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
