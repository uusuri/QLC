# 23. Срезы и проверка палиндрома

После урока вы сможете: Получать часть строки и понимать исключённую правую границу.

Нужные знания: Индексы строк, if и len

## От задачи к способу решения

**Срез** получает последовательную часть строки. Запись `text[start:stop]` берёт позиции от start включительно до stop не включительно. У строки Python срез [1:4] даёт yth: индексы 1, 2, 3. Позиция 4 уже за правой границей. Это такое же соглашение, как у range.

Если начало пропущено, берётся начало строки: text[:3]. Если конец пропущен, берётся остаток: text[3:]. Эти части вместе дают всю строку, без повторения позиции 3. text[:] даёт полную строку по значению.

Третья часть после второго двоеточия — шаг: `text[::2]` берёт каждый второй символ начиная с нулевого. `text[::-1]` проходит строку в обратном направлении и даёт перевёрнутую запись. При отрицательном шаге пропущенные границы подбираются для движения от конца к началу. Шаг 0 запрещён.

Срез за пределами строки обычно безопасно ограничивается её длиной: text[:100] у короткой строки даёт всю строку. Прямой индекс text[100] требует существующего элемента и вызвал бы ошибку. Это разные операции: пустая часть допустима, несуществующий отдельный элемент — нет.

**Палиндром** — строка, равная своей обратной записи. У топот крайние буквы совпадают, затем совпадают вторые, середина остаётся сама собой. Прямой способ — проверять пары индексов с концов. В Python та же идея коротко выражается сравнением text с text[::-1]. Мы создаём всю обратную запись и проверяем полное равенство.

Правила сравнения важны. Топот с заглавной Т не равен своей обратной записи топоТ, если регистр значим. Пробелы тоже сравниваются. В этой задаче не надо автоматически удалять знаки или менять регистр. Пустая строка равна своей обратной пустой строке, поэтому получает ДА.

## Задача и формат данных

Определить, одинаково ли читается строка слева направо и справа налево.

**Ввод:** Одна строка.

**Вывод:** ДА либо НЕТ.

**Допустимые данные:** До 1000 символов; регистр, пробелы и знаки считаются значимыми; пустая строка считается палиндромом.

Вход сквозного примера:

```text
топот
```

Ожидаемый вывод:

```text
ДА
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | Прочитать исходную последовательность | text = топот |
| 2 | Взять срез с шагом -1 | reversed_text = топот |
| 3 | Все символы и порядок совпали | ДА |

## Полная программа

```python
text = input()
reversed_text = text[::-1]
if text == reversed_text:
    print('ДА')
else:
    print('НЕТ')
```

## Как читать реализацию

reversed_text содержит обратную запись, а == сравнивает значения строк. Неизменяемость исходной строки сохраняется: срез не переставляет её символы на месте. Отдельное имя помогает увидеть обе записи перед сравнением.

## Почему работает и сколько действий требуется

Строка является палиндромом по определению ровно тогда, когда равна обратной. Создание среза и сравнение требуют не больше L шагов для длины L. Хранится исходный текст и до L символов новой строки; дополнительная память линейна.

## Границы и частые ошибки

Срез копирует нужное содержание и не становится бесплатным из-за короткой записи. Если памяти мало, пары можно сравнивать без полной обратной строки, но в этом диапазоне срез удобен.
