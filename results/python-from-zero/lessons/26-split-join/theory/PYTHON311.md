# 26. Разбиваем текст на слова: split и join

После урока вы сможете: Получить список частей строки и соединить его с новым разделителем.

Нужные знания: Строковые методы, for и len

## От задачи к способу решения

Чтобы работать со словами отдельно, нужно получить несколько элементов из одной строки. `text.split()` разбивает её по пробельным символам и возвращает **список** строк. Список — упорядоченная коллекция элементов. Пока достаточно понять, что у него есть длина и его можно пройти циклом; изменение списков изучим в следующих уроках.

Для строки с внешними и двойными пробелами «  учим  Python вместе  » результат — три элемента: 'учим', 'Python', 'вместе'. split без аргумента объединяет соседние пробельные разделители и не оставляет пустые элементы на краях. Если текст только из пробелов, получится пустой список.

`text.split(',')` работает иначе: разделяет по конкретной запятой, сохраняя пустые части. Например, 'a,,b'.split(',') даёт 'a', '', 'b'. Пустой текст с явным разделителем даёт один пустой элемент. Поэтому выбирайте вызов по формату, а не по привычке.

Обратная операция **join** соединяет строковые элементы. Запись `'-'.join(words)` читается так: соединить элементы words, вставляя '-' между соседними. Метод вызывается через разделитель. Он не добавляет дефис в начале или конце. Все элементы должны быть строками; список целых сначала нужно преобразовать, что разберём при вводе списков.

Получив words, используем len(words) для количества. В программе нет отдельного ручного счётчика: операция len уже хранит нужный размер списка. Затем join строит новый текст. Внутренние знаки препинания остаются частью слова: 'кот,' — один элемент с запятой. Мы не решаем лингвистический разбор, а выполняем точно заданное деление по пробелам.

Для одного слова join вернёт его без разделителей; для пустого списка — пустую строку. Поэтому ответ всегда печатается двумя строками: во второй может не быть символов, но команда print добавит перенос строки. Эта договорённость важна для проверки пустого ввода.

## Задача и формат данных

Подсчитать слова и соединить их дефисами, игнорируя лишние пробелы.

**Ввод:** Одна строка.

**Вывод:** Количество слов первой строкой, слова через дефис второй.

**Допустимые данные:** До 1000 символов; словом считается непустая часть между пробельными символами.

Вход сквозного примера:

```text
  учим  Python вместе  
```

Ожидаемый вывод:

```text
3
учим-Python-вместе
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | Разделить вход по пробельным границам | words = [учим, Python, вместе] |
| 2 | Посчитать элементы списка | len(words) = 3 |
| 3 | Вставить дефис между соседними элементами | учим-Python-вместе |

## Полная программа

```python
text = input()
words = text.split()
print(len(words))
print('-'.join(words))
```

## Как читать реализацию

text — исходный текст, words — список частей. join работает с частями, а не с исходными промежутками, поэтому лишние пробелы исчезают. Временный список нужен, чтобы повторно использовать выделенные слова для количества и соединения.

## Почему работает и сколько действий требуется

split даёт ровно непустые части по оговорённому правилу, len считает их, join вставляет один дефис на каждую границу между словами. Чтение, разбиение и соединение линейны по общей длине текста; память для списка частей и результата тоже линейна.

## Границы и частые ошибки

При явном разделителе пустые элементы меняют смысл результата. join не принимает целые элементы автоматически. Слово в этом упражнении определено форматом, а не словарём русского языка.
