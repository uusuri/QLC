# 26. Разбиваем текст на слова: split и join: ответы

## Задание 1

Первый даёт ['a', 'b']; второй ['a', '', 'b'], потому что каждое вхождение явного пробела разделяет отдельно.

## Задание 2

кот и пустую строку. Разделитель появляется только между элементами.

## Задание 3

Разделяем именно по запятой и сохраняем пустые элементы.

```python
text = input()
parts = text.split(',')
for part in parts:
    print(part)
```

## Задание 4

Срез разворачивает список слов, join соединяет новый порядок.

```python
words = input().split()
print(' '.join(words[::-1]))
```
