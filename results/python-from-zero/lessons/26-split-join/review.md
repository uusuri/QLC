# Проверка урока 26

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: Строковые методы, for и len

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Подсчитать слова и соединить их дефисами, игнорируя лишние пробелы. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Получить список частей строки и соединить его с новым разделителем. |
| Сквозной пример | Первый пример main: Повторные пробелы. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: Вставить дефис между соседними элементами; результат: учим-Python-вместе |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | text — исходный текст, words — список частей. join работает с частями, а не с исходными промежутками, поэтому лишние пробелы исчезают. Временный список нужен, чтобы повторно использовать выделенные слова для количества и соединения. |
| Корректность | split даёт ровно непустые части по оговорённому правилу, len считает их, join вставляет один дефис на каждую границу между словами. Чтение, разбиение и соединение линейны по общей длине текста; память для списка частей и результата тоже линейна. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: При явном разделителе пустые элементы меняют смысл результата. join не принимает целые элементы автоматически. Слово в этом упражнении определено форматом, а не словарём русского языка.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
