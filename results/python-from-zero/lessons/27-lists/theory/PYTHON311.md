# 27. Списки: создаём и храним несколько значений

После урока вы сможете: Прочитать список чисел и повторно использовать все элементы.

Нужные знания: split, индексы и циклы

## От задачи к способу решения

В сумме можно забывать старые значения. Но для обратного вывода нужны все числа: последнее выводится первым, а первое — последним. Поэтому сохраняем коллекцию целиком. **Список**, тип list, хранит упорядоченные элементы; пример литерала — `[3, 1, 4]`. **Литерал** — запись значения прямо в коде. Пустой список записывается `[]`.

`numbers.append(value)` добавляет один элемент в конец списка. Создадим пустой numbers, затем n раз прочитаем число и добавим его. Через три шага на входе 3, −1, 5 получаем [3, −1, 5]. Порядок совпадает с порядком ввода.

Список поддерживает знакомые len, индексы с нуля, отрицательные индексы и срезы. numbers[::-1] даёт новый список в обратном порядке. `sum(numbers)` получает сумму числовых элементов, а sum([]) равна нулю. `min(numbers)` и `max(numbers)` требуют непустого списка, если отдельно не задано поведение для пустого.

Для вывода через пробел удобно сначала получить текстовые части. Создадим пустой parts, пройдём обратный список, добавим `str(value)` для каждого числа и вызовем `' '.join(parts)`. Этот способ использует уже известные операции. Вывод самого списка через print(numbers) выглядел бы как `[3, -1, 5]`, со скобками и запятыми; это иной формат.

Ещё один способ — `print(*numbers)`: звёздочка в таком вызове передаёт каждый элемент как отдельный аргумент. Для пустого списка печатается пустая строка. Это распаковка аргументов, а не умножение; смысл зависит от места знака. В основной реализации пока оставим явное преобразование, чтобы связь типов была видна.

Список может хранить значения разных типов, но для числовой суммы держим в нём только int. Разнородный список не делает автоматически допустимыми сложение или сортировку его элементов. Выберите понятный контракт для содержимого своей коллекции.

## Задача и формат данных

Прочитать n чисел, затем вывести их количество, сумму и обратный порядок.

**Ввод:** n первой строкой, затем n целых чисел отдельными строками.

**Вывод:** Количество и сумма через пробел первой строкой; числа в обратном порядке через пробел второй строкой.

**Допустимые данные:** 0 <= n <= 1000; элементы от −10000 до 10000.

Вход сквозного примера:

```text
3
3
-1
5
```

Ожидаемый вывод:

```text
3 7
5 -1 3
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 0 | До чтения список пуст | numbers = [] |
| 1 | append первого числа | numbers = [3] |
| 2 | append следующего числа | numbers = [3, -1] |
| 3 | append последнего числа | numbers = [3, -1, 5] |
| 4 | Сумма 7; обратные текстовые части 5, -1, 3 | Вывод: 3 7 и 5 -1 3 |

## Полная программа

```python
n = int(input())
numbers = []
for i in range(n):
    numbers.append(int(input()))
print(len(numbers), sum(numbers))
parts = []
for value in numbers[::-1]:
    parts.append(str(value))
print(' '.join(parts))
```

## Как читать реализацию

numbers хранит числа, parts — строки для вывода. Обратный срез создаёт дополнительную коллекцию; исходный порядок не меняется. Метод append меняет список и возвращает None — отсутствие полезного возвращаемого значения. Не пишите numbers = numbers.append(value): так имя numbers перестанет обозначать список.

## Почему работает и сколько действий требуется

Все n значений добавляются по одному и сохраняются в порядке ввода; срез разворачивает именно эту последовательность. Чтение, суммирование и преобразование проходят элементы по одному. Работа и суммарная память линейны по n при данных ограниченных размерах чисел; копия среза и текстовые части тоже учтены.

## Границы и частые ошибки

Хранение всего ввода нужно для обратного порядка, но излишне для одной суммы. Не считайте срез бесплатным: он добавляет память для n ссылок на элементы.
