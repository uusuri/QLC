# Проверка урока 27

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: split, индексы и циклы

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Прочитать n чисел, затем вывести их количество, сумму и обратный порядок. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Прочитать список чисел и повторно использовать все элементы. |
| Сквозной пример | Первый пример main: Повторное использование. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: Сумма 7; обратные текстовые части 5, -1, 3; результат: Вывод: 3 7 и 5 -1 3 |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | numbers хранит числа, parts — строки для вывода. Обратный срез создаёт дополнительную коллекцию; исходный порядок не меняется. Метод append меняет список и возвращает None — отсутствие полезного возвращаемого значения. Не пишите numbers = numbers.append(value): так имя numbers перестанет обозначать список. |
| Корректность | Все n значений добавляются по одному и сохраняются в порядке ввода; срез разворачивает именно эту последовательность. Чтение, суммирование и преобразование проходят элементы по одному. Работа и суммарная память линейны по n при данных ограниченных размерах чисел; копия среза и текстовые части тоже учтены. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: Хранение всего ввода нужно для обратного порядка, но излишне для одной суммы. Не считайте срез бесплатным: он добавляет память для n ссылок на элементы.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
