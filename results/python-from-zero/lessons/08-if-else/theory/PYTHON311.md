# 08. Сравнения и выбор: if и else

После урока вы сможете: Выполнять одно из двух действий в зависимости от условия.

Нужные знания: Целые числа, ввод и вывод

## От задачи к способу решения

До сих пор каждый запуск выполнял одни и те же команды. Теперь действие зависит от данных. **Условие** — вопрос с двумя результатами: истина или ложь. Выражение `amount >= 1000` спрашивает, не меньше ли сумма тысячи. Python представляет ответ значениями `True` и `False`; их тип называется `bool`.

Сравнения записываются так: `==` равно, `!=` не равно, `<` меньше, `>` больше, `<=` не больше, `>=` не меньше. Знак `=` присваивает значение, а `==` сравнивает. При выборе бесплатной доставки важен знак `>=`: заказ ровно на 1000 подходит. Проверка только `>` потеряет граничный случай.

`if` означает «если». После условия ставится двоеточие. Команды выбранного действия идут ниже с отступом, обычно четыре пробела. **Блок** — несколько команд с одним уровнем отступа, относящихся к одной конструкции. Если условие истинно, выполняется блок if. `else` означает «иначе» и содержит действие для ложного условия. У else нет собственного условия.

Отступ — часть смысла Python. Команда без отступа после двух ветвей выполняется независимо от выбора. Отступы удобнее ставить средствами редактора; не смешивайте табуляцию и пробелы. Ошибка IndentationError просит проверить структуру блоков.

Решаем задачу сначала словами: прочитать сумму; если она не меньше тысячи — сказать БЕСПЛАТНО; в остальных случаях — ПЛАТНО. Не нужны два независимых if: условие либо верно, либо неверно, и эти случаи полностью покрывает if/else.

Проверьте на 1200: условие истинно, выполняется первая ветвь. На 999 оно ложно, выполняется вторая. На 1000 нужно попасть в первую: это следует из слова «включительно», а не из случайного примера. Значения True и False можно отдельно вывести через print, но ответ задачи требует слов, поэтому печатаем их в нужной ветви.

## Задача и формат данных

Бесплатная доставка положена при сумме заказа от 1000 рублей включительно.

**Ввод:** Целая сумма заказа одной строкой.

**Вывод:** БЕСПЛАТНО либо ПЛАТНО.

**Допустимые данные:** Сумма от 0 до 100000.

Вход сквозного примера:

```text
1200
```

Ожидаемый вывод:

```text
БЕСПЛАТНО
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | Прочитать сумму | amount = 1200 |
| 2 | Проверить 1200 >= 1000 | True |
| 3 | Выбрать блок if, потому что условие истинно | БЕСПЛАТНО |

## Полная программа

```python
amount = int(input())
if amount >= 1000:
    print('БЕСПЛАТНО')
else:
    print('ПЛАТНО')
```

## Как читать реализацию

amount хранит сумму. Сравнение возвращает логическое значение. Python выполняет только соответствующий блок: в одном запуске не будут напечатаны оба ответа. Даже если в блоке несколько команд, все они подчиняются одному условию.

## Почему работает и сколько действий требуется

Заказ либо достигает порога, либо нет; других случаев не существует. Знак >= включает сам порог. Одно сравнение и один вывод завершаются после фиксированного числа действий; объём состояния постоянен.

## Границы и частые ошибки

Изменение порога требует заменить число в сравнении. Если бесплатность зависит ещё и от города, одного сравнения недостаточно: нужно составное условие.
