## Задание 3

Проверяем остаток, а не результат обычного деления.

```python
number = int(input())
if number % 2 == 0:
    print('ЧЁТНОЕ')
else:
    print('НЕЧЁТНОЕ')
```

## Задание 4

При равенстве подходит любое из двух значений.

```python
a = int(input())
b = int(input())
if a >= b:
    print(a)
else:
    print(b)
```
