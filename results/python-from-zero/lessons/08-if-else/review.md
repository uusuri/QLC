# Проверка урока 08

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: Целые числа, ввод и вывод

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Бесплатная доставка положена при сумме заказа от 1000 рублей включительно. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Выполнять одно из двух действий в зависимости от условия. |
| Сквозной пример | Первый пример main: Истинная ветвь. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: Выбрать блок if, потому что условие истинно; результат: БЕСПЛАТНО |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | amount хранит сумму. Сравнение возвращает логическое значение. Python выполняет только соответствующий блок: в одном запуске не будут напечатаны оба ответа. Даже если в блоке несколько команд, все они подчиняются одному условию. |
| Корректность | Заказ либо достигает порога, либо нет; других случаев не существует. Знак >= включает сам порог. Одно сравнение и один вывод завершаются после фиксированного числа действий; объём состояния постоянен. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: Изменение порога требует заменить число в сравнении. Если бесплатность зависит ещё и от города, одного сравнения недостаточно: нужно составное условие.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
