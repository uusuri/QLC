# 06. Целое деление, остаток и цифры

После урока вы сможете: Разделить количество на полные группы и остаток.

Нужные знания: Целые числа и арифметические выражения

## От задачи к способу решения

Пусть прошло 135 минут. Полных часов два: 60 + 60 = 120. Остаются 15 минут. Обычное деление даёт 2.25, но для записи часов и минут нужны две отдельные величины. Операция `//` получает целую часть деления с округлением вниз, операция `%` — остаток.

Для неотрицательного количества `minutes // 60` показывает, сколько полных групп по 60 помещается. `minutes % 60` показывает, сколько осталось после этих групп. Проверка результата: `hours * 60 + rest` должно вернуть исходное количество, а rest находится от 0 до 59. Такая связь объясняет обе операции, а не только помогает запомнить знаки.

При 59 минутах полных часов ещё нет, при 60 остаток равен нулю, при 61 остаток один. Именно эти границы отличают правильное решение от округления к ближайшему числу. Если написать `round(minutes / 60)`, можно ошибочно получить час уже при 59 минутах. Нам нужны полностью прошедшие часы.

Деление на ноль не имеет результата: Python сообщит ZeroDivisionError. Для отрицательных чисел «округление вниз» означает движение к меньшему целому: `-7 // 3` равно −3, а `-7 % 3` равно 2. Проверка связи остаётся верной: −3 * 3 + 2 = −7. Пока в задаче минуты неотрицательны, но нельзя переносить фразу «отбрасывает дробь» на все значения.

Эти операции позволяют извлекать десятичные цифры. Для неотрицательного целого последняя цифра — `number % 10`, число без последней цифры — `number // 10`. У 472 получаем 2 и 47. Цифра десятков — `(number // 10) % 10`: сначала убрать единицы, затем взять последнюю цифру оставшегося числа. Это не работа с текстом, а разбиение на полные десятки и остаток.

Извлечение фиксированного числа цифр подходит, когда размер числа известен. Перебор всех цифр числа произвольной длины потребует повторения — цикла. До него не будем придумывать неизвестные конструкции.

## Задача и формат данных

Перевести количество минут в полные часы и оставшиеся минуты.

**Ввод:** Одно целое число — количество минут.

**Вывод:** Два целых числа через пробел: часы и минуты.

**Допустимые данные:** От 0 до 1000000 минут.

Вход сквозного примера:

```text
135
```

Ожидаемый вывод:

```text
2 15
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | Прочитать общее количество | minutes = 135 |
| 2 | Отделить полные группы по 60 | hours = 2 |
| 3 | Взять остаток после двух групп | rest = 15 |
| 4 | Проверить: 2 * 60 + 15 = 135 | Вывод: 2 15 |

## Полная программа

```python
minutes = int(input())
hours = minutes // 60
rest = minutes % 60
print(hours, rest)
```

## Как читать реализацию

В hours хранится число целых часов, в rest — число оставшихся минут. Вывод одного print разделяет их пробелом. Не используйте остаток как дробную долю часа: 15 минут здесь четверть часа, а не 0.15 часа.

## Почему работает и сколько действий требуется

Для каждого допустимого количества деление на 60 выделяет полные часы, остаток сохраняет непройденную часть часа. Число операций фиксировано, сохраняем три небольших целых.

## Границы и частые ошибки

Для перевода в сутки добавляется ещё одно разбиение: сутки = minutes // 1440, а внутри суток остаётся minutes % 1440 минут. Правила для отрицательного времени в этой задаче не определены.
