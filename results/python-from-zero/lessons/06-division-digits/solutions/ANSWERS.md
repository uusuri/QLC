## Задание 3

Сотни получаем делением на 100, десятки — после удаления единиц, единицы — остатком.

```python
number = int(input())
hundreds = number // 100
tens = number // 10 % 10
ones = number % 10
print(hundreds + tens + ones)
```

## Задание 4
