# Проверка урока 06

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: Целые числа и арифметические выражения

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Перевести количество минут в полные часы и оставшиеся минуты. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Разделить количество на полные группы и остаток. |
| Сквозной пример | Первый пример main: Две группы и остаток. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: Проверить: 2 * 60 + 15 = 135; результат: Вывод: 2 15 |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | В hours хранится число целых часов, в rest — число оставшихся минут. Вывод одного print разделяет их пробелом. Не используйте остаток как дробную долю часа: 15 минут здесь четверть часа, а не 0.15 часа. |
| Корректность | Для каждого допустимого количества деление на 60 выделяет полные часы, остаток сохраняет непройденную часть часа. Число операций фиксировано, сохраняем три небольших целых. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: Для перевода в сутки добавляется ещё одно разбиение: сутки = minutes // 1440, а внутри суток остаётся minutes % 1440 минут. Правила для отрицательного времени в этой задаче не определены.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
