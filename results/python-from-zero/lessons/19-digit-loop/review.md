# Проверка урока 19

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: while, //, %, накопители

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Для неотрицательного целого найти сумму цифр и их количество. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Обрабатывать все десятичные цифры и не забыть случай нуля. |
| Сквозной пример | Первый пример main: Нулевая цифра внутри. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: Извлечь 4; больше цифр нет; результат: remaining = 0, digit_sum = 11, digit_count = 3 |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | После //= 10 рабочая часть становится короче на один десятичный разряд. Количество увеличивается даже при digit = 0. Начальный digit_count = 1 ставится только для самого числа 0, а не для всех чисел с нулевыми цифрами. |
| Корректность | Каждая цифра извлекается ровно один раз, поэтому накопители содержат требуемые характеристики. Положительная remaining уменьшается и становится нулевой. Для d цифр требуется d итераций; в указанном диапазоне d <= 19. Хранится постоянное число переменных; за пределами диапазона стоимость операций над огромными int тоже растёт. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: Ведущие нули теряются при преобразовании в int. Если ввод 007 должен иметь три символа, это задача о строке, а не о целочисленной записи.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
