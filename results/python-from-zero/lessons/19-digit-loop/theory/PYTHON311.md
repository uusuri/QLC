# 19. Цикл по цифрам числа

После урока вы сможете: Обрабатывать все десятичные цифры и не забыть случай нуля.

Нужные знания: while, //, %, накопители

## От задачи к способу решения

Для трёхзначного числа мы извлекали ровно три цифры отдельными выражениями. Теперь число может быть любой разрешённой длины. Повторяющийся шаг уже знаком: последняя цифра — остаток на 10, оставшаяся часть — целое деление на 10. Цикл заменяет запись одного выражения для каждого разряда.

Пусть number = 407. `407 % 10` даёт 7, затем `407 // 10` оставляет 40. На следующем шаге цифра 0, остаток числа 4. На третьем цифра 4, остаток 0. Дальше цифр не осталось. Порядок получается справа налево, но для суммы и количества он не важен.

Храним `remaining` — ещё не обработанную часть, `digit_sum` — сумму уже извлечённых цифр и `digit_count` — их количество. На каждом шаге сначала извлекаем digit, затем прибавляем его, увеличиваем количество и удаляем последний разряд из remaining. Если разделить remaining до получения digit, потеряем ещё не обработанную последнюю цифру.

Случай number = 0 требует внимания. Его десятичная запись содержит одну цифру 0. Но while remaining > 0 при нуле не выполнится. Поэтому отдельно устанавливаем digit_count = 1, сумма остаётся 0. Это правило вытекает из записи числа, а не из желания избежать неудобного теста.

Начальный number сохраняем, потому что remaining разрушительно уменьшается. Если позже понадобится вывести исходное число, оно доступно. Такой приём полезен всякий раз, когда алгоритм меняет рабочую копию значения.

Обрабатывать отрицательное число тем же циклом нельзя: условие > 0 сразу остановится. Если задача разрешит отрицательные числа и попросит цифры модуля без знака, можно начать с abs(number). Сначала следует сформулировать договорённость о знаке. В нашем условии отрицательных значений нет.

## Задача и формат данных

Для неотрицательного целого найти сумму цифр и их количество.

**Ввод:** Одно целое число.

**Вывод:** Сумма цифр и число цифр через пробел.

**Допустимые данные:** 0 <= number <= 10**18.

Вход сквозного примера:

```text
407
```

Ожидаемый вывод:

```text
11 3
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 0 | Ещё ни одна цифра не обработана | remaining = 407, digit_sum = 0, digit_count = 0 |
| 1 | Извлечь 7, прибавить и удалить разряд | remaining = 40, digit_sum = 7, digit_count = 1 |
| 2 | Нулевая цифра тоже считается | remaining = 4, digit_sum = 7, digit_count = 2 |
| 3 | Извлечь 4; больше цифр нет | remaining = 0, digit_sum = 11, digit_count = 3 |

## Полная программа

```python
number = int(input())
remaining = number
digit_sum = 0
digit_count = 0
if remaining == 0:
    digit_count = 1
while remaining > 0:
    digit = remaining % 10
    digit_sum += digit
    digit_count += 1
    remaining //= 10
print(digit_sum, digit_count)
```

## Как читать реализацию

После //= 10 рабочая часть становится короче на один десятичный разряд. Количество увеличивается даже при digit = 0. Начальный digit_count = 1 ставится только для самого числа 0, а не для всех чисел с нулевыми цифрами.

## Почему работает и сколько действий требуется

Каждая цифра извлекается ровно один раз, поэтому накопители содержат требуемые характеристики. Положительная remaining уменьшается и становится нулевой. Для d цифр требуется d итераций; в указанном диапазоне d <= 19. Хранится постоянное число переменных; за пределами диапазона стоимость операций над огромными int тоже растёт.

## Границы и частые ошибки

Ведущие нули теряются при преобразовании в int. Если ввод 007 должен иметь три символа, это задача о строке, а не о целочисленной записи.
