# Проверка урока 37

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: Цифры числа, while, индексы и функции

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Перевести неотрицательное десятичное целое в основание от 2 до 16. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Объяснить позиционную запись и построить представление в другом основании. |
| Сквозной пример | Первый пример main: Четыре двоичных разряда. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: Развернуть младшие цифры в привычный порядок; результат: 1101 |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | remaining хранит часть, ещё не разобранную на разряды. parts хранит символы младших цифр сначала. Обратный срез меняет порядок, join убирает границы между частями. digits — таблица соответствия значений цифр их записи, её размер фиксирован. |
| Корректность | На каждом шаге remaining = quotient * base + remainder. Остаток задаёт правильную младшую цифру, а quotient — остальные разряды. Повторение извлекает все цифры. При base >= 2 положительное remaining уменьшается и достигнет нуля. Для d цифр работа и дополнительная память пропорциональны d; d растёт примерно как логарифм number по основанию base. Это оценка для указанного диапазона обычных целых. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: Отрицательные числа исключены; для них пришлось бы отдельно оформить знак и переводить модуль. Формат вывода требует заглавные A–F и не включает префиксы 0b или 0x.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
