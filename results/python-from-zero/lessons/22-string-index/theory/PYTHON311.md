# 22. Строка как последовательность: длина и индексы

После урока вы сможете: Получать символ по позиции и безопасно работать с пустой строкой.

Нужные знания: Строки, for, if и input

## От задачи к способу решения

Строка — не только текст целиком, но и упорядоченная последовательность символов. **Индекс** — номер позиции в этой последовательности. В Python первая позиция имеет индекс 0. У слова кот: индекс 0 — к, индекс 1 — о, индекс 2 — т. Последний положительный индекс на единицу меньше длины.

`len(text)` возвращает длину, `text[0]` — первый символ. Квадратные скобки после имени обращаются к элементу по индексу; круглые скобки используются для вызова функции. Отрицательные индексы считают с конца: `text[-1]` — последний, `text[-2]` — предпоследний. Минус ноль не новый индекс: `text[-0]` то же, что text[0].

У пустой строки длина 0 и нет первого символа. Обращение text[0] или text[-1] вызовет IndexError. Поэтому сначала проверяем length > 0. Для строки из одного символа первый и последний символ совпадают; это правильный результат, а не ошибка.

Можно пройти символы напрямую: `for character in text:`. На каждой итерации character получает строку длины один. Отдельного типа для одиночного символа в Python нет. Если нужен номер, используйте `for index in range(len(text)):` и берите text[index]. Прямой перебор короче, когда позиции не используются.

Строки **неизменяемы**: text[0] = 'К' не исправит первый символ. Для нового текста нужно создать новое строковое значение и при необходимости присвоить его переменной. Переприсваивание имени разрешено; изменение символа внутри существующего строкового значения — нет. Именно поэтому сравнивайте действие с объектом и действие с именем.

len считает кодовые точки Unicode, а не байты файла и не всегда визуальные значки. Обычная кириллическая буква в примерах курса — один элемент строки. Некоторые эмодзи и буквы с отдельно записанным ударением состоят из нескольких кодовых точек. Не считайте len универсальным счётчиком видимых символов.

## Задача и формат данных

Вывести длину строки; для непустой строки также первый и последний символы.

**Ввод:** Одна строка, возможно пустая.

**Вывод:** Длина первой строкой. Если строка непустая, её первый и последний символы через пробел второй строкой.

**Допустимые данные:** От 0 до 100 символов.

Вход сквозного примера:

```text
кот
```

Ожидаемый вывод:

```text
3
к т
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | Прочитать кот как строку | text = кот |
| 2 | Посчитать три позиции | length = 3 |
| 3 | Строка непустая: индексы допустимы | text[0] = к, text[-1] = т |

## Полная программа

```python
text = input()
length = len(text)
print(length)
if length > 0:
    print(text[0], text[-1])
```

## Как читать реализацию

Первый print выполняется для любого текста, а второй защищён проверкой длины. Пробелы из input являются символами строки: они тоже влияют на len и могут быть крайними элементами. В этой задаче не надо удалять их автоматически.

## Почему работает и сколько действий требуется

len задаёт длину, а выбранные индексы обозначают именно края непустой строки. При пустой строке опасная ветвь не выполняется. Чтение и хранение строки длины L требуют работы и памяти, пропорциональных L; операции len и получения одного элемента для str выполняются за постоянное время.

## Границы и частые ошибки

Индекс len(text) выходит за допустимую границу. Для пустой строки не существует даже отрицательного последнего индекса. Различие видимого символа и кодовой точки важно для сложного Unicode.
