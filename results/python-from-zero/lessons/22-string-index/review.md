# Проверка урока 22

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: Строки, for, if и input

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Вывести длину строки; для непустой строки также первый и последний символы. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Получать символ по позиции и безопасно работать с пустой строкой. |
| Сквозной пример | Первый пример main: Кириллица. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: Строка непустая: индексы допустимы; результат: text[0] = к, text[-1] = т |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | Первый print выполняется для любого текста, а второй защищён проверкой длины. Пробелы из input являются символами строки: они тоже влияют на len и могут быть крайними элементами. В этой задаче не надо удалять их автоматически. |
| Корректность | len задаёт длину, а выбранные индексы обозначают именно края непустой строки. При пустой строке опасная ветвь не выполняется. Чтение и хранение строки длины L требуют работы и памяти, пропорциональных L; операции len и получения одного элемента для str выполняются за постоянное время. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: Индекс len(text) выходит за допустимую границу. Для пустой строки не существует даже отрицательного последнего индекса. Различие видимого символа и кодовой точки важно для сложного Unicode.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
