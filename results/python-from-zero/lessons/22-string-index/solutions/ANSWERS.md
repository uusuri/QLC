## Задание 4

У нечётной длины индекс середины равен length // 2. Проверяем чётность до обращения.

```python
text = input()
length = len(text)
if length % 2 == 1:
    print(text[length // 2])
else:
    print('ДВА СРЕДНИХ')
```
