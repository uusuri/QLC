# Проверка урока 34

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: Функции, return, for и сравнения

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Провести игру с ограничением попыток и подсказками относительно секретного числа. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Соединить игровой цикл, подсказки и несколько способов завершения. |
| Сквозной пример | Первый пример main: Победа на последней попытке. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: 11 совпадает: return завершает игру; результат: УГАДАНО 3 |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | secret не меняется в play; attempt меняется по for. Успешный return пропускает не только остаток итерации, но и сообщение после цикла. Один break завершил бы цикл, но не пропустил сообщение после него. Для варианта с break нужен отдельный способ различить победу и исчерпание попыток, например флаг или проверка результата последней догадки. |
| Корректность | Каждая догадка относится к одному из трёх случаев относительно неизменного секрета. Победа заканчивает функцию, а конечный диапазон ограничивает число промахов. Не больше t попыток, значит работа пропорциональна t, служебная память постоянна. Случайное начальное число не меняет корректность сравнения. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: Базовая версия получает только правильные числовые догадки. Обработка пустых строк, выхода и неверного диапазона должна иметь правило: считаются ли они попыткой? Это уже изменение игрового контракта.
