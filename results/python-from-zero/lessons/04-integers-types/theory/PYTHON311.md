# 04. Текст и числа: типы и преобразование

После урока вы сможете: Отличать строку от целого числа и превращать ввод в int.

Нужные знания: input, переменная, присваивание

## От задачи к способу решения

Слова и числа можно вывести одним способом, но работать с ними нужно по-разному. **Тип** описывает вид значения и допустимые действия. Тип `str` — текст, тип `int` — целое число: например 0, 7 или −12. Запись `'7'` означает текст из одного символа, запись `7` — число.

`input()` всегда возвращает строку. Даже если человек ввёл только цифры, Python сначала получил текст. Для суммы нам нужны числа. `int(text)` создаёт целое число из подходящей текстовой записи. Поэтому `a = int(input())` читается изнутри наружу: получить строку → преобразовать в целое → сохранить под именем a.

Знак `+` зависит от типов. Для двух целых он складывает, для двух строк — соединяет. После чтения строк `'12'` и `'3'` операция `+` даст `'123'`. После преобразования получим 15. Это не случайная ошибка Python: мы сами выбрали разные виды данных. Сложить число и строку напрямую нельзя: возникает TypeError.

`str(number)` делает обратное преобразование в текст. Оно нужно, если хочется именно соединить число с другим текстом через `+`. Для обычного вывода удобнее `print('Сумма:', total)`: print умеет показать число сам. `type(value)` позволяет увидеть тип; это диагностический инструмент. Для 7 результат содержит имя `int`, для `'7'` — `str`. Скобки вызова обязательны: `int` без скобок ещё не выполняет преобразование.

Тип принадлежит значению, а имя может позже получить значение другого типа. Такое допустимо, но в учебных программах старайтесь сохранять смысл переменной: имя `age` не должно неожиданно стать названием города.

Сначала решим задачу руками. Если введены 12 и 3, ответ 15. Программа получает два текста, превращает каждый в число, складывает и печатает результат. Не добавляем подпись «Ответ:», потому что формат требует только число.

`int('abc')` и `int('3.5')` не создают целое из этих строк: будет ValueError. Мы пока работаем с вводом, который соответствует условию. Это не повод прятать ошибку: нужно отличать неправильный формат данных от неправильного алгоритма.

## Задача и формат данных

Прочитать два целых числа и вывести их сумму.

**Ввод:** Два целых числа, каждое на отдельной строке.

**Вывод:** Одно целое число — сумма.

**Допустимые данные:** Числа от −1000000 до 1000000.

Вход сквозного примера:

```text
12
3
```

Ожидаемый вывод:

```text
15
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | Прочитать и преобразовать 12 | a = 12, тип int |
| 2 | Прочитать и преобразовать 3 | b = 3, тип int |
| 3 | Сложить числа, а не строки | total = 15 |
| 4 | Вывести total | 15 |

## Полная программа

```python
a = int(input())
b = int(input())
total = a + b
print(total)
```

## Как читать реализацию

Переменная total хранит вычисленный ответ, поэтому её легко проверить отдельно. Если убрать оба int, получится соединение строк. Если убрать только один, получим несовместимые типы. Для поиска такой ошибки сравните type(a) и type(b), затем уберите диагностический вывод из финального ответа.

## Почему работает и сколько действий требуется

Оба введённых значения представлены целыми, операция + выполняет требуемое сложение. В заданном диапазоне это небольшое фиксированное вычисление. Python хранит целые произвольной точности в пределах доступной памяти; очень длинные числа всё же требуют больше работы и памяти.

## Границы и частые ошибки

Знак минус допустим, пробелы по краям числовой строки int обычно принимает. Десятичная точка относится к дробной записи и не подходит для int из строки.
