# Проверка урока 04

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: input, переменная, присваивание

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Прочитать два целых числа и вывести их сумму. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Отличать строку от целого числа и превращать ввод в int. |
| Сквозной пример | Первый пример main: Сумма. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: Вывести total; результат: 15 |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | Переменная total хранит вычисленный ответ, поэтому её легко проверить отдельно. Если убрать оба int, получится соединение строк. Если убрать только один, получим несовместимые типы. Для поиска такой ошибки сравните type(a) и type(b), затем уберите диагностический вывод из финального ответа. |
| Корректность | Оба введённых значения представлены целыми, операция + выполняет требуемое сложение. В заданном диапазоне это небольшое фиксированное вычисление. Python хранит целые произвольной точности в пределах доступной памяти; очень длинные числа всё же требуют больше работы и памяти. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: Знак минус допустим, пробелы по краям числовой строки int обычно принимает. Десятичная точка относится к дробной записи и не подходит для int из строки.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
