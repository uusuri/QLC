# Проверка урока 09

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: if/else, сравнения и отступы

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Классифицировать температуру: ниже нуля — МОРОЗ, от 0 до 19 — ПРОХЛАДНО, от 20 — ТЕПЛО. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Выбирать ровно одну из нескольких категорий. |
| Сквозной пример | Первый пример main: Средняя ветвь. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: Остальная цепочка уже не выполняется; результат: Одно сообщение |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | В elif не повторяется проверка >= 0: она уже следует из того, что первая ветвь не выбрана. else закрывает оставшиеся значения. Такой разбор позволяет восстановить интервалы по коду и заметить пересечение или пропуск. |
| Корректность | Все температуры разделены на три непересекающихся случая, и каждый получает правильное слово. Цепочка делает не больше двух сравнений, затем заканчивается; хранится одна температура. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: Независимые if подходят, когда можно выполнить несколько действий, например одновременно отметить чётность и положительность. Для одной категории используют цепочку.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
