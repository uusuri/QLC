# 09. Несколько вариантов: elif и вложенные условия

После урока вы сможете: Выбирать ровно одну из нескольких категорий.

Нужные знания: if/else, сравнения и отступы

## От задачи к способу решения

Двух ветвей хватает для ответа да/нет. Для трёх категорий можно вложить ещё один if в else, но тогда структура растёт вправо. `elif` означает «иначе, если» и позволяет записать цепочку проверок на одном уровне.

Цепочка работает по порядку. Проверяется if. Если он истинный, его блок выполняется, остальные проверки цепочки пропускаются. Если ложный, проверяется первый elif. Если и он ложный, проверяется следующий. else выполняется, когда ни одно условие цепочки не подошло. Из всей цепочки выбирается самое первое подходящее действие.

Для температуры сначала отделим мороз: `temperature < 0`. Если не мороз, уже знаем, что температура не меньше нуля. Поэтому следующая проверка `temperature < 20` относится фактически к диапазону от 0 до 19. В else остаются значения от 20. Каждая ветвь получает смысл от предыдущих ложных проверок.

Нельзя бездумно заменить elif отдельными if. При температуре −5 проверки `< 0` и `< 20` обе истинны: два независимых if могли бы напечатать две категории. Цепочка разрешает ровно одну. Порядок также важен: проверка `< 20` в начале захватила бы морозные значения раньше их отдельной ветви.

**Вложенное условие** нужно, когда второй вопрос имеет смысл только внутри первого случая. Например, после проверки `age >= 18` можно отдельно проверить наличие билета. Тогда внутренний if пишется с ещё одним уровнем отступа. Но вложенность сама по себе не делает решение точнее. Сначала определите, это независимые действия, взаимоисключающие категории или дополнительный вопрос внутри одной категории.

Для нашего сквозного примера температура 10. Морозная проверка ложна. Проверка `< 20` истинна, значит выводим ПРОХЛАДНО. Вручную этот ответ относится к средней категории. Чтобы проверить границы, отдельно рассмотрим −1, 0, 19 и 20.

## Задача и формат данных

Классифицировать температуру: ниже нуля — МОРОЗ, от 0 до 19 — ПРОХЛАДНО, от 20 — ТЕПЛО.

**Ввод:** Одна целая температура.

**Вывод:** Одно из трёх слов.

**Допустимые данные:** Температура от −100 до 100.

Вход сквозного примера:

```text
10
```

Ожидаемый вывод:

```text
ПРОХЛАДНО
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | Прочитать температуру | temperature = 10 |
| 2 | 10 < 0 ложно: морозная ветвь пропускается | Переходим к elif |
| 3 | 10 < 20 истинно: выбрана средняя категория | ПРОХЛАДНО |
| 4 | Остальная цепочка уже не выполняется | Одно сообщение |

## Полная программа

```python
temperature = int(input())
if temperature < 0:
    print('МОРОЗ')
elif temperature < 20:
    print('ПРОХЛАДНО')
else:
    print('ТЕПЛО')
```

## Как читать реализацию

В elif не повторяется проверка >= 0: она уже следует из того, что первая ветвь не выбрана. else закрывает оставшиеся значения. Такой разбор позволяет восстановить интервалы по коду и заметить пересечение или пропуск.

## Почему работает и сколько действий требуется

Все температуры разделены на три непересекающихся случая, и каждый получает правильное слово. Цепочка делает не больше двух сравнений, затем заканчивается; хранится одна температура.

## Границы и частые ошибки

Независимые if подходят, когда можно выполнить несколько действий, например одновременно отметить чётность и положительность. Для одной категории используют цепочку.
