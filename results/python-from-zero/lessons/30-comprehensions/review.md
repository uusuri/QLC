# Проверка урока 30

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: Создание списка, отбор и арифметика

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Выбрать чётные числа и получить их квадраты в исходном порядке. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Читать включение как отбор и преобразование, не скрывая смысл за краткостью. |
| Сквозной пример | Первый пример main: Отбор до преобразования. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: 0 и 4 чётны: включить их квадраты по порядку; результат: result = [4, 0, 16] |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | Условие проверяет исходное value, а первая часть строит элемент результата. Имена token и value относятся к разным проходам. Вывод с распаковкой показывает числа без списка со скобками. Для восстановления включения напишите пустой result, for, if и append(value ** 2). |
| Корректность | Включение повторяет ровно описанный явный цикл: каждый элемент проверен один раз, чётные преобразованы и добавлены. Для n небольших чисел работа линейна, исходный и итоговый списки требуют линейной памяти. Отсутствие выбранных элементов корректно даёт пустой result. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: Включение не подходит для неизвестного бесконечного потока: оно пытается завершить построение списка целиком. Обработка ошибок int не исчезает из-за краткой записи.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
