# 30. Списковые включения: короткая запись знакомого цикла

После урока вы сможете: Читать включение как отбор и преобразование, не скрывая смысл за краткостью.

Нужные знания: Создание списка, отбор и арифметика

## От задачи к способу решения

Часто программа делает одну и ту же цепочку: создать список → пройти исходные элементы → при подходящем условии добавить преобразованный элемент. **Списковое включение** записывает эту цепочку одним выражением.

`[value ** 2 for value in numbers if value % 2 == 0]` читается по смыслу так: для каждого value из numbers, если оно чётное, включить value ** 2. Первая часть задаёт новый элемент, часть for — источник, часть if — отбор. Результат — новый список. Источник не изменяется.

Для [3, −2, 0, 4] число 3 не проходит проверку. −2 проходит и даёт 4. Ноль проходит и даёт 0. Четыре проходит и даёт 16. Получаем [4, 0, 16], в порядке исходных подходящих элементов, а не по возрастанию квадратов.

Строковый ввод тоже удобно преобразовать включением: `[int(token) for token in input().split()]`. Сначала input получает текст и split делит его на строковые части. Затем для каждой части int создаёт числовой элемент нового списка. Здесь нет if, потому что преобразуются все части.

Короткая форма полезна только после понимания длинной. Если в теле нужны несколько действий, служебный вывод, сложные ветви или выход через break, обычный for часто понятнее. Не превращайте весь алгоритм в одну строку ради внешней компактности.

Включение создаёт все элементы сразу. Оно не уменьшает память до постоянной и не делает цикл быстрее по порядку роста. Для суммы из потокового ввода хранение списка может вообще не понадобиться. Сравнивайте потребности задачи, а не длину записи.

Вложенные включения существуют, но требуют уже уверенного понимания порядка двух циклов. В этом курсе для таблиц оставляем явные циклы. Ошибка начинающего часто заключается не в незнании краткой формы, а в том, что она скрыла порядок вычислений и отбор.

## Задача и формат данных

Выбрать чётные числа и получить их квадраты в исходном порядке.

**Ввод:** Строка целых чисел через пробел, возможно пустая.

**Вывод:** Квадраты выбранных чисел через пробел.

**Допустимые данные:** До 1000 чисел, каждое от −10000 до 10000.

Вход сквозного примера:

```text
3 -2 0 4
```

Ожидаемый вывод:

```text
4 0 16
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | Прочитать все числовые элементы | numbers = [3, -2, 0, 4] |
| 2 | 3 нечётно, -2 чётно: включить квадрат -2 | result = [4] |
| 3 | 0 и 4 чётны: включить их квадраты по порядку | result = [4, 0, 16] |

## Полная программа

```python
numbers = [int(token) for token in input().split()]
result = [value ** 2 for value in numbers if value % 2 == 0]
print(*result)
```

## Как читать реализацию

Условие проверяет исходное value, а первая часть строит элемент результата. Имена token и value относятся к разным проходам. Вывод с распаковкой показывает числа без списка со скобками. Для восстановления включения напишите пустой result, for, if и append(value ** 2).

## Почему работает и сколько действий требуется

Включение повторяет ровно описанный явный цикл: каждый элемент проверен один раз, чётные преобразованы и добавлены. Для n небольших чисел работа линейна, исходный и итоговый списки требуют линейной памяти. Отсутствие выбранных элементов корректно даёт пустой result.

## Границы и частые ошибки

Включение не подходит для неизвестного бесконечного потока: оно пытается завершить построение списка целиком. Обработка ошибок int не исчезает из-за краткой записи.
