# 15. Сумма и счётчик: сохраняем результат между шагами: ответы

## Задание 1

2 — сумму обработанной части, а не всего ещё не прочитанного набора.

## Задание 2

Ноль — количество объектов до обработки. Единица не меняет первый множитель; произведение с начальным нулём навсегда осталось бы нулём.

## Задание 3

Прибавка выполняется лишь при нулевом остатке на 2.

```python
n = int(input())
total = 0
for i in range(n):
    value = int(input())
    if value % 2 == 0:
        total += value
print(total)
```

## Задание 4

Деление на n определено только для непустого набора. Складываем все значения, делим после цикла.

```python
n = int(input())
total = 0
for i in range(n):
    total += int(input())
print(f'{total / n:.2f}')
```
