# 15. Сумма и счётчик: сохраняем результат между шагами

После урока вы сможете: Накапливать сумму и количество подходящих значений.

Нужные знания: for, range и условия

## От задачи к способу решения

Цикл умеет повторить действие, но результаты разных шагов надо связать. Для трёх чисел можно вручную написать a + b + c. При переменном количестве вместо хранения каждого числа достаточно постепенно обновлять одну сумму. **Накопитель** — переменная, которая хранит результат уже обработанных шагов.

Перед чтением чисел `total = 0`: сумма пока пустого набора равна нулю. На каждом шаге `total = total + value`. Python сначала берёт старое total, прибавляет новое число, затем сохраняет результат под тем же именем. Присваивание не является уравнением, поэтому такая запись допустима. Сокращение `total += value` означает то же числовое обновление.

**Счётчик** — накопитель количества. `positive_count = 0` значит, что ещё не встретили положительных значений. Когда `value > 0`, увеличиваем его ровно на 1. Если условие ложно, счётчик не меняется. Не надо прибавлять само value: мы считаем объекты, а не их величину.

Сквозной пример: n = 3, числа 4, −2, 0. Сначала сумма 0 и счётчик 0. После 4 — сумма 4, счётчик 1. После −2 — сумма 2, счётчик остаётся 1. После 0 — сумма остаётся 2, счётчик 1. Ноль не положительный, потому что сравнение строгое.

Начальные значения ставятся **до** цикла. Если total = 0 поместить внутрь, на каждом шаге будет забыта предыдущая сумма и останется только последняя прибавка. Итоговый print ставится **после** цикла: иначе программа напечатает n промежуточных результатов вместо одного ответа.

Переменная day получает номера от 0 до n − 1, но в данном алгоритме сам номер не нужен: range(n) обеспечивает нужное количество чтений. Каждая итерация читает ровно одну следующую строку. Неправильный n во входе приведёт к лишнему запросу или неполной обработке; поэтому формат всегда указывает размер данных.

## Задача и формат данных

В n дневных результатах найти общую сумму и число положительных результатов.

**Ввод:** n первой строкой; затем n целых чисел, каждое на отдельной строке.

**Вывод:** Сумма и количество положительных через пробел.

**Допустимые данные:** 0 <= n <= 10000; значения от −1000 до 1000.

Вход сквозного примера:

```text
3
4
-2
0
```

Ожидаемый вывод:

```text
2 1
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 0 | До чтения чисел нет вклада и подходящих элементов | total = 0, positive_count = 0 |
| 1 | 4 прибавляется и удовлетворяет value > 0 | total = 4, positive_count = 1 |
| 2 | -2 прибавляется, но не положителен | total = 2, positive_count = 1 |
| 3 | 0 не меняет сумму и не проходит строгое сравнение | total = 2, positive_count = 1 |

## Полная программа

```python
n = int(input())
total = 0
positive_count = 0
for day in range(n):
    value = int(input())
    total += value
    if value > 0:
        positive_count += 1
print(total, positive_count)
```

## Как читать реализацию

total отвечает на вопрос о величине всех результатов, positive_count — о числе подходящих дней. Это независимые характеристики: отрицательный день уменьшает total, но не уменьшает число уже увиденных положительных. Сохранить все числа для этой задачи не нужно.

## Почему работает и сколько действий требуется

После каждого шага total равен сумме уже прочитанных чисел, а счётчик равен числу положительных среди них. Добавление очередного вклада сохраняет это свойство. После n шагов обработаны все данные. Работа пропорциональна n; память — постоянное число переменных, без хранения всего ввода.

## Границы и частые ошибки

Для произведения начальное значение 1, а не 0: единица не меняет первый множитель. Для среднего нужен total / n, но пустой набор требует отдельно определить поведение.
