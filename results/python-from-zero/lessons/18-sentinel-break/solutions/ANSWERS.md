# 18. Ввод до сигнала остановки: break и continue: ответы

## Задание 1

break завершает весь ближайший цикл. continue завершает только текущую итерацию этого цикла.

## Задание 2

Программа не отличит данные от команды завершения. Нужен другой сигнал или заранее известное количество.

## Задание 3

После проверки сигнала каждое число увеличивает счётчик.

```python
count = 0
while True:
    value = int(input())
    if value == 0:
        break
    count += 1
print(count)
```

## Задание 4

Сначала сравниваем текст с сигналом, затем преобразуем его в число.

```python
total = 0
while True:
    text = input()
    if text == 'СТОП':
        break
    total += int(text)
print(total)
```
