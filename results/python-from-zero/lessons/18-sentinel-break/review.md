# Проверка урока 18

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: while, условия и накопление суммы

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Сложить положительные числа до первого нуля; отрицательные пропускать. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Обрабатывать последовательность неизвестной длины до специального значения. |
| Сквозной пример | Первый пример main: Все три действия. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: 0 является сигналом: break завершает цикл; результат: Вывод 8 |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | Сначала отделяем служебное значение, затем неподходящие данные, затем обрабатываем оставшиеся. После цикла total — итог всех прибавлений. break и continue действуют на ближайший цикл, поэтому во вложенных циклах они не завершают сразу все уровни. |
| Корректность | Каждое прочитанное число до нуля либо положительно и добавляется ровно раз, либо отрицательно и не влияет на сумму. Сигнал гарантирован форматом, поэтому цикл завершится. Для k чисел до сигнала работа пропорциональна k; хранятся total и value. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: Если файл закончится до нуля, input получит EOFError. Это нарушение данного формата ввода. Ожидание пользовательского ввода не является вычислительным временем алгоритма.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
