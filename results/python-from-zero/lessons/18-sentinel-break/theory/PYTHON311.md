# 18. Ввод до сигнала остановки: break и continue

После урока вы сможете: Обрабатывать последовательность неизвестной длины до специального значения.

Нужные знания: while, условия и накопление суммы

## От задачи к способу решения

Иногда количество строк заранее неизвестно. Пользователь вводит покупки, а специальное значение сообщает конец. Такой сигнал называется **стоп-значением**. В нашей задаче это ноль: он завершает обработку и не является очередным слагаемым.

`while True` начинает цикл, условие которого само по себе всегда истинно. Для выхода нужна команда **break**: она немедленно завершает ближайший содержащий её цикл. После break программа продолжает с команды после цикла. Использовать такой цикл безопасно только когда есть понятный путь выхода или явно задумана бесконечная работа.

В начале каждого шага читаем value. Сначала проверяем ноль. Если это сигнал, выходим. Затем проверяем отрицательность. Отрицательные числа не учитываются; команда **continue** пропускает оставшуюся часть текущей итерации и начинает следующую. Положительное число доходит до total += value.

На входе 5, −2, 3, 0: 5 увеличивает сумму до 5, −2 пропускается, 3 увеличивает до 8, 0 завершает цикл. Ничего после первого нуля не относится к данным этой задачи. Можно обойтись без continue и написать отдельный if value > 0; здесь continue помогает явно показать пропуск.

Положение чтения существенно. Если в while с изменяемым условием написать continue до обновления, можно навсегда повторить одно состояние. В нашей схеме input находится в начале каждой итерации, поэтому после continue будет прочитано новое число.

Почему сумма и сигнал проверяются не наоборот? Для суммы ноль ничего не изменил бы, но правильная структура должна отличать служебный сигнал от данных. При подсчёте количества неправильный порядок мог бы учесть стоп-значение как объект. Если ноль является допустимой покупкой, он не подходит в качестве сигнала; нужно выбрать отдельное слово вроде СТОП и читать сначала текст.

## Задача и формат данных

Сложить положительные числа до первого нуля; отрицательные пропускать.

**Ввод:** Целые числа отдельными строками, последовательность обязательно содержит завершающий 0.

**Вывод:** Сумма положительных чисел до первого 0.

**Допустимые данные:** Не больше 10000 чисел до сигнала; каждое от −1000 до 1000.

Вход сквозного примера:

```text
5
-2
3
0
```

Ожидаемый вывод:

```text
8
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | 5 положительно: добавить | total = 5 |
| 2 | -2 отрицательно: continue пропускает прибавление | total = 5 |
| 3 | 3 положительно: добавить | total = 8 |
| 4 | 0 является сигналом: break завершает цикл | Вывод 8 |

## Полная программа

```python
total = 0
while True:
    value = int(input())
    if value == 0:
        break
    if value < 0:
        continue
    total += value
print(total)
```

## Как читать реализацию

Сначала отделяем служебное значение, затем неподходящие данные, затем обрабатываем оставшиеся. После цикла total — итог всех прибавлений. break и continue действуют на ближайший цикл, поэтому во вложенных циклах они не завершают сразу все уровни.

## Почему работает и сколько действий требуется

Каждое прочитанное число до нуля либо положительно и добавляется ровно раз, либо отрицательно и не влияет на сумму. Сигнал гарантирован форматом, поэтому цикл завершится. Для k чисел до сигнала работа пропорциональна k; хранятся total и value.

## Границы и частые ошибки

Если файл закончится до нуля, input получит EOFError. Это нарушение данного формата ввода. Ожидание пользовательского ввода не является вычислительным временем алгоритма.
