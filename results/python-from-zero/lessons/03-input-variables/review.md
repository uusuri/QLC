# Проверка урока 03

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: print, строки и порядок команд

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Прочитать имя и город, затем вывести приветствие и место проживания. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Прочитать строку, сохранить её под именем и использовать в ответе. |
| Сквозной пример | Первый пример main: Две строки. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: print берёт значение city; результат: Город: Казань |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | Имена name и city сохраняют два независимых результата чтения. Пробел после запятой в приветствии получается из стандартного sep. Если дважды использовать input внутри одного print, программа прочитает новые данные; ранее прочитанные строки сами не возвращаются. |
| Корректность | Каждый input потребляет одну нужную строку, и каждое значение используется на своём месте. Для строк суммарной длины L чтение, хранение и вывод требуют работы и памяти, пропорциональных L: длинный текст надо действительно прочитать и вывести. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: Пустые строки технически читаются, но в этой задаче исключены. При нехватке строк в файле ввода возникнет EOFError: программа запросила больше данных, чем предоставлено.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
