# 03. Ввод, переменные и присваивание

После урока вы сможете: Прочитать строку, сохранить её под именем и использовать в ответе.

Нужные знания: print, строки и порядок команд

## От задачи к способу решения

Программа с фиксированным именем отвечает одинаково всем. Хотим, чтобы ответ зависел от человека. **Ввод** — данные, которые программа получает во время работы. `input()` ждёт одну строку ввода и возвращает её как текст. Нажатие Enter завершает ввод; сам конечный перенос строки не становится частью возвращённого текста. Пробелы внутри строки сохраняются.

Результат нужно запомнить. **Переменная** — имя, по которому программа получает значение. Запись `name = input()` означает: сначала выполнить правую часть, затем связать имя `name` с полученной строкой. `=` называется **присваиванием**. Это действие, а не утверждение математического равенства.

В `print(name)` кавычек нет: нужно взять значение переменной. В `print('name')` кавычки есть: нужно вывести четыре буквы `name`. Это два разных запроса. Имена пишем латинскими буквами, цифрами и подчёркиванием; цифра не может быть первой. Регистр важен: `name` и `Name` — разные имена. Выбирайте смысловые имена: `city` для города понятнее, чем `x`.

Присваивание может заменить прежнее значение. После `word = 'да'`, затем `word = 'нет'` имя `word` связано с `нет`. Оно не хранит историю замен. Если написать `copy = word`, то для изучаемого сейчас текста оба имени получат одно текущее значение; последующее присваивание нового текста одному имени не перепишет другое. Изменяемые списки будут иметь важную особенность, которую изучим отдельно.

В нашей задаче данные идут двумя строками. Первый `input` получает имя, второй — город. Если город состоит из двух слов, например Нижний Новгород, они читаются вместе. Мы ещё не просим Python разбивать строку на слова.

В интерактивной программе допустимо `input('Ваше имя: ')`: текст в скобках сначала печатается как приглашение. В проверяемых задачах приглашения мешают точному ответу, поэтому основной код курса читает через `input()` без приглашения. Когда кажется, что программа «зависла» на input, сначала проверьте, не ждёт ли она очередную строку.

## Задача и формат данных

Прочитать имя и город, затем вывести приветствие и место проживания.

**Ввод:** Первая строка — имя, вторая — город.

**Вывод:** Две строки: Привет, имя и Город: город.

**Допустимые данные:** Каждая строка содержит от 1 до 100 символов.

Вход сквозного примера:

```text
Аня
Казань
```

Ожидаемый вывод:

```text
Привет, Аня
Город: Казань
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | Первый input читает первую строку | name = Аня |
| 2 | Второй input читает следующую строку | city = Казань |
| 3 | print берёт значение name | Привет, Аня |
| 4 | print берёт значение city | Город: Казань |

## Полная программа

```python
name = input()
city = input()
print('Привет,', name)
print('Город:', city)
```

## Как читать реализацию

Имена name и city сохраняют два независимых результата чтения. Пробел после запятой в приветствии получается из стандартного sep. Если дважды использовать input внутри одного print, программа прочитает новые данные; ранее прочитанные строки сами не возвращаются.

## Почему работает и сколько действий требуется

Каждый input потребляет одну нужную строку, и каждое значение используется на своём месте. Для строк суммарной длины L чтение, хранение и вывод требуют работы и памяти, пропорциональных L: длинный текст надо действительно прочитать и вывести.

## Границы и частые ошибки

Пустые строки технически читаются, но в этой задаче исключены. При нехватке строк в файле ввода возникнет EOFError: программа запросила больше данных, чем предоставлено.
