## Задание 3

Знак отделяется до деления, остаток оформляется двумя цифрами.

```python
def money_text(kopecks):
    sign = ''
    if kopecks < 0:
        sign = '-'
    value = abs(kopecks)
    return f'{sign}{value // 100}.{value % 100:02d}'

kopecks = int(input())
print(money_text(kopecks))
```

## Задание 4

Для проверки суммы названия и прежние отдельные цены больше не нужны. Сохраняем только накопитель.

```python
budget = int(input())
n = int(input())
total = 0
for i in range(n):
    total += int(input())
if total <= budget:
    print('ДА')
else:
    print('НЕТ')
```
