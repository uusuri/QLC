# 17. Повторение до выполнения условия: while

После урока вы сможете: Написать цикл с изменяемым состоянием и объяснить его завершение.

Нужные знания: Сравнения, += и циклы

## От задачи к способу решения

for подходит, когда известен набор значений или число повторений. Иногда удобнее описать состояние, при котором работу надо продолжать. **while** означает «пока»: перед каждой итерацией Python проверяет условие; если оно истинно — выполняет блок, затем снова проверяет. Если условие сразу ложное, тело не выполняется ни разу.

Запас 7 литров, расход 3 литра в день. После первого дня останется 4, после второго 1, на третий запас исчерпается. Дней три. В модели последняя операция уменьшает запас до −2: это вычислительное обозначение того, что полного дневного расхода уже не хватило. Реального отрицательного количества воды не возникает.

Будем хранить `remaining`, ещё не израсходованную часть, и `days`, число учтённых дней. Пока remaining > 0, учитываем следующий день и уменьшаем запас на use. Запись `remaining -= use` означает `remaining = remaining - use`. Когда остаток становится нулевым или отрицательным, условие ложное.

Сначала выбираем **условие продолжения**, затем проверяем, приближают ли обновления к его ложности. Без remaining -= use условие осталось бы истинным навсегда: получился бы бесконечный цикл. Если use = 0, уменьшения нет даже при наличии строки обновления. Поэтому положительность расхода — существенное условие задачи.

Для while нельзя рассчитывать, что имя счётчика само изменится, как у for. Программа отвечает за обновления. Условие `remaining >= 0` тоже неверно: при запасе 6 и расходе 3 оно посчитает лишний день из состояния remaining = 0. Нам нужен день только пока вода ещё есть.

Эту же задачу можно решить формулой `(stock + use - 1) // use`. Она не проходит дни по одному и быстрее для огромного запаса. Цикл нужен здесь для освоения модели состояния; формула допустима потому, что расход одинаков каждый день. Если расходы меняются по внешним данным, одной формулы может не хватить.

## Задача и формат данных

Есть запас воды и дневной расход. Найти число дней до исчерпания; последний неполный день считается.

**Ввод:** Запас и положительный расход двумя строками.

**Вывод:** Число дней.

**Допустимые данные:** 0 <= stock <= 10000; 1 <= use <= 10000.

Вход сквозного примера:

```text
7
3
```

Ожидаемый вывод:

```text
3
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 0 | Перед расходом дней ещё нет | remaining = 7, days = 0 |
| 1 | 7 > 0: учесть день и вычесть 3 | remaining = 4, days = 1 |
| 2 | 4 > 0: следующий день | remaining = 1, days = 2 |
| 3 | 1 > 0: последний неполный день тоже учитывается | remaining = -2, days = 3 |
| 4 | -2 > 0 ложно: завершить | Вывод 3 |

## Полная программа

```python
stock = int(input())
use = int(input())
remaining = stock
days = 0
while remaining > 0:
    remaining -= use
    days += 1
print(days)
```

## Как читать реализацию

stock сохраняет исходный запас, remaining меняется. Такое разделение позволяет сравнить итог с исходными данными. Счётчик days обновляется на каждой допустимой итерации. Положительный use гарантирует, что remaining строго уменьшается.

## Почему работает и сколько действий требуется

После d итераций учтены ровно d дней, remaining равен stock - d * use. Цикл останавливается при первом d с неположительным остатком, то есть после нужного количества дней. Работа пропорциональна числу дней; хранится фиксированное число целых.

## Границы и частые ошибки

Нулевой расход исключён, иначе цикл не завершится при положительном запасе. При большом числе дней формула выгоднее; результат у неё тот же.
