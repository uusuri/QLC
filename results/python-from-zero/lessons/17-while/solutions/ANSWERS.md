# 17. Повторение до выполнения условия: while: ответы

## Задание 1

Ноль: условие сразу ложное.

## Задание 2

remaining -= use. При положительном use она уменьшает остаток.

## Задание 3

Пока текущее число положительно, печатаем и уменьшаем.

```python
current = int(input())
while current > 0:
    print(current)
    current -= 1
```

## Задание 4

Округление количества дней вверх даёт (stock + use - 1) // use, при нуле тоже получается ноль.

```python
stock = int(input())
use = int(input())
print((stock + use - 1) // use)
```
