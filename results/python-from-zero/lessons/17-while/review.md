# Проверка урока 17

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: Сравнения, += и циклы

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Есть запас воды и дневной расход. Найти число дней до исчерпания; последний неполный день считается. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Написать цикл с изменяемым состоянием и объяснить его завершение. |
| Сквозной пример | Первый пример main: Последний неполный день. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: -2 > 0 ложно: завершить; результат: Вывод 3 |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | stock сохраняет исходный запас, remaining меняется. Такое разделение позволяет сравнить итог с исходными данными. Счётчик days обновляется на каждой допустимой итерации. Положительный use гарантирует, что remaining строго уменьшается. |
| Корректность | После d итераций учтены ровно d дней, remaining равен stock - d * use. Цикл останавливается при первом d с неположительным остатком, то есть после нужного количества дней. Работа пропорциональна числу дней; хранится фиксированное число целых. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: Нулевой расход исключён, иначе цикл не завершится при положительном запасе. При большом числе дней формула выгоднее; результат у неё тот же.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
