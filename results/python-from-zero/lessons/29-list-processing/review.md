# Проверка урока 29

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: Циклы по спискам, append и копии

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Из целых чисел выбрать положительные и вывести их по возрастанию. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Сохранить подходящие элементы и объяснить, когда можно менять порядок. |
| Сквозной пример | Первый пример main: Повтор сохраняется. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: sort переставляет элементы по числовому возрастанию; результат: positive = [2, 3, 3] |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | tokens хранит части исходной строки, value — очередное преобразованное число. positive сохраняет только подходящие числа. После sort порядок изменён намеренно. Сумма не вычисляется: ответ требует количество и конкретную последовательность. |
| Корректность | Каждый положительный элемент добавляется один раз и никакой другой не добавляется. Сортировка меняет только порядок, сохраняя элементы и повторы. Для n входных элементов и k выбранных отбор линейный, сортировка до порядка k log k, общий худший порядок n log n. Хранение частей ввода, выбранных элементов и служебной памяти сортировки линейно. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: Пустой список можно сортировать и выводить. Поиск index в пустом списке выдаст ValueError. Если нужен прежний порядок, пропустите сортировку.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
