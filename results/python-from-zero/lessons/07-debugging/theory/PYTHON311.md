# 07. Как читать ошибки и проверять вычисления

После урока вы сможете: Различать ошибку записи, ошибку выполнения и неверный ответ.

Нужные знания: Ввод целых, переменные и арифметика

## От задачи к способу решения

Ошибка — информация о том, где программа перестала соответствовать замыслу. Полезно разделять три случая. **Синтаксическая ошибка** означает, что запись не подходит правилам языка: например не закрыта скобка. **Ошибка выполнения** появляется у записанной правильно команды, которую нельзя выполнить с текущими данными: например число делится на ноль. **Логическая ошибка** не мешает запуску, но даёт неверный ответ.

Сообщение Python обычно содержит название файла, номер строки, фрагмент кода и название ошибки. Начинайте с последней строки: она называет тип и причину. Затем найдите указанное место в своём файле. Показанная строка — место обнаружения, а причина иногда находится выше: забытая скобка может нарушить следующую команду.

`SyntaxError` просит проверить запись. `NameError` означает, что использовано имя без доступного значения; проверьте написание и порядок присваиваний. `TypeError` — операция получила неподходящие типы. `ValueError` при int часто означает неподходящий текст числа. `ZeroDivisionError` объясняет запрещённое деление. Номер строки помогает найти место, но не заменяет рассуждение о смысле.

Возьмём задачу о билетах. Для цены 80 и количества 3 вручную получаем 240. Если программа выдала 83, вероятно, вместо произведения вычислена сумма. Если выдала 803, вероятно, соединены строки. Эти результаты подсказывают разные исправления.

**Отладка** — поиск и устранение причины ошибки. Действуйте по шагам: найдите небольшой вход → получите ожидаемый ответ руками → запустите программу → сравните → проверьте ближайшее неверное промежуточное значение. Временно добавьте `print(price, count)` перед вычислением. Если данные верны, исследуйте выражение. Если нет, исследуйте чтение. После исправления уберите служебный вывод.

**Тест** — выбранные данные и ожидаемое поведение. Один обычный тест ещё не проверяет все случаи. Для билетов полезны нулевое количество, один билет и максимальные значения. Меняйте одну причину за раз, сохраняйте файл и повторяйте тест, на котором было расхождение. Бессистемная замена нескольких строк мешает понять, какая правка помогла.

## Задача и формат данных

Прочитать цену и количество билетов, вывести общую стоимость.

**Ввод:** Цена и количество на отдельных строках.

**Вывод:** Одно целое число — стоимость.

**Допустимые данные:** Цена от 0 до 10000; количество от 0 до 100.

Вход сквозного примера:

```text
80
3
```

Ожидаемый вывод:

```text
240
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | Прочитать оба числа с преобразованием | price = 80, count = 3 |
| 2 | Сравнить действие с ручным расчётом | 80 * 3 = 240 |
| 3 | Вывести только требуемый ответ | 240 |

## Полная программа

```python
price = int(input())
count = int(input())
cost = price * count
print(cost)
```

## Как читать реализацию

Проверяем не только результат, но и путь его получения: int создаёт числа, умножение выражает покупку count одинаковых билетов. Если в файле написано prise, а в print — price, это два разных имени. Замените опечатку в месте использования, не создавайте случайную новую переменную ради исчезновения ошибки.

## Почему работает и сколько действий требуется

Произведение цены и количества соответствует условию. Проверка чтением даёт объяснение для любого допустимого входа; тесты помогают заметить отдельные реализации неверной идеи. Программа делает фиксированное число действий и хранит несколько чисел.

## Границы и частые ошибки

Успешный запуск не гарантирует правильность ответа. В этом уроке не перехватываем исключения: сначала надо понять их причину. Обработку пользовательских ошибок изучим после функций.

## Попробуйте самостоятельно

Закройте готовую программу. Начните с первых двух вопросов, затем напишите решения двух задач. Ответы находятся в отдельном файле.

1. Как называется ошибка в print(total), если раньше создана только переменная cost?

2. Программа стоимости складывает price + count. Какой тест из 80 и 3 обнаружит ошибку и почему?

3. Исправьте вычисление среднего двух чисел: ошибочная программа пишет a + b / 2. Числа читаются двумя строками, каждое от −100 до 100.

4. Для покупки билетов напечатайте сдачу: третьей строкой дан платёж, не меньше стоимости. Исправьте типичную ошибку payment - price * (count - 1).
