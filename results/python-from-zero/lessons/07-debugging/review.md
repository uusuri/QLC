# Проверка урока 07

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: Ввод целых, переменные и арифметика

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Прочитать цену и количество билетов, вывести общую стоимость. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Различать ошибку записи, ошибку выполнения и неверный ответ. |
| Сквозной пример | Первый пример main: Обычный тест. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: Вывести только требуемый ответ; результат: 240 |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | Проверяем не только результат, но и путь его получения: int создаёт числа, умножение выражает покупку count одинаковых билетов. Если в файле написано prise, а в print — price, это два разных имени. Замените опечатку в месте использования, не создавайте случайную новую переменную ради исчезновения ошибки. |
| Корректность | Произведение цены и количества соответствует условию. Проверка чтением даёт объяснение для любого допустимого входа; тесты помогают заметить отдельные реализации неверной идеи. Программа делает фиксированное число действий и хранит несколько чисел. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: Успешный запуск не гарантирует правильность ответа. В этом уроке не перехватываем исключения: сначала надо понять их причину. Обработку пользовательских ошибок изучим после функций.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
