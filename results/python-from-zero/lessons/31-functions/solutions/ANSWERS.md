# 31. Свои функции: отделяем действие и вызываем его: ответы

## Задание 1

Ни одного. Определение создаёт функцию, а выполняет тело вызов.

## Задание 2

Параметр — имя в определении. Аргумент — конкретное переданное значение выражения first.

## Задание 3

Функция получает готовое число и выполняет одно понятное действие.

```python
def print_square(side):
    print(side * side)

side = int(input())
print_square(side)
```

## Задание 4

Каждое имя сразу передаётся функции, поэтому накопление списка не нужно.

```python
def greet(name):
    print(f'Привет, {name}!')

n = int(input())
for i in range(n):
    greet(input())
```
