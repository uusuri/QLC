# Проверка урока 31

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: Переменные, условия, циклы и готовые функции

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Для двух введённых имён вывести по персональному приветствию. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Определить функцию с параметром и вызвать её несколько раз. |
| Сквозной пример | Первый пример main: Два вызова. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: greet(second): новый вызов получает Лев; результат: Привет, Лев! |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | f-строка вставляет значение параметра name. Пустая строка в исходном коде отделяет определение от основной части для чтения; она не создаёт вывода. Круглые скобки в greet(first) необходимы для вызова: запись greet без скобок лишь обращается к объекту функции. |
| Корректность | Оба имени по одному передаются одному правилу оформления, поэтому каждый вызов печатает нужную строку. Работа пропорциональна суммарной длине имён; они хранятся как строки. В каждый момент выполняется один короткий вызов, вложенность не растёт. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: Функция вызывается столько раз, сколько указано вызовов. Один def не запускает тело. Чтобы напечатать n приветствий, вызов можно поставить в цикл.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
