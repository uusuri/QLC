# 31. Свои функции: отделяем действие и вызываем его

После урока вы сможете: Определить функцию с параметром и вызвать её несколько раз.

Нужные знания: Переменные, условия, циклы и готовые функции

## От задачи к способу решения

Повторяющиеся строки программы можно вынести в функцию. **Определение функции** описывает действие и даёт ему имя. **Вызов** выполняет это действие с конкретными данными. Они различаются: запись определения сама по себе не печатает приветствие.

`def greet(name):` вводит функцию greet. **Параметр** name — имя для данных, которые будут переданы при вызове. Тело функции пишется с отступом. Вызов `greet(first)` передаёт значение first как **аргумент**; внутри данного вызова оно доступно под параметром name.

Для Ани и Льва правило приветствия одинаковое. Можно написать два print, но тогда изменение формата пришлось бы внести в два места. Функция хранит одно описание: вывести Привет, затем имя, затем !. Оба вызова используют его. Это полезно не только для экономии строк: имя greet объясняет назначение действия.

Объявим функцию раньше вызовов. Python должен выполнить def и связать имя с функцией к тому моменту, когда встретит greet(first). Затем читаем два имени, вызываем greet для первого, потом для второго. После каждого вызова выполнение возвращается к следующей команде основной программы.

Имя параметра не обязано совпадать с именем переданной переменной. При greet(first) параметр name получает значение first; при greet(second) — значение second. Нельзя сделать вывод, что переменная name основной программы изменилась: у функции собственное пространство локальных имён, которое подробнее разберём дальше.

Наш greet создаёт вывод как действие. Такой эффект полезен для оформления сообщений, но не стоит прятать в нём чтение имени: тогда связь между аргументом и результатом исчезнет. Получать данные удобно в основной программе, а функции передавать уже готовое значение. Позже функция сможет возвращать рассчитанный ответ без печати.

Имена функций лучше выбирать по смыслу действия: greet, print_report, calculate_total. Не нужно выносить каждую строку в отдельную функцию. Хорошая функция имеет понятную работу и контракт: здесь принимает одно имя, выводит одну строку приветствия.

## Задача и формат данных

Для двух введённых имён вывести по персональному приветствию.

**Ввод:** Два имени на отдельных строках.

**Вывод:** Две строки вида Привет, имя!.

**Допустимые данные:** Длина каждого имени от 1 до 100 символов.

Вход сквозного примера:

```text
Аня
Лев
```

Ожидаемый вывод:

```text
Привет, Аня!
Привет, Лев!
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | def создаёт функцию; тело пока не выполняется | Имя greet доступно для вызова |
| 2 | Прочитать два имени | first = Аня, second = Лев |
| 3 | greet(first): параметр name получает Аня | Привет, Аня! |
| 4 | greet(second): новый вызов получает Лев | Привет, Лев! |

## Полная программа

```python
def greet(name):
    print(f'Привет, {name}!')

first = input()
second = input()
greet(first)
greet(second)
```

## Как читать реализацию

f-строка вставляет значение параметра name. Пустая строка в исходном коде отделяет определение от основной части для чтения; она не создаёт вывода. Круглые скобки в greet(first) необходимы для вызова: запись greet без скобок лишь обращается к объекту функции.

## Почему работает и сколько действий требуется

Оба имени по одному передаются одному правилу оформления, поэтому каждый вызов печатает нужную строку. Работа пропорциональна суммарной длине имён; они хранятся как строки. В каждый момент выполняется один короткий вызов, вложенность не растёт.

## Границы и частые ошибки

Функция вызывается столько раз, сколько указано вызовов. Один def не запускает тело. Чтобы напечатать n приветствий, вызов можно поставить в цикл.
