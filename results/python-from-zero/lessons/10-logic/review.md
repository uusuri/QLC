# Проверка урока 10

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: Сравнения, bool и if

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Допустить участника, если возраст от 12 до 17 включительно и есть согласие. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Переводить слова «и», «или», «не» в точные логические выражения. |
| Сквозной пример | Первый пример main: Оба условия. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: Обе части истинны: and истинен; результат: ДА |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | Проверки отвечают разным требованиям. Они соединены and, потому что правила не позволяют заменить согласие подходящим возрастом. not можно использовать для отрицания понятного целого условия, например not (12 <= age <= 17), но отрицание не стоит усложнять без причины. |
| Корректность | Возрастной диапазон и согласие необходимы одновременно; выражение истинно ровно в этих случаях. Количество проверок ограничено константой, дополнительных коллекций нет. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: and и or могут возвращать сами операнды, если им переданы не bool. В основных примерах обе части — сравнения, поэтому результат булев. Дальнейшую семантику операндов для этой задачи знать не нужно.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
