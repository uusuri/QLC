# 10. Составные условия: and, or и not

После урока вы сможете: Переводить слова «и», «или», «не» в точные логические выражения.

Нужные знания: Сравнения, bool и if

## От задачи к способу решения

Иногда одного сравнения недостаточно. Нужно соединить несколько вопросов. `and` означает: оба условия должны быть истинны. `or` означает: достаточно хотя бы одного. В Python это включающее «или»: если истинны оба, результат тоже истинный. `not` меняет истину на ложь и наоборот.

Для возрастного диапазона должны выполняться две границы: `age >= 12 and age <= 17`. Python позволяет равнозначную запись `12 <= age <= 17`. Добавим согласие: `(12 <= age <= 17) and consent == 1`. Возраст подходит и согласие дано — допускаем; любой провал означает отказ.

Полезно составить маленькую таблицу для and: истина и истина → истина; истина и ложь → ложь; ложь и истина → ложь; ложь и ложь → ложь. У or только сочетание двух ложных условий даёт ложь. Это способ проверить смысл до записи большой формулы.

Частая ловушка — `age >= 12 or age <= 17`. Для возраста 80 первая часть истинна, и участник ошибочно допускается. Для диапазона нужны обе границы одновременно. Другая ловушка — `number == 1 or 2`: это не сокращение двух сравнений. Пишите `number == 1 or number == 2`.

Сравнения связываются раньше not, затем and, затем or. Если есть риск прочитать выражение иначе, ставьте скобки по смыслу. Python также проверяет составные условия слева направо и прекращает проверку, когда результат известен. Например, `divisor != 0 and number % divisor == 0` не станет делить на ноль: при нулевом divisor первая часть уже ложна.

В условиях числовой ноль и пустая строка считаются ложными, остальные целые и непустые строки — истинными. Это объясняет, почему голое `2` в ошибочной записи с or не проверяет равенство. Пока используйте явные сравнения: они лучше показывают вопрос программы.

## Задача и формат данных

Допустить участника, если возраст от 12 до 17 включительно и есть согласие.

**Ввод:** Возраст одной строкой; затем 1, если согласие есть, иначе 0.

**Вывод:** ДА либо НЕТ.

**Допустимые данные:** Возраст от 0 до 120; согласие — только 0 или 1.

Вход сквозного примера:

```text
15
1
```

Ожидаемый вывод:

```text
ДА
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | Прочитать возраст и согласие | age = 15, consent = 1 |
| 2 | Возраст внутри обеих включённых границ | 12 <= 15 <= 17: True |
| 3 | Проверить наличие согласия | consent == 1: True |
| 4 | Обе части истинны: and истинен | ДА |

## Полная программа

```python
age = int(input())
consent = int(input())
if 12 <= age <= 17 and consent == 1:
    print('ДА')
else:
    print('НЕТ')
```

## Как читать реализацию

Проверки отвечают разным требованиям. Они соединены and, потому что правила не позволяют заменить согласие подходящим возрастом. not можно использовать для отрицания понятного целого условия, например not (12 <= age <= 17), но отрицание не стоит усложнять без причины.

## Почему работает и сколько действий требуется

Возрастной диапазон и согласие необходимы одновременно; выражение истинно ровно в этих случаях. Количество проверок ограничено константой, дополнительных коллекций нет.

## Границы и частые ошибки

and и or могут возвращать сами операнды, если им переданы не bool. В основных примерах обе части — сравнения, поэтому результат булев. Дальнейшую семантику операндов для этой задачи знать не нужно.
