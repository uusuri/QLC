# Проверка урока 25

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: Цикл по символам и строковые методы

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Посчитать латинские гласные в строке, не учитывая регистр. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Отличать поиск вхождения от подсчёта и собирать ответ по правилу. |
| Сквозной пример | Первый пример main: Разный регистр и знак. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: ! не входит; обработка закончена; результат: Вывод 2 |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | count считает подходящие позиции, а не число различных видов букв: в aaa он равен 3. Для каждого исходного символа проверяем принадлежность короткой строке длины 10. Преобразование lower не применяется: условия уже явно включают оба регистра нужных букв. |
| Корректность | Каждая исходная позиция рассматривается ровно раз и увеличивает счётчик ровно тогда, когда удовлетворяет правилу. Цикл конечен по длине строки. Работа пропорциональна L при фиксированном наборе гласных; хранится исходный текст длины L и постоянное число служебных переменных. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: Для кириллических гласных нужен другой набор. Смена набора меняет предметное правило, но сохраняет механизм цикла и счётчика.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
