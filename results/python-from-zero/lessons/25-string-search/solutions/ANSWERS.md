## Задание 3

Используем count для одного конкретного символа.

```python
text = input()
print(text.count(' '))
```

## Задание 4

Пустая строка — начальный ответ. Прибавляем только разрешённые символы. Для очень больших текстов заменили бы сборку на список частей.

```python
text = input()
result = ''
for character in text:
    if character in '0123456789':
        result += character
print(result)
```
