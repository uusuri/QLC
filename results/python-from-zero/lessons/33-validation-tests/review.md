# Проверка урока 33

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: Функции, return, if и сообщения об ошибках

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Проверить ввод возраста: текст должен быть целым числом от 0 до 120. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Обработать ожидаемую ошибку преобразования и проверить контракт функции. |
| Сквозной пример | Первый пример main: Верхняя граница нарушена. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: Выбрать сообщение об ошибке диапазона; результат: ДИАПАЗОН |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | in_age_range не печатает и не читает, только возвращает результат числовой проверки. В except попадают исключительно ошибки int в данном try. Ветвь else выполняется при доступном age; поэтому попытки использовать несуществующее значение после неудачного преобразования нет. |
| Корректность | Каждая строка либо не преобразуется, либо создаёт целое внутри диапазона, либо создаёт целое вне него. Эти случаи не пересекаются и полностью покрывают ввод по контракту. Для длины L чтение и преобразование требуют работы по длине, хранится исходный текст и результат. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: Пустая строка тоже получает ЧИСЛО. EOFError при отсутствии строки вообще не то же, что пустая введённая строка, и здесь не перехватывается. assert в учебных тестах не заменяет явную обработку неправильного ввода.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
