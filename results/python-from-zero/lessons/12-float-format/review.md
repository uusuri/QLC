# Проверка урока 12

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: Арифметика, int и преобразования

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Найти среднее двух измерений и вывести его с двумя знаками после точки. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Читать float и отличать значение от способа его отображения. |
| Сквозной пример | Первый пример main: Дробное среднее. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: Оформить число с двумя знаками; результат: 2.75 |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | Чтение создаёт float, деление сохраняет дробное среднее. Скобки в формуле существенны, а фигурные скобки f-строки управляют подстановкой. Внутри .2f число 2 задаёт количество знаков, а f — формат фиксированной десятичной записи. |
| Корректность | Формула соответствует определению среднего, формат соответствует требованию двух знаков. Вычисление имеет обычную погрешность float. Число операций фиксировано, сохраняем несколько числовых значений и короткую строку вывода. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: Тесты не подменяют обсуждение точности. Отрицательное приближённое число, близкое к нулю, иногда отображается как -0.00; это свойство представления. Правило удаления такого знака должно быть отдельно задано условием.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
