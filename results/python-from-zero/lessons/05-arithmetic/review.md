# Проверка урока 05

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: int, числовой ввод и сложение

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Купить одинаковые тетради и одну ручку; найти общую стоимость. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Переводить словесную задачу в выражение со скобками. |
| Сквозной пример | Первый пример main: Обычная покупка. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: Прибавить одну ручку; результат: total = 145 |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | Имена отражают смысл данных. Подстановка price = 30 и count = 4 в выражение объясняет 120. В конце выводится только total, потому что промежуточная стоимость не запрошена. Разбить вычисление на две строки допустимо; результат тот же, что у price * count + pen. |
| Корректность | Каждая тетрадь оплачивается ровно один раз, ручка — один раз. Фиксированное число чтений и арифметических действий достаточно для всех допустимых входов. Сохраняем несколько небольших целых чисел. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: Нулевое количество оставляет только цену ручки. Отрицательные цены и количества условием исключены; здесь они не являются допустимыми тестами.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
