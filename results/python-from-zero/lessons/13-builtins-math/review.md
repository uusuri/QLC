# Проверка урока 13

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: Числовые выражения и float

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Найти расстояние между двумя точками на числовой прямой. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Использовать готовую операцию и проверять область допустимых данных. |
| Сквозной пример | Первый пример main: Через ноль. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: Убрать знак через расстояние от нуля; результат: distance = 8 |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | Разность задаёт направление от одной координаты к другой, abs оставляет только длину. Отдельная переменная distance не обязательна для синтаксиса, но показывает смысл итогового значения. Оператор if мог бы реализовать два знака вручную, однако здесь готовая функция выражает именно требуемую операцию. |
| Корректность | Модуль разности не зависит от порядка точек и равен длине промежутка между ними. Вычисление завершается после двух чтений и фиксированных операций. Дополнительная память — несколько чисел. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: Для расстояния в плоскости одной разности уже недостаточно: там потребуется другая формула. Для прямой применимость не зависит от знаков координат.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
