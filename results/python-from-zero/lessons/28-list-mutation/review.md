# Проверка урока 28

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: Список, append и индексы

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Прочитать список, создать копию, заменить первый элемент копии и вывести оба списка. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Отличать новое имя того же списка от независимой копии. |
| Сквозной пример | Первый пример main: Независимая копия. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: Менять элемент только копии; результат: edited = [9, 4, 6], numbers = [2, 4, 6] |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | Копирование выполняется до замены. numbers и edited содержат одинаковые числовые значения, но внешние списки разные. Исходный список обещан непустым, поэтому индекс 0 допустим. Удаление последнего элемента через pop не подходит для замены первого. |
| Корректность | copy отделяет структуру плоского списка, поэтому присваивание в edited не меняет numbers. Чтение, копирование и вывод требуют линейной работы по числу элементов. Помимо исходного списка хранится копия такой же длины; дополнительная память линейна. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: Для списка вложенных списков нужна отдельная стратегия копирования. Методы, меняющие середину списка, обычно сдвигают последующие элементы и могут требовать линейной работы.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
