# Проверка урока 24

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: Строки, сравнение и неизменяемость

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Нормализовать название команды: убрать внешние пробелы и сделать буквы строчными. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Вызывать метод и сохранять результат преобразования. |
| Сквозной пример | Первый пример main: Оба преобразования. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: lower создаёт строчную запись; результат: command = помощь |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | text сохраняет исходный ввод, cleaned — результат очистки, command — результат смены регистра. Это помогает проверить каждое преобразование. print(command) не добавляет кавычки. Пустая очищенная команда выводится как пустая строка. |
| Корректность | strip удаляет только оговорённые края, lower меняет регистр букв, следовательно получаем требуемую нормализованную запись. Для длины L каждый проход требует линейной работы в худшем случае; создаваемые строки требуют памяти порядка L. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: Методы возвращают новые строки. Unicode-регистр не всегда сохраняет число кодовых точек, поэтому после преобразования индексы лучше вычислять заново. Для простой кириллицы примера длина сохраняется.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
