# 24. Методы строк: очистка, регистр и замена

После урока вы сможете: Вызывать метод и сохранять результат преобразования.

Нужные знания: Строки, сравнение и неизменяемость

## От задачи к способу решения

**Метод** — операция, вызываемая через значение: `text.lower()`. Слева от точки находится строка, справа — имя метода со скобками. Уже знакомая функция len вызывается иначе: `len(text)`. Это две формы обращения к готовым операциям.

`lower()` создаёт строку со строчными буквами, `upper()` — с прописными. `strip()` убирает пробельные символы по обоим краям. Он не удаляет пробелы внутри предложения. `lstrip()` и `rstrip()` обрабатывают только одну сторону. Без аргумента речь идёт не только об обычном пробеле, но и о других пробельных символах.

Задача: пользователь ввёл два пробела, слово ПоМоЩь и ещё два пробела. Для сравнения с известной командой помощь внешние пробелы и регистр не должны мешать. Сначала strip даёт ПоМоЩь, затем lower даёт помощь. Такие преобразования по заранее выбранным правилам называются **нормализацией**.

Методы не меняют существующую строку. Запись `text.strip()` без сохранения вычислит новый результат и потеряет его. Пишите `cleaned = text.strip()`, затем `command = cleaned.lower()`. Цепочка `text.strip().lower()` допустима, но сначала полезно увидеть два отдельных шага и понять, к какому результату применяется второй метод.

`replace(old, new)` создаёт текст, где заменены все вхождения old. Третий аргумент ограничивает число замен. Например, `'a-a-a'.replace('-', ':', 1)` даёт a:a-a. Это преобразование, а не поиск первого индекса. `strip('ab')` тоже не удаляет готовое слово ab: аргумент задаёт набор символов, которые можно снимать с краёв. Для удаления определённого фрагмента нужны другие договорённости.

Методы `isalpha()`, `isdigit()` и `isalnum()` отвечают, состоит ли непустая строка соответственно из букв, цифр или букв и цифр. Они учитывают Unicode, поэтому isdigit не ограничивается десятью латинскими символами 0–9. Для такого узкого формата используйте явные границы или проверку принадлежности строке '0123456789'. Для отрицательной записи '-12' isdigit возвращает False из-за знака.

Нормализация уместна только по правилам задачи. Пароль и точный идентификатор нельзя произвольно приводить к нижнему регистру: можно изменить их смысл.

## Задача и формат данных

Нормализовать название команды: убрать внешние пробелы и сделать буквы строчными.

**Ввод:** Одна строка команды.

**Вывод:** Очищенная команда строчными буквами.

**Допустимые данные:** До 100 символов; допускается пустая строка.

Вход сквозного примера:

```text
  ПоМоЩь  
```

Ожидаемый вывод:

```text
помощь
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | Прочитать строку вместе с пробелами | text содержит: два пробела, ПоМоЩь, два пробела |
| 2 | strip убирает только внешние пробелы | cleaned = ПоМоЩь |
| 3 | lower создаёт строчную запись | command = помощь |

## Полная программа

```python
text = input()
cleaned = text.strip()
command = cleaned.lower()
print(command)
```

## Как читать реализацию

text сохраняет исходный ввод, cleaned — результат очистки, command — результат смены регистра. Это помогает проверить каждое преобразование. print(command) не добавляет кавычки. Пустая очищенная команда выводится как пустая строка.

## Почему работает и сколько действий требуется

strip удаляет только оговорённые края, lower меняет регистр букв, следовательно получаем требуемую нормализованную запись. Для длины L каждый проход требует линейной работы в худшем случае; создаваемые строки требуют памяти порядка L.

## Границы и частые ошибки

Методы возвращают новые строки. Unicode-регистр не всегда сохраняет число кодовых точек, поэтому после преобразования индексы лучше вычислять заново. Для простой кириллицы примера длина сохраняется.
