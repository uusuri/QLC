# Проверка урока 16

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: Цикл чтения и if

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Найти наибольшую из n целых температур. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Найти максимум без ошибочной опоры на ноль. |
| Сквозной пример | Первый пример main: Все отрицательные. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: -5 не превосходит -3: замена не нужна; результат: best = -3 |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | best хранит максимум прочитанной части. value — только очередное число. В этой программе i обозначает номер повторения, а не номер самой температуры: первая уже прочитана отдельно. Для индексов конкретных объектов нужно осознанно выбрать диапазон. |
| Корректность | Первый кандидат максимален в наборе из одного числа. На каждом шаге сравнение сохраняет большее из прежнего максимума и нового значения. После всех чтений кандидат максимален во всём наборе. Работа пропорциональна n, память постоянна. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: Для пустого набора максимум здесь не определён. Если задача разрешит n = 0, нужно задать отдельный ответ, например НЕТ ДАННЫХ, а не придумывать максимум 0.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
