# 16. Наибольшее значение: правильно выбираем начало

После урока вы сможете: Найти максимум без ошибочной опоры на ноль.

Нужные знания: Цикл чтения и if

## От задачи к способу решения

Сумма начинает с нуля, но максимум так начать нельзя. Если все температуры −8, −3, −5, ноль не встречается во входе и не должен стать ответом. Начальное значение должно иметь обоснование, а не быть привычной цифрой.

Прямой способ — сохранить все данные и затем искать самое большое число. Но для ответа достаточно помнить самого сильного кандидата из уже прочитанной части. Назовём его `best`. Первую температуру читаем до цикла и делаем первым кандидатом. Это возможно, потому что условие обещает хотя бы одну температуру.

Затем читаем остальные n − 1 значения. Если новое value больше best, заменяем кандидата. Если меньше или равно, прежний кандидат всё ещё максимален среди просмотренных. На следующем шаге нам не нужны старые проигравшие значения: их превосходит уже сохранённый best.

Пройдём −8, −3, −5. После первого чтения best = −8. Второе значение −3 больше −8, поэтому best меняется на −3. Третье −5 меньше −3, поэтому замены нет. Итог −3 действительно самый большой, хотя все числа отрицательны.

Обратите внимание на число чтений. Одно значение получено до цикла, поэтому range(n − 1) читает ровно остальные. Цикл range(n) после первого чтения запросил бы лишнюю температуру. При n = 1 цикл пустой, и первый кандидат сразу является ответом.

При равенстве строгий знак `>` оставляет более раннего кандидата. Пока нужен только максимум, это не меняет значение ответа. Если надо вернуть номер первого появления максимума, выбор строгого знака становится частью правила. Имя лучшего номера и правило его обновления добавим в упражнении.

Так появляется распространённая идея: хранить не всю историю, а достаточно информации о ней. Но это решение подходит только когда прошлые значения можно безопасно забыть. Если позже нужен полный список отсортированных температур, одного best уже мало.

## Задача и формат данных

Найти наибольшую из n целых температур.

**Ввод:** n первой строкой; затем n целых температур отдельными строками.

**Вывод:** Наибольшая температура.

**Допустимые данные:** 1 <= n <= 10000; температуры от −100 до 100.

Вход сквозного примера:

```text
3
-8
-3
-5
```

Ожидаемый вывод:

```text
-3
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | Первое значение становится допустимым кандидатом | best = -8 |
| 2 | -3 больше -8: найден более сильный кандидат | best = -3 |
| 3 | -5 не превосходит -3: замена не нужна | best = -3 |

## Полная программа

```python
n = int(input())
best = int(input())
for i in range(n - 1):
    value = int(input())
    if value > best:
        best = value
print(best)
```

## Как читать реализацию

best хранит максимум прочитанной части. value — только очередное число. В этой программе i обозначает номер повторения, а не номер самой температуры: первая уже прочитана отдельно. Для индексов конкретных объектов нужно осознанно выбрать диапазон.

## Почему работает и сколько действий требуется

Первый кандидат максимален в наборе из одного числа. На каждом шаге сравнение сохраняет большее из прежнего максимума и нового значения. После всех чтений кандидат максимален во всём наборе. Работа пропорциональна n, память постоянна.

## Границы и частые ошибки

Для пустого набора максимум здесь не определён. Если задача разрешит n = 0, нужно задать отдельный ответ, например НЕТ ДАННЫХ, а не придумывать максимум 0.
