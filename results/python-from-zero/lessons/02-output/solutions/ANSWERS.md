# 02. Вывод: несколько значений, sep и end: ответы

## Задание 1

1-2-3. Два разделителя соединяют три части.

## Задание 2

sep действует между аргументами одного print. end действует после последнего аргумента и влияет на начало вывода следующего print.

## Задание 3

Разделитель — косая черта.

```python
print('01', '10', '2026', sep='/')
```

## Задание 4

Первый print не завершает строку.

```python
print('A', end='')
print('B')
```
