# 02. Вывод: несколько значений, sep и end

После урока вы сможете: Управлять пробелами и переносами строк в результате.

Нужные знания: Запуск файла и print с одной строкой

## От задачи к способу решения

В прошлом уроке один `print` печатал одну строку. Теперь хотим собрать сообщение из нескольких частей. Можно заранее написать весь текст, но позже части будут приходить от пользователя. Поэтому научимся передавать `print` несколько значений.

**Аргумент** — значение, которое передают команде в скобках. В `print('А', 'Б')` два аргумента. Запятая в коде разделяет аргументы, а на экране между ними по умолчанию появляется пробел. Запятые вывода не создают.

`sep` задаёт разделитель **между** аргументами. В `print('А', 'Б', sep=':')` разделитель — двоеточие. Крайние значения не получают лишнего двоеточия. `end` задаёт то, что появится **после всех** аргументов. Обычно это перенос строки. Если задать `end=' '`, следующий `print` продолжит ту же строку после пробела. Имена `sep` и `end` с `=` — настройки вызова, а не отдельные сообщения.

Перенос строки внутри текста записывается как `\n`. Обратная косая черта сообщает Python, что вместе с `n` это специальная запись одного символа. `print('А\nБ')` покажет две строки. Обычный символ обратной косой черты можно записать как `\\`. Одинарные и двойные кавычки равноправны: удобно обрамить текст двойными кавычками, если внутри есть одинарная.

Комментарий начинается с `#` и длится до конца строки кода. Python не выполняет комментарий. Он объясняет человеку замысел, например почему выбран необычный разделитель. Если `#` находится внутри кавычек, это часть текста.

Соберём карточку по шагам. Название занимает отдельную строку. Два слова соединяем `sep=':'`. Последнее сообщение собираем двумя командами: первая оставляет после себя пробел, вторая заканчивает строку. Разделитель и завершение решают разные задачи; их смешение — частая причина лишних пробелов в ответе.

## Задача и формат данных

Напечатать короткую карточку: название, два слова через двоеточие и сообщение в одну строку.

**Ввод:** Ввод не требуется.

**Вывод:** Три строки, как в примере.

**Допустимые данные:** Текст задан прямо в программе.

Вход сквозного примера — пустой, программа не запрашивает данные:

```text

```

Ожидаемый вывод:

```text
Карточка
ученик:Python

```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | Обычный print заканчивает строку | Карточка |
| 2 | sep ставит двоеточие между двумя словами | ученик:Python |
| 3 | end оставляет пробел вместо переноса | Учимся и пробел |
| 4 | Последний print продолжает начатую строку | Учимся вместе |

## Полная программа

```python
print('Карточка')
print('ученик', 'Python', sep=':')
print('Учимся', end=' ')
print('вместе')
```

## Как читать реализацию

Во втором вызове два текста, поэтому разделитель применяется один раз. В третьем вызове один текст: `sep` здесь ничего бы не изменил. Завершение `end=' '` заменяет привычный перенос, и четвёртая команда дописывает сообщение. Если использовать `end=''`, между словами не появится даже пробела.

В задачах с точным ответом пробелы и переносы — часть договорённости. Сначала выпишите желаемый результат, затем подберите команды для него. Не добавляйте приветствие, если задание требует только число.

## Почему работает и сколько действий требуется

Каждый фрагмент выводится в заданном порядке, sep помещается между частями, end — после вызова. Печатается фиксированное число символов; работа и память малы и не зависят от входа.

## Границы и частые ошибки

Пустой sep соединяет части вплотную. Пустой end позволяет продолжить строку. Конечный перенос строки стандартен для обычного print.
