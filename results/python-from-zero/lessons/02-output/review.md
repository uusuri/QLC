# Проверка урока 02

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: Запуск файла и print с одной строкой

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Напечатать короткую карточку: название, два слова через двоеточие и сообщение в одну строку. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Управлять пробелами и переносами строк в результате. |
| Сквозной пример | Первый пример main: Разделитель и продолжение строки. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: Последний print продолжает начатую строку; результат: Учимся вместе |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | Во втором вызове два текста, поэтому разделитель применяется один раз. В третьем вызове один текст: `sep` здесь ничего бы не изменил. Завершение `end=' '` заменяет привычный перенос, и четвёртая команда дописывает сообщение. Если использовать `end=''`, между словами не появится даже пробела. |
| Корректность | Каждый фрагмент выводится в заданном порядке, sep помещается между частями, end — после вызова. Печатается фиксированное число символов; работа и память малы и не зависят от входа. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: Пустой sep соединяет части вплотную. Пустой end позволяет продолжить строку. Конечный перенос строки стандартен для обычного print.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
