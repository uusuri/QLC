# 14. Повторение известное число раз: for и range: ответы

## Задание 1

1, 3, 5. Число 7 исключено.

## Задание 2

Первый диапазон пытается идти вверх от 5 до меньшей границы. Второй идёт вниз и выдаёт 5, 4, 3, 2.

## Задание 3

Для каждого текущего числа вычисляем его квадрат.

```python
n = int(input())
for number in range(1, n + 1):
    print(number ** 2)
```

## Задание 4

Конец 0 исключён, шаг отрицательный.

```python
n = int(input())
for number in range(n, 0, -1):
    print(number)
```
