# 14. Повторение известное число раз: for и range

После урока вы сможете: Записать повторение и правильно выбрать границы range.

Нужные знания: Условия, блоки и целые числа

## От задачи к способу решения

Для трёх заданий можно написать три команды print. Для ста заданий это неудобно, а количество заранее приходит от пользователя. **Цикл** — конструкция, которая повторяет блок команд. **Итерация** — одно выполнение этого блока.

`for number in range(1, n + 1):` означает: последовательно взять значения из заданного диапазона, каждый раз связать очередное значение с number и выполнить блок. Имя number — обычная переменная, получающая новое значение на каждом шаге. После двоеточия команды тела цикла пишутся с отступом, как в if.

`range(stop)` задаёт целые от 0 до stop, не включая stop. `range(start, stop)` задаёт от start до stop, также не включая stop. Поэтому для номеров от 1 до n нужно `range(1, n + 1)`. Конец диапазона исключён: `range(1, 3)` содержит только 1 и 2.

Третий аргумент — **шаг**, величина изменения: `range(2, 9, 2)` даёт 2, 4, 6, 8. Отрицательный шаг позволяет идти вниз: `range(3, 0, -1)` даёт 3, 2, 1. Шаг ноль запрещён. Если направление не соответствует границам, диапазон пуст: `range(3, 0)` не выдаёт значений, потому что стандартный шаг положительный.

В сквозном примере n = 3, значит number по очереди получает 1, 2 и 3. Во время каждой итерации print показывает текущее значение. Команда после цикла без отступа выполнилась бы лишь после всех итераций; команда внутри — на каждом шаге. Это позволяет решить, где печатать промежуточные и итоговые результаты.

range не создаёт заранее список всех чисел: он представляет правило диапазона. Цикл получает значения последовательно. Но сами команды всё равно выполняются n раз; краткая запись не означает мгновенную работу для огромного n. Для нашего предела тысяча повторений достаточно небольшая величина.

## Задача и формат данных

Вывести номера заданий от 1 до n, каждый на своей строке.

**Ввод:** Одно число n.

**Вывод:** Числа 1, 2, ..., n отдельными строками; при n = 0 вывод пустой.

**Допустимые данные:** 0 <= n <= 1000.

Вход сквозного примера:

```text
3
```

Ожидаемый вывод:

```text
1
2
3
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | n = 3, диапазон от 1 до 4 без 4 | Следующие значения: 1, 2, 3 |
| 2 | Первая итерация | number = 1, вывод 1 |
| 3 | Вторая итерация | number = 2, вывод 2 |
| 4 | Третья итерация и конец диапазона | number = 3, вывод 3 |

## Полная программа

```python
n = int(input())
for number in range(1, n + 1):
    print(number)
```

## Как читать реализацию

n задаёт размер диапазона, number — текущий номер. Менять number вручную внутри такого цикла не требуется: на следующей итерации for возьмёт очередное значение range. При n = 0 диапазон range(1, 1) пуст, поэтому тело не выполняется.

## Почему работает и сколько действий требуется

Диапазон содержит ровно все нужные номера в правильном порядке, каждый посещается один раз. Цикл заканчивается после n итераций. Число действий растёт пропорционально n; служебное состояние и range занимают постоянную память, результат выводится постепенно.

## Границы и частые ошибки

Ошибка n вместо n + 1 пропускает последний номер. При пустом диапазоне переменная цикла может не получить значения, поэтому нельзя рассчитывать на неё после цикла.
