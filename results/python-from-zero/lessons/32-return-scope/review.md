# Проверка урока 32

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: def, вызовы и списки

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Вычислить стоимость товара после скидки в процентах. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Сделать вычисляющую функцию, использовать её ответ и объяснить область имён. |
| Сквозной пример | Первый пример main: Скидка. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: Основная часть сохраняет и форматирует ответ; результат: 170.00 |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | price и percent локальны вызову, original_price и discount относятся к основной части. return передаёт число, а формат вывода выбирает основная программа. Аргумент по умолчанию в этой основной программе не используется, потому что оба значения заданы явно, но вызов discounted_price(200) тоже допустим. |
| Корректность | После скидки p процентов остаётся 100 - p процентов цены, что прямо выражает формула. Для допустимого диапазона доля неотрицательна. Число действий и глубина вызова постоянны; для вывода применяется приближённая арифметика float и оговорённое форматирование. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: Для точных денежных правил округления нужен отдельный контракт: этот учебный расчёт не задаёт банковский порядок округления копеек. return None и отсутствие return не являются числовым результатом.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
