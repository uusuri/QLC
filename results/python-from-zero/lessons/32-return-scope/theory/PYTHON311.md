# 32. Возвращаем результат: return, локальные имена и параметры

После урока вы сможете: Сделать вычисляющую функцию, использовать её ответ и объяснить область имён.

Нужные знания: def, вызовы и списки

## От задачи к способу решения

Функция может не печатать, а **возвращать** значение вызывающему коду. Команда `return expression` вычисляет expression, завершает текущий вызов и передаёт результат. Затем основная программа сама решает, печатать его, сохранить или использовать в другом расчёте.

Для цены 200 и скидки 15 процентов остаётся 85 процентов цены: 200 * 85 / 100 = 170. Определим discounted_price(price, percent). Параметры отвечают на два входных вопроса, результат — новая цена. Можно вызвать эту функцию в нескольких местах с разными аргументами без копирования формулы.

Разница с print принципиальна. Если функция только печатает 170, это сообщение на экране не становится числом в переменной вызывающего кода. Функция без выполненного return возвращает `None` — специальное значение отсутствующего результата. Поэтому `answer = print(170)` сначала печатает 170, а answer становится None.

**Область видимости** — часть программы, где доступно имя. Параметры и присваивания внутри функции создают локальные имена. После завершения вызова нельзя рассчитывать на доступ к его параметрам из основной части. Передавайте нужные данные явно и возвращайте результат. В этой программе внешняя переменная original_price передаётся внутреннему price, хотя имена различаются.

**Аргумент по умолчанию** позволяет не передавать одно значение. Запись `def discounted_price(price, percent=0):` задаёт нулевую скидку при вызове с одной ценой. По умолчанию не следует использовать изменяемый список: такой объект создаётся один раз при определении и может сохранять изменения между вызовами. Для нашего числового значения этой проблемы нет.

Передача списка не копирует его. Если функция выполнит append над переданным списком, изменение увидит вызывающий код. Чистая вычисляющая функция не меняет чужие данные и при тех же аргументах получает тот же ответ; такую функцию легче проверять отдельно. Для скидки выберем именно вычисляющую форму.

return может находиться в if и выполнять ранний выход. Команды после выполненного return в этом вызове уже не выполняются. Несколько return допустимы для разных случаев; важно, чтобы у всех разрешённых входов был определён нужный результат.

## Задача и формат данных

Вычислить стоимость товара после скидки в процентах.

**Ввод:** Целая цена и целый процент скидки на отдельных строках.

**Вывод:** Новая цена с двумя знаками после точки.

**Допустимые данные:** Цена от 0 до 1000000; процент от 0 до 100.

Вход сквозного примера:

```text
200
15
```

Ожидаемый вывод:

```text
170.00
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | Прочитать исходные данные | original_price = 200, discount = 15 |
| 2 | Вызов передаёт данные параметрам | price = 200, percent = 15 |
| 3 | return вычисляет оставшуюся долю | Возвращается 170.0 |
| 4 | Основная часть сохраняет и форматирует ответ | 170.00 |

## Полная программа

```python
def discounted_price(price, percent=0):
    return price * (100 - percent) / 100

original_price = int(input())
discount = int(input())
answer = discounted_price(original_price, discount)
print(f'{answer:.2f}')
```

## Как читать реализацию

price и percent локальны вызову, original_price и discount относятся к основной части. return передаёт число, а формат вывода выбирает основная программа. Аргумент по умолчанию в этой основной программе не используется, потому что оба значения заданы явно, но вызов discounted_price(200) тоже допустим.

## Почему работает и сколько действий требуется

После скидки p процентов остаётся 100 - p процентов цены, что прямо выражает формула. Для допустимого диапазона доля неотрицательна. Число действий и глубина вызова постоянны; для вывода применяется приближённая арифметика float и оговорённое форматирование.

## Границы и частые ошибки

Для точных денежных правил округления нужен отдельный контракт: этот учебный расчёт не задаёт банковский порядок округления копеек. return None и отсутствие return не являются числовым результатом.
