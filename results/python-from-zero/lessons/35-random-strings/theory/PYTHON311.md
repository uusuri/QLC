# 35. Мини-проект: учебный генератор паролей

После урока вы сможете: Создавать строку заданной длины из разрешённого набора и проверять свойства результата.

Нужные знания: Модуль random, функции, списки и join

## От задачи к способу решения

Это упражнение на случайный выбор и сборку текста. random подходит для учебной игры, но не для настоящих секретных паролей: его последовательность можно предсказывать по состоянию. Для реальных секретов нужен специально предназначенный генератор, например модуль secrets. Здесь изучаем механику строки и не обещаем безопасность результата.

Зафиксируем **алфавит** — строку всех разрешённых символов. `random.choice(alphabet)` возвращает один случайно выбранный элемент непустой последовательности. Повторяя выбор length раз, получим length символов. Один и тот же символ может выпадать несколько раз: выбирать с повторениями разрешено.

Чтобы не наращивать неизменяемую строку на каждом шаге, будем добавлять выбранные символы в список parts. Затем `''.join(parts)` соединит их без разделителя. Функция generate_password(length) возвращает строку; основной код задаёт seed, вызывает её и печатает результат.

Воспроизводимый пример: в фактически проверенной среде Python 3.13.0 seed 7 и длина 8 дают u8jzPde0. Seed не является длиной или секретом; он выбирает начальное состояние случайной последовательности. Для учебного примера фиксированный seed позволяет сравнивать запуски. Совпадение конкретной последовательности разных версий random не является общим обещанием курса; отчёт фиксирует использованную среду.

Генератор не гарантирует хотя бы одну цифру, заглавную и строчную букву в каждой строке. Он только разрешает эти символы. Например, при длине 1 выполнить требование трёх категорий вообще невозможно. Если правило требует каждую категорию, это отдельная задача: нужно изменить построение и явно определить минимальную длину.

Проверять такой результат надо по нескольким уровням. При фиксированной среде и seed можно сравнить точный пример. Независимо от последовательности нужно проверить длину и принадлежность каждого символа разрешённому набору. Нельзя считать правильной только красивую строку из демонстрации: функция должна работать и при длине ноль.

Для length = 0 список частей пуст, join возвращает пустую строку, а print выводит только перевод строки. Это предусмотренный результат, не ошибка генерации.

## Задача и формат данных

Сгенерировать учебную строку из латинских букв обоих регистров и цифр.

**Ввод:** Seed и длина отдельными строками.

**Вывод:** Одна сгенерированная строка заданной длины.

**Допустимые данные:** 0 <= seed <= 1000000; 0 <= length <= 100; набор — латинские a–z, A–Z, 0–9.

Вход сквозного примера:

```text
7
8
```

Ожидаемый вывод:

```text
u8jzPde0
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | Задать начальное состояние генератора | seed = 7, length = 8 |
| 2 | Выполнить восемь выборов в проверенной среде | parts = ['u', '8', 'j', 'z', 'P', 'd', 'e', '0'] |
| 3 | Соединить без разделителей | u8jzPde0 |

## Полная программа

```python
import random

def generate_password(length):
    alphabet = 'abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789'
    parts = []
    for i in range(length):
        parts.append(random.choice(alphabet))
    return ''.join(parts)

seed = int(input())
length = int(input())
random.seed(seed)
print(generate_password(length))
```

## Как читать реализацию

Алфавит непустой, поэтому choice имеет допустимый источник. parts хранит ровно по одному элементу на итерацию. random.seed находится вне функции перед первым вызовом, поэтому функция не сбрасывает генератор при каждой новой строке.

## Почему работает и сколько действий требуется

Каждый выбранный символ принадлежит алфавиту, итераций ровно length, join не добавляет посторонних символов. Время и память линейны по длине. Это доказывает формат строки, но не криптографическую стойкость и не обязательное присутствие каждой категории.

## Границы и частые ошибки

Фиксированный seed нужен проверке, а не реальным паролям. Для непустой строки требуется положительная длина; пустой алфавит недопустим для choice. Конкретные строки проверены в указанном Python.
