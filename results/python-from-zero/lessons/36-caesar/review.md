# Проверка урока 36

Авторская самопроверка, не эксперимент с реальным студентом. Исходные знания: Строки, остаток, функции и join

| Проверка | Конкретное свидетельство в финальном тексте |
| --- | --- |
| Постановка | Сдвинуть латинские буквы на заданное число позиций, сохранив регистр. |
| Понятия | В разделе «От задачи к способу решения» новые операции объяснены до полной реализации; исходные знания перечислены перед разделом. |
| Выбор метода | Перевести буквенное правило в индексы и сохранить посторонние символы. |
| Сквозной пример | Первый пример main: Оба регистра и знаки. Те же данные находятся в таблице и проверяемом описании. |
| Ручной проход | Таблица «Пройдём пример руками»: ! не буква: сохранить; результат: Cb-b! |
| Реализация | Полная программа дословно совпадает с code/PYTHON311/main.py; содержит все чтения и вывод по контракту. |
| Разбор | start выбирается по регистру. position обозначает номер внутри своего алфавита, а не общий Unicode-код. new_position всегда от 0 до 25. Ранний return для постороннего символа не позволяет использовать не заданный start. caesar ничего не печатает, её результат выводит основная часть. |
| Корректность | Для каждой латинской буквы вычисляется её номер, круговой сдвиг и обратное преобразование в букву того же регистра. Другие символы остаются неизменными. Каждый символ обработан один раз, значит время линейно по длине L; список частей и строка результата занимают линейную дополнительную память. |
| Сложность | В «Почему работает и сколько действий требуется» оценка связана с количеством проходов и фактически хранимыми данными. |
| Практика | Вопросы 1–2 проверяют механизм и причину; задачи 3–4 требуют реализации и изменения условия. Решения отделены. |
| Языковая версия | Только Python, синтаксис совместим с Python 3.11. Фактический интерпретатор указан в verification.json, совместимость не выдается за запуск 3.11. |

Ограничения: Применимость формулы ord ограничена двумя подряд расположенными ASCII-алфавитами. Для русского алфавита с ё удобнее задать явную строку алфавита и искать позицию в ней.

Фактические запуски — verification.json. Структурная проверка скилла не доказывает понимание студентом.
