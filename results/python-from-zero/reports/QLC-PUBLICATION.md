# Курс Python опубликован в QLC

Курс: [Python с нуля](http://localhost:3000/courses/course-4).

8 модулей, 38 опубликованных уроков. В каждом уроке — четыре отдельных задания во вкладке «Практика»: всего 152 задания (76 CODE, 70 TEST, 6 NUMERIC).

Упражнения и ответы убраны из теории. Для каждого задания сохранены три последовательные наводящие подсказки. Готовые ответы и полные решения из подсказок удалены; это проверено отдельно для всех 152 заданий. У CODE сохранены язык PYTHON311, стартовый комментарий и примеры ввода-вывода; выполнение Python не подключалось по прямому указанию пользователя. У TEST и NUMERIC сохранены штатные варианты и правильные ответы платформы.

Все 38 текстов и все 152 задания прочитаны обратно из базы и сверены с подготовленными данными. Через публичный API проверены списки четырёх задач у каждого из 38 уроков. Другие курсы и настройки курса Python не менялись; исходники приложения не изменялись. Интерфейс в браузере не проверялся по просьбе пользователя.
