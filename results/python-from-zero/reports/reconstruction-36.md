# 36. Мини-проект: шифр Цезаря и круговой сдвиг

После урока вы сможете: Перевести буквенное правило в индексы и сохранить посторонние символы.

Нужные знания: Строки, остаток, функции и join

## От задачи к способу решения

Шифр Цезаря заменяет букву другой буквой через заданное число позиций алфавита. При сдвиге 2: a превращается в c, b в d, y в a, z в b. После конца алфавита движение продолжается с начала. Это учебное преобразование легко обратить и оно не защищает настоящую переписку.

Сначала работаем с одной строчной буквой. Дадим буквам номера от 0 до 25: a — 0, b — 1, ..., z — 25. После прибавления сдвига номер может выйти за границу. Остаток на 26 возвращает его в допустимый круг: для z и сдвига 2 получаем (25 + 2) % 26 = 1, то есть b.

`ord(character)` возвращает целочисленный код одной кодовой точки Unicode. `chr(number)` получает строку с кодовой точкой заданного кода. Латинские ASCII-буквы a–z идут подряд в таблице кодов. Поэтому номер буквы равен `ord(character) - ord('a')`, а новая буква получается через chr от начала алфавита плюс новый номер. Для прописных используем начало 'A' отдельно.

Нельзя применять такой расчёт ко всему Unicode: чужие буквы и знаки не обязаны находиться в этих непрерывных 26 позициях. Проверим сначала диапазон 'a' <= character <= 'z', затем прописной диапазон. Все остальные символы возвращаем неизменными. Русские буквы в этой конкретной программе не шифруются, потому что условие задаёт только латиницу.

Сквозной пример Az-z! со сдвигом 2 даёт Cb-b!. A сдвигается внутри прописного алфавита в C. z оборачивается в b. Дефис и восклицательный знак сохраняются. Это одновременно проверяет обе ветви регистров и сохранение посторонних символов.

Функция shift_character решает задачу одного элемента. Функция caesar проходит весь текст, собирает части и возвращает строку. Такое разделение позволяет сначала проверить буквы на границе, а затем переносить работу на любую длину текста.

Отрицательный сдвиг означает движение назад. При положительном делителе 26 остаток в Python неотрицателен: для a и −1 получаем номер 25, букву z. Для расшифровки можно вызвать тот же алгоритм с противоположным сдвигом; новое правило не требует отдельного перебора букв.

## Задача и формат данных

Сдвинуть латинские буквы на заданное число позиций, сохранив регистр.

**Ввод:** Сдвиг целым числом первой строкой, текст второй.

**Вывод:** Преобразованный текст одной строкой.

**Допустимые данные:** −1000000 <= shift <= 1000000; до 1000 символов; меняются только ASCII a–z и A–Z.

Вход сквозного примера:

```text
2
Az-z!
```

Ожидаемый вывод:

```text
Cb-b!
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | A: номер 0, после сдвига 2, регистр сохраняется | C |
| 2 | z: (25 + 2) % 26 = 1 | Cb |
| 3 | Дефис не буква: сохранить, затем ещё z сдвинуть в b | Cb-b |
| 4 | ! не буква: сохранить | Cb-b! |

## Почему работает и сколько действий требуется

Для каждой латинской буквы вычисляется её номер, круговой сдвиг и обратное преобразование в букву того же регистра. Другие символы остаются неизменными. Каждый символ обработан один раз, значит время линейно по длине L; список частей и строка результата занимают линейную дополнительную память.

## Границы и частые ошибки

Применимость формулы ord ограничена двумя подряд расположенными ASCII-алфавитами. Для русского алфавита с ё удобнее задать явную строку алфавита и искать позицию в ней.
