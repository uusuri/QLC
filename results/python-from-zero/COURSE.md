# 01. Что такое программа и как её запустить

После урока вы сможете: Сохранить файл Python, запустить его и отличить код от результата.

Нужные знания: Никаких знаний программирования не требуется.

## От задачи к способу решения

Программирование начинается с точного описания действий. Представьте просьбу «приготовь чай». Человек сам догадается взять чашку, но программе нужны конкретные команды. **Алгоритм** — понятная последовательность шагов для получения результата. **Программа** — запись этих шагов на языке, который умеет исполнять компьютер. Python — один из таких языков. **Интерпретатор** — программа, которая выполняет команды Python.

Пока достаточно следующей картины: вы пишете текст → сохраняете его в файл → запускаете Python → видите результат. Текст программы называется **исходным кодом**. Результат на экране называется **выводом**. Написанная в редакторе строка ещё не означает, что компьютер её выполнил.

### Подготовьте место для работы

Откройте [официальную страницу Python](https://www.python.org/downloads/), выберите Python 3 для своей системы и установите его. Номер Python 3 может отличаться от номера в примерах; в этом курсе нет возможностей новее Python 3.11. В Windows можно включить пункт добавления Python в PATH, если установщик его предлагает. Он нужен для запуска из терминала, но для первого урока хватит IDLE. В macOS установщик с python.org обычно включает IDLE. В Linux IDLE иногда устанавливается отдельным пакетом средствами системы. Не нужно менять системный Python.

Найдите приложение IDLE. Его окно **Shell** показывает приглашение `>>>`: это место для немедленного выполнения отдельных команд. Через File → New File откройте другое окно — редактор. Вставьте туда программу ниже. Сохраните файл с именем `first.py` в отдельную папку учебных работ. Расширение `.py` помогает узнать файл программы Python. Выберите Run → Run Module; обычное сочетание клавиш — F5. Результат появится в Shell.

Если Python уже доступен в вашем учебном редакторе, создайте там файл `.py` и воспользуйтесь кнопкой запуска. В терминале из папки файла можно выполнить `python3 first.py`; в Windows часто используется `py first.py`. Терминал — окно для команд операционной системе. Эти команды запуска не надо вставлять внутрь файла Python.

### Первая команда

`print` означает «вывести». Скобки содержат то, что нужно показать. Текст в кавычках называется **строкой**. Кавычки обозначают границы текста и сами не печатаются. В примерах используются обычные прямые кавычки, а не типографские «ёлочки».

Хотим получить два сообщения. На бумаге алгоритм состоит из двух действий: вывести первое сообщение, затем второе. Две команды `print` записывают именно этот алгоритм. Здесь не нужно понимать все возможности `print`: сначала научимся запускать небольшой понятный файл.

# 02. Вывод: несколько значений, sep и end

После урока вы сможете: Управлять пробелами и переносами строк в результате.

Нужные знания: Запуск файла и print с одной строкой

## От задачи к способу решения

В прошлом уроке один `print` печатал одну строку. Теперь хотим собрать сообщение из нескольких частей. Можно заранее написать весь текст, но позже части будут приходить от пользователя. Поэтому научимся передавать `print` несколько значений.

**Аргумент** — значение, которое передают команде в скобках. В `print('А', 'Б')` два аргумента. Запятая в коде разделяет аргументы, а на экране между ними по умолчанию появляется пробел. Запятые вывода не создают.

`sep` задаёт разделитель **между** аргументами. В `print('А', 'Б', sep=':')` разделитель — двоеточие. Крайние значения не получают лишнего двоеточия. `end` задаёт то, что появится **после всех** аргументов. Обычно это перенос строки. Если задать `end=' '`, следующий `print` продолжит ту же строку после пробела. Имена `sep` и `end` с `=` — настройки вызова, а не отдельные сообщения.

Перенос строки внутри текста записывается как `\n`. Обратная косая черта сообщает Python, что вместе с `n` это специальная запись одного символа. `print('А\nБ')` покажет две строки. Обычный символ обратной косой черты можно записать как `\\`. Одинарные и двойные кавычки равноправны: удобно обрамить текст двойными кавычками, если внутри есть одинарная.

Комментарий начинается с `#` и длится до конца строки кода. Python не выполняет комментарий. Он объясняет человеку замысел, например почему выбран необычный разделитель. Если `#` находится внутри кавычек, это часть текста.

Соберём карточку по шагам. Название занимает отдельную строку. Два слова соединяем `sep=':'`. Последнее сообщение собираем двумя командами: первая оставляет после себя пробел, вторая заканчивает строку. Разделитель и завершение решают разные задачи; их смешение — частая причина лишних пробелов в ответе.

## Задача и формат данных

Напечатать короткую карточку: название, два слова через двоеточие и сообщение в одну строку.

**Ввод:** Ввод не требуется.

**Вывод:** Три строки, как в примере.

**Допустимые данные:** Текст задан прямо в программе.

Вход сквозного примера — пустой, программа не запрашивает данные:

```text

```

Ожидаемый вывод:

```text
Карточка
ученик:Python
Учимся вместе
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | Обычный print заканчивает строку | Карточка |
| 2 | sep ставит двоеточие между двумя словами | ученик:Python |
| 3 | end оставляет пробел вместо переноса | Учимся и пробел |
| 4 | Последний print продолжает начатую строку | Учимся вместе |

## Полная программа

```python
print('Карточка')
print('ученик', 'Python', sep=':')
print('Учимся', end=' ')
print('вместе')
```

## Как читать реализацию

Во втором вызове два текста, поэтому разделитель применяется один раз. В третьем вызове один текст: `sep` здесь ничего бы не изменил. Завершение `end=' '` заменяет привычный перенос, и четвёртая команда дописывает сообщение. Если использовать `end=''`, между словами не появится даже пробела.

В задачах с точным ответом пробелы и переносы — часть договорённости. Сначала выпишите желаемый результат, затем подберите команды для него. Не добавляйте приветствие, если задание требует только число.

## Почему работает и сколько действий требуется

Каждый фрагмент выводится в заданном порядке, sep помещается между частями, end — после вызова. Печатается фиксированное число символов; работа и память малы и не зависят от входа.

## Границы и частые ошибки

Пустой sep соединяет части вплотную. Пустой end позволяет продолжить строку. Конечный перенос строки стандартен для обычного print.

# 03. Ввод, переменные и присваивание

После урока вы сможете: Прочитать строку, сохранить её под именем и использовать в ответе.

Нужные знания: print, строки и порядок команд

## От задачи к способу решения

Программа с фиксированным именем отвечает одинаково всем. Хотим, чтобы ответ зависел от человека. **Ввод** — данные, которые программа получает во время работы. `input()` ждёт одну строку ввода и возвращает её как текст. Нажатие Enter завершает ввод; сам конечный перенос строки не становится частью возвращённого текста. Пробелы внутри строки сохраняются.

Результат нужно запомнить. **Переменная** — имя, по которому программа получает значение. Запись `name = input()` означает: сначала выполнить правую часть, затем связать имя `name` с полученной строкой. `=` называется **присваиванием**. Это действие, а не утверждение математического равенства.

В `print(name)` кавычек нет: нужно взять значение переменной. В `print('name')` кавычки есть: нужно вывести четыре буквы `name`. Это два разных запроса. Имена пишем латинскими буквами, цифрами и подчёркиванием; цифра не может быть первой. Регистр важен: `name` и `Name` — разные имена. Выбирайте смысловые имена: `city` для города понятнее, чем `x`.

Присваивание может заменить прежнее значение. После `word = 'да'`, затем `word = 'нет'` имя `word` связано с `нет`. Оно не хранит историю замен. Если написать `copy = word`, то для изучаемого сейчас текста оба имени получат одно текущее значение; последующее присваивание нового текста одному имени не перепишет другое. Изменяемые списки будут иметь важную особенность, которую изучим отдельно.

В нашей задаче данные идут двумя строками. Первый `input` получает имя, второй — город. Если город состоит из двух слов, например Нижний Новгород, они читаются вместе. Мы ещё не просим Python разбивать строку на слова.

В интерактивной программе допустимо `input('Ваше имя: ')`: текст в скобках сначала печатается как приглашение. В проверяемых задачах приглашения мешают точному ответу, поэтому основной код курса читает через `input()` без приглашения. Когда кажется, что программа «зависла» на input, сначала проверьте, не ждёт ли она очередную строку.

## Задача и формат данных

Прочитать имя и город, затем вывести приветствие и место проживания.

**Ввод:** Первая строка — имя, вторая — город.

**Вывод:** Две строки: Привет, имя и Город: город.

**Допустимые данные:** Каждая строка содержит от 1 до 100 символов.

## Почему работает и сколько действий требуется

Каждый input потребляет одну нужную строку, и каждое значение используется на своём месте. Для строк суммарной длины L чтение, хранение и вывод требуют работы и памяти, пропорциональных L: длинный текст надо действительно прочитать и вывести.

Пустые строки технически читаются, но в этой задаче исключены. При нехватке строк в файле ввода возникнет EOFError: программа запросила больше данных, чем предоставлено.

# 04. Текст и числа: типы и преобразование

После урока вы сможете: Отличать строку от целого числа и превращать ввод в int.

Нужные знания: input, переменная, присваивание

## От задачи к способу решения

Слова и числа можно вывести одним способом, но работать с ними нужно по-разному. **Тип** описывает вид значения и допустимые действия. Тип `str` — текст, тип `int` — целое число: например 0, 7 или −12. Запись `'7'` означает текст из одного символа, запись `7` — число.

`input()` всегда возвращает строку. Даже если человек ввёл только цифры, Python сначала получил текст. Для суммы нам нужны числа. `int(text)` создаёт целое число из подходящей текстовой записи. Поэтому `a = int(input())` читается изнутри наружу: получить строку → преобразовать в целое → сохранить под именем a.

Знак `+` зависит от типов. Для двух целых он складывает, для двух строк — соединяет. После чтения строк `'12'` и `'3'` операция `+` даст `'123'`. После преобразования получим 15. Это не случайная ошибка Python: мы сами выбрали разные виды данных. Сложить число и строку напрямую нельзя: возникает TypeError.

`str(number)` делает обратное преобразование в текст. Оно нужно, если хочется именно соединить число с другим текстом через `+`. Для обычного вывода удобнее `print('Сумма:', total)`: print умеет показать число сам. `type(value)` позволяет увидеть тип; это диагностический инструмент. Для 7 результат содержит имя `int`, для `'7'` — `str`. Скобки вызова обязательны: `int` без скобок ещё не выполняет преобразование.

Тип принадлежит значению, а имя может позже получить значение другого типа. Такое допустимо, но в учебных программах старайтесь сохранять смысл переменной: имя `age` не должно неожиданно стать названием города.

Сначала решим задачу руками. Если введены 12 и 3, ответ 15. Программа получает два текста, превращает каждый в число, складывает и печатает результат. Не добавляем подпись «Ответ:», потому что формат требует только число.

# 05. Арифметика, выражения и порядок вычислений

После урока вы сможете: Переводить словесную задачу в выражение со скобками.

Нужные знания: int, числовой ввод и сложение

## От задачи к способу решения

**Выражение** — запись, из которой получается значение. В `price * count + pen` сначала умножается цена на количество, затем прибавляется цена ручки. **Операторы** — знаки действий: `+` сложение, `-` вычитание, `*` умножение, `/` деление, `**` возведение в степень. Например, `3 ** 2` равно 9.

У действий есть порядок. Скобки заставляют сначала вычислить их содержимое. Возведение в степень выполняется раньше умножения и деления; умножение и деление — раньше сложения и вычитания. Поэтому `2 + 3 * 4` равно 14, а `(2 + 3) * 4` равно 20. Действия одного уровня вроде вычитания выполняются слева направо: `10 - 3 - 2` равно 5. Степени группируются справа: `2 ** 3 ** 2` означает `2 ** (3 ** 2)`.

Полезная тонкость: `-3 ** 2` равно −9, потому что степень вычисляется до унарного минуса. Операнд — значение, к которому применяется действие. Унарный минус — знак отрицательного значения с одним операндом. Если хотите квадрат отрицательного числа, пишите `(-3) ** 2`. Не пытайтесь запомнить результат без причины: скобки явно показывают задуманный порядок.

Перевод задачи в код начинаем с единиц измерения. Цена одной тетради — рубли за штуку, count — число штук. Произведение даёт рубли за все тетради. Ручку покупаем один раз, поэтому её цену прибавляем после умножения. В выражении `(price + pen) * count` ручка ошибочно покупалась бы вместе с каждой тетрадью.

Пример: тетрадь стоит 30 рублей, берём 4 штуки, ручка стоит 25. Тетради обходятся в 120, вся покупка — в 145. Чтобы проверка была понятной, введём промежуточное имя `notebooks_cost`. Оно связывает действие программы с конкретным шагом рассуждения.

Деление `/` даёт дробное значение даже при делении 6 на 2: результат 3.0. Это пригодится для средних величин. Для целых упаковок и остатков нужны другие операции; их разберём в следующем уроке. Python не использует запятую как десятичный знак и не понимает математическую запись `2x`: умножение всегда записываем явно, `2 * x`.

## Задача и формат данных

**Ввод:** Три строки: цена тетради, число тетрадей, цена ручки.

**Вывод:** Общая стоимость в целых рублях.

**Допустимые данные:** Цены от 0 до 10000; число тетрадей от 0 до 100.

Вход сквозного примера:

```text

4
25
```

Ожидаемый вывод:

```text

```

| 3 | Прибавить одну ручку | total = 145 |

# 06. Целое деление, остаток и цифры

После урока вы сможете: Разделить количество на полные группы и остаток.

Нужные знания: Целые числа и арифметические выражения

## От задачи к способу решения

Пусть прошло 135 минут. Полных часов два: 60 + 60 = 120. Остаются 15 минут. Обычное деление даёт 2.25, но для записи часов и минут нужны две отдельные величины. Операция `//` получает целую часть деления с округлением вниз, операция `%` — остаток.

Для неотрицательного количества `minutes // 60` показывает, сколько полных групп по 60 помещается. `minutes % 60` показывает, сколько осталось после этих групп. Проверка результата: `hours * 60 + rest` должно вернуть исходное количество, а rest находится от 0 до 59. Такая связь объясняет обе операции, а не только помогает запомнить знаки.

При 59 минутах полных часов ещё нет, при 60 остаток равен нулю, при 61 остаток один. Именно эти границы отличают правильное решение от округления к ближайшему числу. Если написать `round(minutes / 60)`, можно ошибочно получить час уже при 59 минутах. Нам нужны полностью прошедшие часы.

Деление на ноль не имеет результата: Python сообщит ZeroDivisionError. Для отрицательных чисел «округление вниз» означает движение к меньшему целому: `-7 // 3` равно −3, а `-7 % 3` равно 2. Проверка связи остаётся верной: −3 * 3 + 2 = −7. Пока в задаче минуты неотрицательны, но нельзя переносить фразу «отбрасывает дробь» на все значения.

Эти операции позволяют извлекать десятичные цифры. Для неотрицательного целого последняя цифра — `number % 10`, число без последней цифры — `number // 10`. У 472 получаем 2 и 47. Цифра десятков — `(number // 10) % 10`: сначала убрать единицы, затем взять последнюю цифру оставшегося числа. Это не работа с текстом, а разбиение на полные десятки и остаток.

Извлечение фиксированного числа цифр подходит, когда размер числа известен. Перебор всех цифр числа произвольной длины потребует повторения — цикла. До него не будем придумывать неизвестные конструкции.

## Задача и формат данных

**Вывод:** Два целых числа через пробел: часы и минуты.

**Допустимые данные:** От 0 до 1000000 минут.

Вход сквозного примера:

```text

```

Ожидаемый вывод:

```text

```

| Шаг | Действие и причина | Состояние или результат |

| 2 | Отделить полные группы по 60 | hours = 2 |
| 3 | Взять остаток после двух групп | rest = 15 |
| 4 | Проверить: 2 * 60 + 15 = 135 | Вывод: 2 15 |

## Почему работает и сколько действий требуется

Для каждого допустимого количества деление на 60 выделяет полные часы, остаток сохраняет непройденную часть часа. Число операций фиксировано, сохраняем три небольших целых.

# 07. Как читать ошибки и проверять вычисления

После урока вы сможете: Различать ошибку записи, ошибку выполнения и неверный ответ.

## От задачи к способу решения

Ошибка — информация о том, где программа перестала соответствовать замыслу. Полезно разделять три случая. **Синтаксическая ошибка** означает, что запись не подходит правилам языка: например не закрыта скобка. **Ошибка выполнения** появляется у записанной правильно команды, которую нельзя выполнить с текущими данными: например число делится на ноль. **Логическая ошибка** не мешает запуску, но даёт неверный ответ.

Сообщение Python обычно содержит название файла, номер строки, фрагмент кода и название ошибки. Начинайте с последней строки: она называет тип и причину. Затем найдите указанное место в своём файле. Показанная строка — место обнаружения, а причина иногда находится выше: забытая скобка может нарушить следующую команду.

`SyntaxError` просит проверить запись. `NameError` означает, что использовано имя без доступного значения; проверьте написание и порядок присваиваний. `TypeError` — операция получила неподходящие типы. `ValueError` при int часто означает неподходящий текст числа. `ZeroDivisionError` объясняет запрещённое деление. Номер строки помогает найти место, но не заменяет рассуждение о смысле.

**Отладка** — поиск и устранение причины ошибки. Действуйте по шагам: найдите небольшой вход → получите ожидаемый ответ руками → запустите программу → сравните → проверьте ближайшее неверное промежуточное значение. **Тест** — выбранные данные и ожидаемое поведение. Один обычный тест ещё не проверяет все случаи. Для билетов полезны нулевое количество, один билет и максимальные значения. Меняйте одну причину за раз, сохраняйте файл и повторяйте тест, на котором было расхождение. Бессистемная замена нескольких строк мешает понять, какая правка помогла.

## От задачи к способу решения

До сих пор каждый запуск выполнял одни и те же команды. Теперь действие зависит от данных. **Условие** — вопрос с двумя результатами: истина или ложь. Выражение `amount >= 1000` спрашивает, не меньше ли сумма тысячи. Python представляет ответ значениями `True` и `False`; их тип называется `bool`.

Сравнения записываются так: `==` равно, `!=` не равно, `<` меньше, `>` больше, `<=` не больше, `>=` не меньше. Знак `=` присваивает значение, а `==` сравнивает. При выборе бесплатной доставки важен знак `>=`: заказ ровно на 1000 подходит. Проверка только `>` потеряет граничный случай.

`if` означает «если». После условия ставится двоеточие. Команды выбранного действия идут ниже с отступом, обычно четыре пробела. **Блок** — несколько команд с одним уровнем отступа, относящихся к одной конструкции. Если условие истинно, выполняется блок if. `else` означает «иначе» и содержит действие для ложного условия. У else нет собственного условия.

Отступ — часть смысла Python. Команда без отступа после двух ветвей выполняется независимо от выбора. Отступы удобнее ставить средствами редактора; не смешивайте табуляцию и пробелы. Ошибка IndentationError просит проверить структуру блоков.

Решаем задачу сначала словами: прочитать сумму; если она не меньше тысячи — сказать БЕСПЛАТНО; в остальных случаях — ПЛАТНО. Не нужны два независимых if: условие либо верно, либо неверно, и эти случаи полностью покрывает if/else.

Проверьте на 1200: условие истинно, выполняется первая ветвь. На 999 оно ложно, выполняется вторая. На 1000 нужно попасть в первую: это следует из слова «включительно», а не из случайного примера. Значения True и False можно отдельно вывести через print, но ответ задачи требует слов, поэтому печатаем их в нужной ветви.

# 09. Несколько вариантов: elif и вложенные условия

После урока вы сможете: Выбирать ровно одну из нескольких категорий.

Нужные знания: if/else, сравнения и отступы

## От задачи к способу решения

Двух ветвей хватает для ответа да/нет. Для трёх категорий можно вложить ещё один if в else, но тогда структура растёт вправо. `elif` означает «иначе, если» и позволяет записать цепочку проверок на одном уровне.

Цепочка работает по порядку. Проверяется if. Если он истинный, его блок выполняется, остальные проверки цепочки пропускаются. Если ложный, проверяется первый elif. Если и он ложный, проверяется следующий. else выполняется, когда ни одно условие цепочки не подошло. Из всей цепочки выбирается самое первое подходящее действие.

Для температуры сначала отделим мороз: `temperature < 0`. Если не мороз, уже знаем, что температура не меньше нуля. Поэтому следующая проверка `temperature < 20` относится фактически к диапазону от 0 до 19. В else остаются значения от 20. Каждая ветвь получает смысл от предыдущих ложных проверок.

Нельзя бездумно заменить elif отдельными if. При температуре −5 проверки `< 0` и `< 20` обе истинны: два независимых if могли бы напечатать две категории. Цепочка разрешает ровно одну. Порядок также важен: проверка `< 20` в начале захватила бы морозные значения раньше их отдельной ветви.

**Вложенное условие** нужно, когда второй вопрос имеет смысл только внутри первого случая. Например, после проверки `age >= 18` можно отдельно проверить наличие билета. Тогда внутренний if пишется с ещё одним уровнем отступа. Но вложенность сама по себе не делает решение точнее. Сначала определите, это независимые действия, взаимоисключающие категории или дополнительный вопрос внутри одной категории.

Для нашего сквозного примера температура 10. Морозная проверка ложна. Проверка `< 20` истинна, значит выводим ПРОХЛАДНО. Вручную этот ответ относится к средней категории. Чтобы проверить границы, отдельно рассмотрим −1, 0, 19 и 20.

## Задача и формат данных

Классифицировать температуру: ниже нуля — МОРОЗ, от 0 до 19 — ПРОХЛАДНО, от 20 — ТЕПЛО.

**Ввод:** Одна целая температура.

**Вывод:** Одно из трёх слов.

**Допустимые данные:** Температура от −100 до 100.

Вход сквозного примера:

```text

```

Ожидаемый вывод:

```text

```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | Прочитать температуру | temperature = 10 |
| 2 | 10 < 0 ложно: морозная ветвь пропускается | Переходим к elif |
| 3 | 10 < 20 истинно: выбрана средняя категория | ПРОХЛАДНО |
| 4 | Остальная цепочка уже не выполняется | Одно сообщение |

## Полная программа

```python

    print('МОРОЗ')
elif temperature < 20:
    print('ПРОХЛАДНО')

## Как читать реализацию

В elif не повторяется проверка >= 0: она уже следует из того, что первая ветвь не выбрана. else закрывает оставшиеся значения. Такой разбор позволяет восстановить интервалы по коду и заметить пересечение или пропуск.

## Почему работает и сколько действий требуется

Все температуры разделены на три непересекающихся случая, и каждый получает правильное слово. Цепочка делает не больше двух сравнений, затем заканчивается; хранится одна температура.

## Границы и частые ошибки

Независимые if подходят, когда можно выполнить несколько действий, например одновременно отметить чётность и положительность. Для одной категории используют цепочку.

# 10. Составные условия: and, or и not

После урока вы сможете: Переводить слова «и», «или», «не» в точные логические выражения.

Нужные знания: Сравнения, bool и if

## От задачи к способу решения

Иногда одного сравнения недостаточно. Нужно соединить несколько вопросов. `and` означает: оба условия должны быть истинны. `or` означает: достаточно хотя бы одного. В Python это включающее «или»: если истинны оба, результат тоже истинный. `not` меняет истину на ложь и наоборот.

Для возрастного диапазона должны выполняться две границы: `age >= 12 and age <= 17`. Python позволяет равнозначную запись `12 <= age <= 17`. Добавим согласие: `(12 <= age <= 17) and consent == 1`. Возраст подходит и согласие дано — допускаем; любой провал означает отказ.

Полезно составить маленькую таблицу для and: истина и истина → истина; истина и ложь → ложь; ложь и истина → ложь; ложь и ложь → ложь. У or только сочетание двух ложных условий даёт ложь. Это способ проверить смысл до записи большой формулы.

Частая ловушка — `age >= 12 or age <= 17`. Для возраста 80 первая часть истинна, и участник ошибочно допускается. Для диапазона нужны обе границы одновременно. Другая ловушка — `number == 1 or 2`: это не сокращение двух сравнений. Пишите `number == 1 or number == 2`.

Сравнения связываются раньше not, затем and, затем or. Если есть риск прочитать выражение иначе, ставьте скобки по смыслу. Python также проверяет составные условия слева направо и прекращает проверку, когда результат известен. Например, `divisor != 0 and number % divisor == 0` не станет делить на ноль: при нулевом divisor первая часть уже ложна.

В условиях числовой ноль и пустая строка считаются ложными, остальные целые и непустые строки — истинными. Это объясняет, почему голое `2` в ошибочной записи с or не проверяет равенство. Пока используйте явные сравнения: они лучше показывают вопрос программы.

## Задача и формат данных

**Ввод:** Возраст одной строкой; затем 1, если согласие есть, иначе 0.

**Вывод:** ДА либо НЕТ.

**Допустимые данные:** Возраст от 0 до 120; согласие — только 0 или 1.

```text

```

Ожидаемый вывод:

```

| 3 | Проверить наличие согласия | consent == 1: True |

Проверки отвечают разным требованиям. Они соединены and, потому что правила не позволяют заменить согласие подходящим возрастом. not можно использовать для отрицания понятного целого условия, например not (12 <= age <= 17), но отрицание не стоит усложнять без причины.

Возрастной диапазон и согласие необходимы одновременно; выражение истинно ровно в этих случаях. Количество проверок ограничено константой, дополнительных коллекций нет.

and и or могут возвращать сами операнды, если им переданы не bool. В основных примерах обе части — сравнения, поэтому результат булев. Дальнейшую семантику операндов для этой задачи знать не нужно.

# 11. Составляем решение: календарь и проверка правил

После урока вы сможете: Перевести правило с исключением в программу и подобрать проверки.

Нужные знания: Остаток, and, or, if/else

## От задачи к способу решения

Этот урок учит не новому знаку, а работе с условием. Правило задачи: год високосный, если делится на 400, либо делится на 4, но не делится на 100. Здесь правило задано для всех разрешённых номеров года; исторические даты перехода стран на календарь не рассматриваются.

Начните с примеров. 2024 делится на 4, не делится на 100 — подходит. 1900 делится на 4, но столетний и не делится на 400 — не подходит. 2000 делится на 400 — подходит. Один пример 2024 не обнаружил бы решение «проверять только делимость на 4».

Разделим правило на вопросы. `by_four` означает нулевой остаток от деления на 4. Аналогично зададим `by_hundred` и `by_four_hundred`. Теперь словесное правило превращается в `by_four_hundred or (by_four and not by_hundred)`. Имена здесь сохраняют результаты сравнений, то есть значения bool.

Правильность проверяем по группам. Если год делится на 400, первая часть допускает его. Если не делится на 400, ответ определяется второй частью: он должен делиться на 4 и не быть исключённым столетием. Если не делится на 4, не пройдёт ни один допустимый случай. Нам не нужно перечислять тысячи годов.

Так же переводятся геометрические и бытовые правила. Например, три положительные длины a, b, c образуют невырожденный треугольник, если каждая меньше суммы двух других. Невырожденный означает, что вершины не лежат на одной прямой и площадь не нулевая. Длины 2, 3, 5 дают равенство, поэтому не подходят. Проверка одной суммы недостаточна: с 10, 2, 3 самая длинная сторона нарушает другое неравенство.

Общий порядок работы: выписать правила словами → найти примеры для каждого случая → назвать логические части → соединить их → проверить границы. Условия становятся проще, когда мы знаем, какое требование проверяет каждая часть. Укорачивание строки не является целью.

## Задача и формат данных

Определить, високосный ли год в григорианском календаре.

**Ввод:** Один целый номер года.

**Вывод:** ДА для високосного, иначе НЕТ.

**Допустимые данные:** Годы от 1 до 9999; используется указанное правило календаря.

Вход сквозного примера:

```text
1900
```

Ожидаемый вывод:

```text
НЕТ
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | Прочитать год | year = 1900 |
| 2 | Получить три результата делимости | by_four = True, by_hundred = True, by_four_hundred = False |
| 3 | Столетний год не прошёл исключение про 400 | False or (True and False) = False |
| 4 | Выбрать отрицательный ответ | НЕТ |

## Полная программа

```python

by_four = year % 4 == 0
by_hundred = year % 100 == 0
by_four_hundred = year % 400 == 0
if by_four_hundred or (by_four and not by_hundred):
    print('ДА')
else:
    print('НЕТ')
```

## Как читать реализацию

Промежуточные bool позволяют проверить каждую часть отдельно. В финальном выражении скобки показывают, что запрет столетий относится только к ветви делимости на 4, а кратность 400 образует самостоятельный разрешённый случай.

## Почему работает и сколько действий требуется

Выражение дословно кодирует два разрешённых случая и запрещает остальные; оно не зависит от удачности одного примера. Выполняется три остатка и несколько логических действий, хранится фиксированное число значений.

## Границы и частые ошибки

Для другой календарной системы нужен другой алгоритм: исходное правило применимости изменилось. Для этой задачи номера года положительны.

# 12. Дробные числа и формат результата

После урока вы сможете: Читать float и отличать значение от способа его отображения.

Нужные знания: Арифметика, int и преобразования

## От задачи к способу решения

Целых чисел не хватает для роста 1.75 метра или температуры 22.5. Тип `float` хранит дробные значения приближённо. В коде десятичная часть отделяется точкой: `1.75`. Для текстового ввода используется `float(input())`. Строка `'1,75'` не подходит такому преобразованию: запятая здесь не десятичный знак.

Среднее двух чисел — их сумма, разделённая на 2. Скобки нужны, чтобы делилась вся сумма. С измерениями 2.5 и 3.0 получится 2.75. Вывод задачи требует ровно два знака после точки, даже если ответ целый: 3.00, а не 3.0.

Для этого применим **форматированную строку**, или f-строку. Перед кавычками ставится `f`. В фигурных скобках внутри текста Python вычисляет выражение и подставляет его результат. Запись `f'{average:.2f}'` содержит настройку после двоеточия: `.2f` означает вывести дробное число с двумя знаками после точки. Этот текст передаётся print.

Форматирование меняет представление, а не само значение average. `round(average, 2)` вычисляет округлённое значение, но не заставляет обычный print показать завершающие нули. Кроме того, при равных расстояниях round выбирает ближайшее чётное значение: `round(2.5)` равно 2, `round(3.5)` равно 4. Не переносите без проверки школьное правило «всегда вверх при пяти» на Python.

Многие десятичные дроби нельзя точно представить в двоичной памяти float. Поэтому `0.1 + 0.2` обычно показывается как 0.30000000000000004. Это не значит, что сложение «не работает»: сохраняется близкое представимое число. Для близости измерений лучше проверять `abs(a - b) <= tolerance`, где abs — расстояние от нуля, а tolerance — допустимая погрешность, выбранная по смыслу задачи. Точную работу с abs разберём дальше.

В учебных задачах с рублями и копейками, когда нужна точность, удобнее хранить целое число копеек. Для данной задачи об измерениях float подходит. Сначала решите, нужна точная дискретная сумма или приближённый расчёт, и только затем выбирайте тип.

**Вывод:** Среднее с двумя знаками после точки.

**Допустимые данные:** Каждое число от −1000 до 1000, не больше трёх знаков после точки.

```

Ожидаемый вывод:

```text

Формула соответствует определению среднего, формат соответствует требованию двух знаков. Вычисление имеет обычную погрешность float. Число операций фиксировано, сохраняем несколько числовых значений и короткую строку вывода.

Тесты не подменяют обсуждение точности. Отрицательное приближённое число, близкое к нулю, иногда отображается как -0.00; это свойство представления. Правило удаления такого знака должно быть отдельно задано условием.

# 13. Готовые функции: abs, min, max и math

После урока вы сможете: Использовать готовую операцию и проверять область допустимых данных.

Нужные знания: Числовые выражения и float

## От задачи к способу решения

**Функция** — операция с именем, которую вызывают с аргументами и которая может вернуть результат. Вы уже пользовались функциями input, print и преобразованиями int, float. Создание своих функций изучим после циклов и списков; сейчас полезно уметь читать вызовы готовых.

Расстояние между координатами −3 и 5 равно 8. Разность −3 − 5 равна −8, а расстояние отрицательным не бывает. Можно выбрать порядок вычитания через if, но задача сводится к знакомому понятию **модуля числа**: его расстоянию от нуля. Функция `abs(x)` возвращает модуль. Поэтому `abs(left - right)` подходит для любого порядка координат.

`min(a, b)` получает меньшее из значений, `max(a, b)` — большее. Им можно передать больше двух аргументов. Это встроенные функции: отдельно подключать их не нужно. Не называйте свои переменные `min`, `max` или `input`, иначе имя стандартной функции будет заслонено вашим значением и следующий вызов перестанет работать.

Некоторые готовые операции собраны в **модуль** — набор доступных имён. Для математических функций пишут `import math`, затем, например, `math.sqrt(9)` для квадратного корня. У готовой функции есть **контракт**: что она принимает и что возвращает. Квадратный корень math.sqrt здесь определён для неотрицательных чисел; отрицательный аргумент даст ValueError. ceil и floor различаются и на отрицательных значениях: для −2.2 это −2 и −3. Готовая функция сокращает код, но не отменяет объяснение. В задаче о координатах нужно понять, почему берём модуль разности, и проверить равные координаты. Применять max вместо abs к одной разности было бы бессмысленно: max выбирает среди кандидатов, а не меняет знак по определению расстояния.

# 14. Повторение известное число раз: for и range

После урока вы сможете: Записать повторение и правильно выбрать границы range.

Нужные знания: Условия, блоки и целые числа

## От задачи к способу решения

Для трёх заданий можно написать три команды print. Для ста заданий это неудобно, а количество заранее приходит от пользователя. **Цикл** — конструкция, которая повторяет блок команд. **Итерация** — одно выполнение этого блока.

`for number in range(1, n + 1):` означает: последовательно взять значения из заданного диапазона, каждый раз связать очередное значение с number и выполнить блок. Имя number — обычная переменная, получающая новое значение на каждом шаге. После двоеточия команды тела цикла пишутся с отступом, как в if.

`range(stop)` задаёт целые от 0 до stop, не включая stop. `range(start, stop)` задаёт от start до stop, также не включая stop. Поэтому для номеров от 1 до n нужно `range(1, n + 1)`. Конец диапазона исключён: `range(1, 3)` содержит только 1 и 2.

Третий аргумент — **шаг**, величина изменения: `range(2, 9, 2)` даёт 2, 4, 6, 8. Отрицательный шаг позволяет идти вниз: `range(3, 0, -1)` даёт 3, 2, 1. Шаг ноль запрещён. Если направление не соответствует границам, диапазон пуст: `range(3, 0)` не выдаёт значений, потому что стандартный шаг положительный.

В сквозном примере n = 3, значит number по очереди получает 1, 2 и 3. Во время каждой итерации print показывает текущее значение. Команда после цикла без отступа выполнилась бы лишь после всех итераций; команда внутри — на каждом шаге. Это позволяет решить, где печатать промежуточные и итоговые результаты.

range не создаёт заранее список всех чисел: он представляет правило диапазона. Цикл получает значения последовательно. Но сами команды всё равно выполняются n раз; краткая запись не означает мгновенную работу для огромного n. Для нашего предела тысяча повторений достаточно небольшая величина.

## Задача и формат данных

Вывести номера заданий от 1 до n, каждый на своей строке.

**Ввод:** Одно число n.

**Вывод:** Числа 1, 2, ..., n отдельными строками; при n = 0 вывод пустой.

**Допустимые данные:** 0 <= n <= 1000.

Вход сквозного примера:

```text
3
```

Ожидаемый вывод:

```text
1
2
3
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | n = 3, диапазон от 1 до 4 без 4 | Следующие значения: 1, 2, 3 |
| 2 | Первая итерация | number = 1, вывод 1 |
| 3 | Вторая итерация | number = 2, вывод 2 |
| 4 | Третья итерация и конец диапазона | number = 3, вывод 3 |

## Полная программа

```python
n = int(input())
for number in range(1, n + 1):
    print(number)
```

## Как читать реализацию

n задаёт размер диапазона, number — текущий номер. Менять number вручную внутри такого цикла не требуется: на следующей итерации for возьмёт очередное значение range. При n = 0 диапазон range(1, 1) пуст, поэтому тело не выполняется.

## Почему работает и сколько действий требуется

Диапазон содержит ровно все нужные номера в правильном порядке, каждый посещается один раз. Цикл заканчивается после n итераций. Число действий растёт пропорционально n; служебное состояние и range занимают постоянную память, результат выводится постепенно.

## Границы и частые ошибки

Ошибка n вместо n + 1 пропускает последний номер. При пустом диапазоне переменная цикла может не получить значения, поэтому нельзя рассчитывать на неё после цикла.

# 15. Сумма и счётчик: сохраняем результат между шагами

После урока вы сможете: Накапливать сумму и количество подходящих значений.

Нужные знания: for, range и условия

## От задачи к способу решения

Цикл умеет повторить действие, но результаты разных шагов надо связать. Для трёх чисел можно вручную написать a + b + c. При переменном количестве вместо хранения каждого числа достаточно постепенно обновлять одну сумму. **Накопитель** — переменная, которая хранит результат уже обработанных шагов.

Перед чтением чисел `total = 0`: сумма пока пустого набора равна нулю. На каждом шаге `total = total + value`. Python сначала берёт старое total, прибавляет новое число, затем сохраняет результат под тем же именем. Присваивание не является уравнением, поэтому такая запись допустима. Сокращение `total += value` означает то же числовое обновление.

**Счётчик** — накопитель количества. `positive_count = 0` значит, что ещё не встретили положительных значений. Когда `value > 0`, увеличиваем его ровно на 1. Если условие ложно, счётчик не меняется. Не надо прибавлять само value: мы считаем объекты, а не их величину.

Сквозной пример: n = 3, числа 4, −2, 0. Сначала сумма 0 и счётчик 0. После 4 — сумма 4, счётчик 1. После −2 — сумма 2, счётчик остаётся 1. После 0 — сумма остаётся 2, счётчик 1. Ноль не положительный, потому что сравнение строгое.

Начальные значения ставятся **до** цикла. Если total = 0 поместить внутрь, на каждом шаге будет забыта предыдущая сумма и останется только последняя прибавка. Итоговый print ставится **после** цикла: иначе программа напечатает n промежуточных результатов вместо одного ответа.

Переменная day получает номера от 0 до n − 1, но в данном алгоритме сам номер не нужен: range(n) обеспечивает нужное количество чтений. Каждая итерация читает ровно одну следующую строку. Неправильный n во входе приведёт к лишнему запросу или неполной обработке; поэтому формат всегда указывает размер данных.

## Задача и формат данных

В n дневных результатах найти общую сумму и число положительных результатов.

**Ввод:** n первой строкой; затем n целых чисел, каждое на отдельной строке.

**Вывод:** Сумма и количество положительных через пробел.

**Допустимые данные:** 0 <= n <= 10000; значения от −1000 до 1000.

Вход сквозного примера:

```text
3
4
-2
0
```

Ожидаемый вывод:

```text
2 1
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 0 | До чтения чисел нет вклада и подходящих элементов | total = 0, positive_count = 0 |
| 1 | 4 прибавляется и удовлетворяет value > 0 | total = 4, positive_count = 1 |
| 2 | -2 прибавляется, но не положителен | total = 2, positive_count = 1 |
| 3 | 0 не меняет сумму и не проходит строгое сравнение | total = 2, positive_count = 1 |

## Полная программа

```python
n = int(input())
total = 0
positive_count = 0
for day in range(n):
    value = int(input())
    total += value
    if value > 0:
        positive_count += 1
print(total, positive_count)
```

## Как читать реализацию

total отвечает на вопрос о величине всех результатов, positive_count — о числе подходящих дней. Это независимые характеристики: отрицательный день уменьшает total, но не уменьшает число уже увиденных положительных. Сохранить все числа для этой задачи не нужно.

## Почему работает и сколько действий требуется

После каждого шага total равен сумме уже прочитанных чисел, а счётчик равен числу положительных среди них. Добавление очередного вклада сохраняет это свойство. После n шагов обработаны все данные. Работа пропорциональна n; память — постоянное число переменных, без хранения всего ввода.

## Границы и частые ошибки

Для произведения начальное значение 1, а не 0: единица не меняет первый множитель. Для среднего нужен total / n, но пустой набор требует отдельно определить поведение.

# 16. Наибольшее значение: правильно выбираем начало

После урока вы сможете: Найти максимум без ошибочной опоры на ноль.

Нужные знания: Цикл чтения и if

## От задачи к способу решения

Сумма начинает с нуля, но максимум так начать нельзя. Если все температуры −8, −3, −5, ноль не встречается во входе и не должен стать ответом. Начальное значение должно иметь обоснование, а не быть привычной цифрой.

Прямой способ — сохранить все данные и затем искать самое большое число. Но для ответа достаточно помнить самого сильного кандидата из уже прочитанной части. Назовём его `best`. Первую температуру читаем до цикла и делаем первым кандидатом. Это возможно, потому что условие обещает хотя бы одну температуру.

Затем читаем остальные n − 1 значения. Если новое value больше best, заменяем кандидата. Если меньше или равно, прежний кандидат всё ещё максимален среди просмотренных. На следующем шаге нам не нужны старые проигравшие значения: их превосходит уже сохранённый best.

Пройдём −8, −3, −5. После первого чтения best = −8. Второе значение −3 больше −8, поэтому best меняется на −3. Третье −5 меньше −3, поэтому замены нет. Итог −3 действительно самый большой, хотя все числа отрицательны.

Обратите внимание на число чтений. Одно значение получено до цикла, поэтому range(n − 1) читает ровно остальные. Цикл range(n) после первого чтения запросил бы лишнюю температуру. При n = 1 цикл пустой, и первый кандидат сразу является ответом.

При равенстве строгий знак `>` оставляет более раннего кандидата. Пока нужен только максимум, это не меняет значение ответа. Если надо вернуть номер первого появления максимума, выбор строгого знака становится частью правила. Имя лучшего номера и правило его обновления добавим в упражнении.

Так появляется распространённая идея: хранить не всю историю, а достаточно информации о ней. Но это решение подходит только когда прошлые значения можно безопасно забыть. Если позже нужен полный список отсортированных температур, одного best уже мало.

## Задача и формат данных

Найти наибольшую из n целых температур.

**Ввод:** n первой строкой; затем n целых температур отдельными строками.

**Вывод:** Наибольшая температура.

**Допустимые данные:** 1 <= n <= 10000; температуры от −100 до 100.

Вход сквозного примера:

```text

-8
-3
-5
```

Ожидаемый вывод:

```text

```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | Первое значение становится допустимым кандидатом | best = -8 |
| 2 | -3 больше -8: найден более сильный кандидат | best = -3 |
| 3 | -5 не превосходит -3: замена не нужна | best = -3 |

## Полная программа

    value = int(input())

        best = value

## Как читать реализацию

best хранит максимум прочитанной части. value — только очередное число. В этой программе i обозначает номер повторения, а не номер самой температуры: первая уже прочитана отдельно. Для индексов конкретных объектов нужно осознанно выбрать диапазон.

## Почему работает и сколько действий требуется

Первый кандидат максимален в наборе из одного числа. На каждом шаге сравнение сохраняет большее из прежнего максимума и нового значения. После всех чтений кандидат максимален во всём наборе. Работа пропорциональна n, память постоянна.

## Границы и частые ошибки

Для пустого набора максимум здесь не определён. Если задача разрешит n = 0, нужно задать отдельный ответ, например НЕТ ДАННЫХ, а не придумывать максимум 0.

# 17. Повторение до выполнения условия: while

После урока вы сможете: Написать цикл с изменяемым состоянием и объяснить его завершение.

Нужные знания: Сравнения, += и циклы

## От задачи к способу решения

for подходит, когда известен набор значений или число повторений. Иногда удобнее описать состояние, при котором работу надо продолжать. **while** означает «пока»: перед каждой итерацией Python проверяет условие; если оно истинно — выполняет блок, затем снова проверяет. Если условие сразу ложное, тело не выполняется ни разу.

Запас 7 литров, расход 3 литра в день. После первого дня останется 4, после второго 1, на третий запас исчерпается. Дней три. В модели последняя операция уменьшает запас до −2: это вычислительное обозначение того, что полного дневного расхода уже не хватило. Реального отрицательного количества воды не возникает.

Будем хранить `remaining`, ещё не израсходованную часть, и `days`, число учтённых дней. Пока remaining > 0, учитываем следующий день и уменьшаем запас на use. Запись `remaining -= use` означает `remaining = remaining - use`. Когда остаток становится нулевым или отрицательным, условие ложное.

Сначала выбираем **условие продолжения**, затем проверяем, приближают ли обновления к его ложности. Без remaining -= use условие осталось бы истинным навсегда: получился бы бесконечный цикл. Если use = 0, уменьшения нет даже при наличии строки обновления. Поэтому положительность расхода — существенное условие задачи.

Для while нельзя рассчитывать, что имя счётчика само изменится, как у for. Программа отвечает за обновления. Условие `remaining >= 0` тоже неверно: при запасе 6 и расходе 3 оно посчитает лишний день из состояния remaining = 0. Нам нужен день только пока вода ещё есть.

Эту же задачу можно решить формулой `(stock + use - 1) // use`. Она не проходит дни по одному и быстрее для огромного запаса. Цикл нужен здесь для освоения модели состояния; формула допустима потому, что расход одинаков каждый день. Если расходы меняются по внешним данным, одной формулы может не хватить.

## Задача и формат данных

Есть запас воды и дневной расход. Найти число дней до исчерпания; последний неполный день считается.

**Ввод:** Запас и положительный расход двумя строками.

**Вывод:** Число дней.

**Допустимые данные:** 0 <= stock <= 10000; 1 <= use <= 10000.

Вход сквозного примера:

```text
7
3
```

Ожидаемый вывод:

```text
3
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 0 | Перед расходом дней ещё нет | remaining = 7, days = 0 |
| 1 | 7 > 0: учесть день и вычесть 3 | remaining = 4, days = 1 |
| 2 | 4 > 0: следующий день | remaining = 1, days = 2 |
| 3 | 1 > 0: последний неполный день тоже учитывается | remaining = -2, days = 3 |
| 4 | -2 > 0 ложно: завершить | Вывод 3 |

## Полная программа

```python
stock = int(input())
use = int(input())
remaining = stock
days = 0
while remaining > 0:
    remaining -= use
    days += 1
print(days)
```

## Как читать реализацию

stock сохраняет исходный запас, remaining меняется. Такое разделение позволяет сравнить итог с исходными данными. Счётчик days обновляется на каждой допустимой итерации. Положительный use гарантирует, что remaining строго уменьшается.

## Почему работает и сколько действий требуется

После d итераций учтены ровно d дней, remaining равен stock - d * use. Цикл останавливается при первом d с неположительным остатком, то есть после нужного количества дней. Работа пропорциональна числу дней; хранится фиксированное число целых.

## Границы и частые ошибки

Нулевой расход исключён, иначе цикл не завершится при положительном запасе. При большом числе дней формула выгоднее; результат у неё тот же.

# 18. Ввод до сигнала остановки: break и continue

После урока вы сможете: Обрабатывать последовательность неизвестной длины до специального значения.

Нужные знания: while, условия и накопление суммы

## От задачи к способу решения

Иногда количество строк заранее неизвестно. Пользователь вводит покупки, а специальное значение сообщает конец. Такой сигнал называется **стоп-значением**. В нашей задаче это ноль: он завершает обработку и не является очередным слагаемым.

`while True` начинает цикл, условие которого само по себе всегда истинно. Для выхода нужна команда **break**: она немедленно завершает ближайший содержащий её цикл. После break программа продолжает с команды после цикла. Использовать такой цикл безопасно только когда есть понятный путь выхода или явно задумана бесконечная работа.

В начале каждого шага читаем value. Сначала проверяем ноль. Если это сигнал, выходим. Затем проверяем отрицательность. Отрицательные числа не учитываются; команда **continue** пропускает оставшуюся часть текущей итерации и начинает следующую. Положительное число доходит до total += value.

На входе 5, −2, 3, 0: 5 увеличивает сумму до 5, −2 пропускается, 3 увеличивает до 8, 0 завершает цикл. Ничего после первого нуля не относится к данным этой задачи. Можно обойтись без continue и написать отдельный if value > 0; здесь continue помогает явно показать пропуск.

Положение чтения существенно. Если в while с изменяемым условием написать continue до обновления, можно навсегда повторить одно состояние. В нашей схеме input находится в начале каждой итерации, поэтому после continue будет прочитано новое число.

Почему сумма и сигнал проверяются не наоборот? Для суммы ноль ничего не изменил бы, но правильная структура должна отличать служебный сигнал от данных. При подсчёте количества неправильный порядок мог бы учесть стоп-значение как объект. Если ноль является допустимой покупкой, он не подходит в качестве сигнала; нужно выбрать отдельное слово вроде СТОП и читать сначала текст.

## Задача и формат данных

Сложить положительные числа до первого нуля; отрицательные пропускать.

**Ввод:** Целые числа отдельными строками, последовательность обязательно содержит завершающий 0.

**Вывод:** Сумма положительных чисел до первого 0.

**Допустимые данные:** Не больше 10000 чисел до сигнала; каждое от −1000 до 1000.

Вход сквозного примера:

```text
5
-2
3
0
```

Ожидаемый вывод:

```text
8
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | 5 положительно: добавить | total = 5 |
| 2 | -2 отрицательно: continue пропускает прибавление | total = 5 |
| 3 | 3 положительно: добавить | total = 8 |
| 4 | 0 является сигналом: break завершает цикл | Вывод 8 |

## Полная программа

```python
total = 0
while True:
    value = int(input())
    if value == 0:
        break
    if value < 0:
        continue
    total += value
print(total)
```

## Как читать реализацию

Сначала отделяем служебное значение, затем неподходящие данные, затем обрабатываем оставшиеся. После цикла total — итог всех прибавлений. break и continue действуют на ближайший цикл, поэтому во вложенных циклах они не завершают сразу все уровни.

## Почему работает и сколько действий требуется

Каждое прочитанное число до нуля либо положительно и добавляется ровно раз, либо отрицательно и не влияет на сумму. Сигнал гарантирован форматом, поэтому цикл завершится. Для k чисел до сигнала работа пропорциональна k; хранятся total и value.

## Границы и частые ошибки

Если файл закончится до нуля, input получит EOFError. Это нарушение данного формата ввода. Ожидание пользовательского ввода не является вычислительным временем алгоритма.

# 19. Цикл по цифрам числа

После урока вы сможете: Обрабатывать все десятичные цифры и не забыть случай нуля.

Нужные знания: while, //, %, накопители

## От задачи к способу решения

Для трёхзначного числа мы извлекали ровно три цифры отдельными выражениями. Теперь число может быть любой разрешённой длины. Повторяющийся шаг уже знаком: последняя цифра — остаток на 10, оставшаяся часть — целое деление на 10. Цикл заменяет запись одного выражения для каждого разряда.

Пусть number = 407. `407 % 10` даёт 7, затем `407 // 10` оставляет 40. На следующем шаге цифра 0, остаток числа 4. На третьем цифра 4, остаток 0. Дальше цифр не осталось. Порядок получается справа налево, но для суммы и количества он не важен.

Храним `remaining` — ещё не обработанную часть, `digit_sum` — сумму уже извлечённых цифр и `digit_count` — их количество. На каждом шаге сначала извлекаем digit, затем прибавляем его, увеличиваем количество и удаляем последний разряд из remaining. Если разделить remaining до получения digit, потеряем ещё не обработанную последнюю цифру.

Случай number = 0 требует внимания. Его десятичная запись содержит одну цифру 0. Но while remaining > 0 при нуле не выполнится. Поэтому отдельно устанавливаем digit_count = 1, сумма остаётся 0. Это правило вытекает из записи числа, а не из желания избежать неудобного теста.

Начальный number сохраняем, потому что remaining разрушительно уменьшается. Если позже понадобится вывести исходное число, оно доступно. Такой приём полезен всякий раз, когда алгоритм меняет рабочую копию значения.

Обрабатывать отрицательное число тем же циклом нельзя: условие > 0 сразу остановится. Если задача разрешит отрицательные числа и попросит цифры модуля без знака, можно начать с abs(number). Сначала следует сформулировать договорённость о знаке. В нашем условии отрицательных значений нет.

## Задача и формат данных

Для неотрицательного целого найти сумму цифр и их количество.

**Ввод:** Одно целое число.

**Вывод:** Сумма цифр и число цифр через пробел.

**Допустимые данные:** 0 <= number <= 10**18.

Вход сквозного примера:

```text
407
```

Ожидаемый вывод:

```text
11 3
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 0 | Ещё ни одна цифра не обработана | remaining = 407, digit_sum = 0, digit_count = 0 |
| 1 | Извлечь 7, прибавить и удалить разряд | remaining = 40, digit_sum = 7, digit_count = 1 |
| 2 | Нулевая цифра тоже считается | remaining = 4, digit_sum = 7, digit_count = 2 |
| 3 | Извлечь 4; больше цифр нет | remaining = 0, digit_sum = 11, digit_count = 3 |

## Полная программа

```python
number = int(input())
remaining = number
digit_sum = 0
digit_count = 0
if remaining == 0:
    digit_count = 1
while remaining > 0:
    digit = remaining % 10
    digit_sum += digit
    digit_count += 1
    remaining //= 10
print(digit_sum, digit_count)
```

## Как читать реализацию

После //= 10 рабочая часть становится короче на один десятичный разряд. Количество увеличивается даже при digit = 0. Начальный digit_count = 1 ставится только для самого числа 0, а не для всех чисел с нулевыми цифрами.

## Почему работает и сколько действий требуется

Каждая цифра извлекается ровно один раз, поэтому накопители содержат требуемые характеристики. Положительная remaining уменьшается и становится нулевой. Для d цифр требуется d итераций; в указанном диапазоне d <= 19. Хранится постоянное число переменных; за пределами диапазона стоимость операций над огромными int тоже растёт.

## Границы и частые ошибки

Ведущие нули теряются при преобразовании в int. Если ввод 007 должен иметь три символа, это задача о строке, а не о целочисленной записи.

# 20. Вложенные циклы и таблицы

После урока вы сможете: Отличать внешний шаг от внутренних и считать общее число повторений.

Нужные знания: for, range, print с end

## От задачи к способу решения

Один цикл печатает последовательность. Для таблицы нужно повторять действия внутри каждого ряда. **Вложенный цикл** — цикл, расположенный в теле другого. Внешний выбирает строку, внутренний — позиции внутри неё.

Для высоты 2 и ширины 3 ожидаем две строки по три звёздочки. После выбора первой строки внутренний цикл проходит три позиции: печатает `*`, затем `*`, затем `*`. После него один print без аргументов переводит вывод на новую строку. Только потом внешний цикл выбирает вторую строку, и внутренний снова начинает с первой позиции.

`print('*', end='')` не добавляет ни пробел, ни перенос. Поэтому звёздочки соединяются. `print()` с пустыми скобками печатает только стандартное завершение — перенос строки. Его отступ должен совпасть с внутренним for, чтобы он относился к внешнему телу, но находился после внутреннего цикла.

Если перенос поставить внутрь второго цикла, каждая звёздочка окажется на новой строке. Если вынести за оба цикла, все ряды сольются. Отступы здесь показывают, что должно повториться для каждой ячейки, а что — один раз после каждого ряда.

Число итераций не равно height + width. На каждую из height строк приходится width внутренних шагов, значит всего height * width печатаний звёздочки. При 2 и 3 это шесть ячеек. Если обе стороны равны n, работа растёт как n²: удвоение стороны даёт вчетверо больше ячеек.

Прямоугольник можно напечатать и без внутреннего цикла: строка `'*' * width` повторяет текст width раз. Это полезное сокращение, но не отменяет размер вывода. Вложенные циклы нужны для более сложных таблиц, где значение зависит от номера строки и столбца, например таблицы умножения.

## Задача и формат данных

Напечатать прямоугольник из звёздочек заданной высоты и ширины.

**Ввод:** Высота и ширина отдельными строками.

**Вывод:** height строк, в каждой width звёздочек.

**Допустимые данные:** 1 <= height, width <= 30.

Вход сквозного примера:

```text
2
3
```

Ожидаемый вывод:

```text
***
***
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | Внешний цикл выбирает первый ряд | row = 0 |
| 2 | Внутренний цикл печатает три символа без переноса | *** |
| 3 | После внутреннего цикла завершить ряд | Первая строка готова |
| 4 | Второй ряд повторяет три печатания и перенос | Вторая строка: *** |

## Полная программа

```python
height = int(input())
width = int(input())
for row in range(height):
    for column in range(width):
        print('*', end='')
    print()
```

## Как читать реализацию

row — номер повторения ряда, column — номер позиции. Здесь их значения не влияют на символ; в таблице умножения влияли бы. Внутренний диапазон проходит заново при каждом внешнем шаге, это не один общий проход по width.

## Почему работает и сколько действий требуется

Каждый ряд содержит ровно width звёздочек и один перевод строки, рядов height. Циклы конечны. Для h рядов и w столбцов работа и размер вывода пропорциональны h * w; программа не хранит таблицу, поэтому дополнительная память постоянна.

## Границы и частые ошибки

break внутри внутреннего цикла закончит только текущий ряд, а внешний продолжится. Для большой таблицы надо учитывать объём результата, даже если код короткий.

# 21. Перебор кандидатов: делители и простые числа

После урока вы сможете: Проверять кандидатов по правилу и вывести границу перебора.

Нужные знания: Остаток, циклы, break и bool

## От задачи к способу решения

**Делитель** положительного числа n — положительное целое d, на которое n делится без остатка. У 12 делители 1, 2, 3, 4, 6, 12. **Простое число** — целое больше 1, у которого ровно два положительных делителя: 1 и оно само. Ноль и единица простыми не являются.

Понятный способ проверки: перебрать все числа от 2 до n − 1 и спросить, делит ли каждое n. Если нашли хотя бы одно — число составное. Если не нашли — простое. Это корректно, но для большого n выполняет почти n проверок.

Сократим повторяющуюся работу. Делители идут парами: если n = a * b, то a и b — делители. В паре хотя бы одно число не больше квадратного корня из n. Иначе оба были бы больше корня, и произведение оказалось бы больше n. Поэтому при наличии нетривиального делителя есть такой делитель не выше корня.

Не будем вычислять приближённый корень. Проверка `divisor * divisor <= n` использует целые и означает тот же предел. Начинаем с divisor = 2, последовательно увеличиваем на 1. Если остаток ноль, ставим `is_prime = False` и выходим через break: одного свидетеля достаточно.

Сквозной пример 49 особенно полезен. Кандидаты 2, 3, 4, 5, 6 не делят 49. Кандидат 7 делит, поэтому число не простое. Если ошибочно написать `< n` вместо `<= n` в условии квадрата, проверка 7 пропадёт и квадрат простого будет признан простым.

Изначально is_prime = n >= 2. Это **флаг** — логическая переменная, обозначающая состояние. У нуля и единицы флаг сразу ложный; цикл не запускается. У остальных число считается кандидатом в простые, пока не найден делитель. Такой флаг не является доказательством сам по себе: его смысл поддерживается проверками.

## Задача и формат данных

Определить, является ли целое n простым.

**Ввод:** Одно целое n.

**Вывод:** ДА для простого, иначе НЕТ.

**Допустимые данные:** 0 <= n <= 1000000.

Вход сквозного примера:

```text
49
```

Ожидаемый вывод:

```text
НЕТ
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 0 | 49 >= 2: допускаем кандидата, начинаем с 2 | is_prime = True, divisor = 2 |
| 1 | 2, 3, 4, 5, 6 проверены, остатки ненулевые | is_prime = True, divisor = 7 |
| 2 | 7 * 7 <= 49 и 49 % 7 = 0: найден делитель | is_prime = False |
| 3 | break завершает поиск свидетеля | НЕТ |

## Полная программа

```python
n = int(input())
is_prime = n >= 2
divisor = 2
while is_prime and divisor * divisor <= n:
    if n % divisor == 0:
        is_prime = False
        break
    divisor += 1
if is_prime:
    print('ДА')
else:
    print('НЕТ')
```

## Как читать реализацию

is_prime хранит текущий результат проверки, divisor — очередной кандидат. Порядок and не запускает цикл для уже отвергнутых 0 и 1. Если делитель найден, дальнейший перебор не изменит ответ, поэтому break безопасен. Если кандидаты кончились, ни одного малого делителя нет.

## Почему работает и сколько действий требуется

Любой составной n >= 2 имеет делитель от 2 до квадратного корня, и цикл проверяет все такие кандидаты. Поэтому отсутствие свидетеля означает простоту. divisor растёт на каждом не завершающем шаге. Не больше примерно корня из n проверок, постоянное число переменных. В пределах заданного n целочисленные операции малы.

## Границы и частые ошибки

Алгоритм предназначен для одного числа, не для списка миллионов запросов. Для очень больших целых потребуются другие методы. Отрицательные числа не разрешены.

# 22. Строка как последовательность: длина и индексы

После урока вы сможете: Получать символ по позиции и безопасно работать с пустой строкой.

Нужные знания: Строки, for, if и input

## От задачи к способу решения

Строка — не только текст целиком, но и упорядоченная последовательность символов. **Индекс** — номер позиции в этой последовательности. В Python первая позиция имеет индекс 0. У слова кот: индекс 0 — к, индекс 1 — о, индекс 2 — т. Последний положительный индекс на единицу меньше длины.

`len(text)` возвращает длину, `text[0]` — первый символ. Квадратные скобки после имени обращаются к элементу по индексу; круглые скобки используются для вызова функции. Отрицательные индексы считают с конца: `text[-1]` — последний, `text[-2]` — предпоследний. Минус ноль не новый индекс: `text[-0]` то же, что text[0].

У пустой строки длина 0 и нет первого символа. Обращение text[0] или text[-1] вызовет IndexError. Поэтому сначала проверяем length > 0. Для строки из одного символа первый и последний символ совпадают; это правильный результат, а не ошибка.

Можно пройти символы напрямую: `for character in text:`. На каждой итерации character получает строку длины один. Отдельного типа для одиночного символа в Python нет. Если нужен номер, используйте `for index in range(len(text)):` и берите text[index]. Прямой перебор короче, когда позиции не используются.

Строки **неизменяемы**: text[0] = 'К' не исправит первый символ. Для нового текста нужно создать новое строковое значение и при необходимости присвоить его переменной. Переприсваивание имени разрешено; изменение символа внутри существующего строкового значения — нет. Именно поэтому сравнивайте действие с объектом и действие с именем.

len считает кодовые точки Unicode, а не байты файла и не всегда визуальные значки. Обычная кириллическая буква в примерах курса — один элемент строки. Некоторые эмодзи и буквы с отдельно записанным ударением состоят из нескольких кодовых точек. Не считайте len универсальным счётчиком видимых символов.

## Задача и формат данных

Вывести длину строки; для непустой строки также первый и последний символы.

**Ввод:** Одна строка, возможно пустая.

**Вывод:** Длина первой строкой. Если строка непустая, её первый и последний символы через пробел второй строкой.

**Допустимые данные:** От 0 до 100 символов.

Вход сквозного примера:

```text

```

Ожидаемый вывод:

```text
3
к т
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | Прочитать кот как строку | text = кот |
| 2 | Посчитать три позиции | length = 3 |
| 3 | Строка непустая: индексы допустимы | text[0] = к, text[-1] = т |

## Полная программа

```python

length = len(text)
print(length)
if length > 0:
    print(text[0], text[-1])
```

## Как читать реализацию

Первый print выполняется для любого текста, а второй защищён проверкой длины. Пробелы из input являются символами строки: они тоже влияют на len и могут быть крайними элементами. В этой задаче не надо удалять их автоматически.

## Почему работает и сколько действий требуется

len задаёт длину, а выбранные индексы обозначают именно края непустой строки. При пустой строке опасная ветвь не выполняется. Чтение и хранение строки длины L требуют работы и памяти, пропорциональных L; операции len и получения одного элемента для str выполняются за постоянное время.

## Границы и частые ошибки

Индекс len(text) выходит за допустимую границу. Для пустой строки не существует даже отрицательного последнего индекса. Различие видимого символа и кодовой точки важно для сложного Unicode.

# 23. Срезы и проверка палиндрома

После урока вы сможете: Получать часть строки и понимать исключённую правую границу.

Нужные знания: Индексы строк, if и len

## От задачи к способу решения

**Срез** получает последовательную часть строки. Запись `text[start:stop]` берёт позиции от start включительно до stop не включительно. У строки Python срез [1:4] даёт yth: индексы 1, 2, 3. Позиция 4 уже за правой границей. Это такое же соглашение, как у range.

Если начало пропущено, берётся начало строки: text[:3]. Если конец пропущен, берётся остаток: text[3:]. Эти части вместе дают всю строку, без повторения позиции 3. text[:] даёт полную строку по значению.

Третья часть после второго двоеточия — шаг: `text[::2]` берёт каждый второй символ начиная с нулевого. `text[::-1]` проходит строку в обратном направлении и даёт перевёрнутую запись. При отрицательном шаге пропущенные границы подбираются для движения от конца к началу. Шаг 0 запрещён.

Срез за пределами строки обычно безопасно ограничивается её длиной: text[:100] у короткой строки даёт всю строку. Прямой индекс text[100] требует существующего элемента и вызвал бы ошибку. Это разные операции: пустая часть допустима, несуществующий отдельный элемент — нет.

**Палиндром** — строка, равная своей обратной записи. У топот крайние буквы совпадают, затем совпадают вторые, середина остаётся сама собой. Прямой способ — проверять пары индексов с концов. В Python та же идея коротко выражается сравнением text с text[::-1]. Мы создаём всю обратную запись и проверяем полное равенство.

Правила сравнения важны. Топот с заглавной Т не равен своей обратной записи топоТ, если регистр значим. Пробелы тоже сравниваются. В этой задаче не надо автоматически удалять знаки или менять регистр. Пустая строка равна своей обратной пустой строке, поэтому получает ДА.

## Задача и формат данных

Определить, одинаково ли читается строка слева направо и справа налево.

**Ввод:** Одна строка.

**Вывод:** ДА либо НЕТ.

**Допустимые данные:** До 1000 символов; регистр, пробелы и знаки считаются значимыми; пустая строка считается палиндромом.

# 24. Методы строк: очистка, регистр и замена

Нужные знания: Строки, сравнение и неизменяемость

## От задачи к способу решения

**Метод** — операция, вызываемая через значение: `text.lower()`. Слева от точки находится строка, справа — имя метода со скобками. Уже знакомая функция len вызывается иначе: `len(text)`. Это две формы обращения к готовым операциям.

`lower()` создаёт строку со строчными буквами, `upper()` — с прописными. `strip()` убирает пробельные символы по обоим краям. Он не удаляет пробелы внутри предложения. `lstrip()` и `rstrip()` обрабатывают только одну сторону. Без аргумента речь идёт не только об обычном пробеле, но и о других пробельных символах.

Задача: пользователь ввёл два пробела, слово ПоМоЩь и ещё два пробела. Для сравнения с известной командой помощь внешние пробелы и регистр не должны мешать. Сначала strip даёт ПоМоЩь, затем lower даёт помощь. Такие преобразования по заранее выбранным правилам называются **нормализацией**.

Методы не меняют существующую строку. Запись `text.strip()` без сохранения вычислит новый результат и потеряет его. Пишите `cleaned = text.strip()`, затем `command = cleaned.lower()`. Цепочка `text.strip().lower()` допустима, но сначала полезно увидеть два отдельных шага и понять, к какому результату применяется второй метод.

`replace(old, new)` создаёт текст, где заменены все вхождения old. Третий аргумент ограничивает число замен. Например, `'a-a-a'.replace('-', ':', 1)` даёт a:a-a. Это преобразование, а не поиск первого индекса. `strip('ab')` тоже не удаляет готовое слово ab: аргумент задаёт набор символов, которые можно снимать с краёв. Для удаления определённого фрагмента нужны другие договорённости.

Методы `isalpha()`, `isdigit()` и `isalnum()` отвечают, состоит ли непустая строка соответственно из букв, цифр или букв и цифр. Они учитывают Unicode, поэтому isdigit не ограничивается десятью латинскими символами 0–9. Для такого узкого формата используйте явные границы или проверку принадлежности строке '0123456789'. Для отрицательной записи '-12' isdigit возвращает False из-за знака.

Нормализация уместна только по правилам задачи. Пароль и точный идентификатор нельзя произвольно приводить к нижнему регистру: можно изменить их смысл.

# 25. Поиск, подсчёт и построение строки

После урока вы сможете: Отличать поиск вхождения от подсчёта и собирать ответ по правилу.

Нужные знания: Цикл по символам и строковые методы

## От задачи к способу решения

**Вхождение** — место, где искомый фрагмент встретился в тексте. Оператор `in` спрашивает о наличии: `'cat' in text` даёт True, если фрагмент встречается. Пустая строка содержится в любой строке. В проверке отдельного символа `character in 'aeiou'` вопрос проще: входит ли он в наш набор гласных.

`text.find(fragment)` возвращает индекс первого вхождения или −1, если ничего не найдено. Ноль — допустимый найденный индекс, поэтому нельзя писать `if text.find(fragment):`: найденный в начале фрагмент будет трактоваться как ложное число, а −1 как истинное. Проверяйте `!= -1` или используйте in, если позиция не нужна.

`text.count(fragment)` считает непересекающиеся вхождения. В aaaa фрагмент aa считается два раза, хотя начал перекрывающихся пар три. Выберите правило задачи прежде, чем выбирать метод. Для отдельного символа перекрытие не возникает.

В сквозной задаче нужен счётчик пяти видов ASCII-гласных в обоих регистрах. Пройдём исходную строку без изменения регистра. Если символ входит в 'AEIOUaeiou', увеличим счётчик. Для Apple! подходят A и e, значит ответ 2. Никакой отдельной обработки восклицательного знака не нужно: он просто не входит в набор.

Здесь сохраняем исходные символы намеренно. В Unicode смена регистра иногда меняет число кодовых точек: İ может превратиться в i и отдельно записанную точку. Но условие разрешает только явно перечисленные ASCII-буквы, поэтому прямой тест принадлежности точнее общей нормализации. ASCII — базовый набор символов, в который входят английские буквы, цифры и привычные знаки.

Построение строки похоже на сумму, но начало — пустой текст: `result = ''`. На шаге можно делать `result += character`, если символ подходит. Это создаёт новое строковое значение, потому что строки неизменяемы. В учебных пределах короткие ответы так собирать удобно; для длинных текстов лучше накапливать части в списке и затем использовать join, который изучим дальше.

# 26. Разбиваем текст на слова: split и join

После урока вы сможете: Получить список частей строки и соединить его с новым разделителем.

Нужные знания: Строковые методы, for и len

## От задачи к способу решения

Чтобы работать со словами отдельно, нужно получить несколько элементов из одной строки. `text.split()` разбивает её по пробельным символам и возвращает **список** строк. Список — упорядоченная коллекция элементов. Пока достаточно понять, что у него есть длина и его можно пройти циклом; изменение списков изучим в следующих уроках.

Для строки с внешними и двойными пробелами «  учим  Python вместе  » результат — три элемента: 'учим', 'Python', 'вместе'. split без аргумента объединяет соседние пробельные разделители и не оставляет пустые элементы на краях. Если текст только из пробелов, получится пустой список.

`text.split(',')` работает иначе: разделяет по конкретной запятой, сохраняя пустые части. Например, 'a,,b'.split(',') даёт 'a', '', 'b'. Пустой текст с явным разделителем даёт один пустой элемент. Поэтому выбирайте вызов по формату, а не по привычке.

Обратная операция **join** соединяет строковые элементы. Запись `'-'.join(words)` читается так: соединить элементы words, вставляя '-' между соседними. Метод вызывается через разделитель. Он не добавляет дефис в начале или конце. Все элементы должны быть строками; список целых сначала нужно преобразовать, что разберём при вводе списков.

Получив words, используем len(words) для количества. В программе нет отдельного ручного счётчика: операция len уже хранит нужный размер списка. Затем join строит новый текст. Внутренние знаки препинания остаются частью слова: 'кот,' — один элемент с запятой. Мы не решаем лингвистический разбор, а выполняем точно заданное деление по пробелам.

Для одного слова join вернёт его без разделителей; для пустого списка — пустую строку. Поэтому ответ всегда печатается двумя строками: во второй может не быть символов, но команда print добавит перенос строки. Эта договорённость важна для проверки пустого ввода.

## Задача и формат данных

Подсчитать слова и соединить их дефисами, игнорируя лишние пробелы.

**Ввод:** Одна строка.

**Вывод:** Количество слов первой строкой, слова через дефис второй.

**Допустимые данные:** До 1000 символов; словом считается непустая часть между пробельными символами.

Вход сквозного примера:

```text
  учим  Python вместе  
```

Ожидаемый вывод:

```text
3
учим-Python-вместе
```

## Как читать реализацию

## Почему работает и сколько действий требуется

split даёт ровно непустые части по оговорённому правилу, len считает их, join вставляет один дефис на каждую границу между словами. Чтение, разбиение и соединение линейны по общей длине текста; память для списка частей и результата тоже линейна.

## Границы и частые ошибки

При явном разделителе пустые элементы меняют смысл результата. join не принимает целые элементы автоматически. Слово в этом упражнении определено форматом, а не словарём русского языка.

# 27. Списки: создаём и храним несколько значений

После урока вы сможете: Прочитать список чисел и повторно использовать все элементы.

Нужные знания: split, индексы и циклы

## От задачи к способу решения

В сумме можно забывать старые значения. Но для обратного вывода нужны все числа: последнее выводится первым, а первое — последним. Поэтому сохраняем коллекцию целиком. **Список**, тип list, хранит упорядоченные элементы; пример литерала — `[3, 1, 4]`. **Литерал** — запись значения прямо в коде. Пустой список записывается `[]`.

`numbers.append(value)` добавляет один элемент в конец списка. Создадим пустой numbers, затем n раз прочитаем число и добавим его. Через три шага на входе 3, −1, 5 получаем [3, −1, 5]. Порядок совпадает с порядком ввода.

Список поддерживает знакомые len, индексы с нуля, отрицательные индексы и срезы. numbers[::-1] даёт новый список в обратном порядке. `sum(numbers)` получает сумму числовых элементов, а sum([]) равна нулю. `min(numbers)` и `max(numbers)` требуют непустого списка, если отдельно не задано поведение для пустого.

Для вывода через пробел удобно сначала получить текстовые части. Создадим пустой parts, пройдём обратный список, добавим `str(value)` для каждого числа и вызовем `' '.join(parts)`. Этот способ использует уже известные операции. Вывод самого списка через print(numbers) выглядел бы как `[3, -1, 5]`, со скобками и запятыми; это иной формат.

Ещё один способ — `print(*numbers)`: звёздочка в таком вызове передаёт каждый элемент как отдельный аргумент. Для пустого списка печатается пустая строка. Это распаковка аргументов, а не умножение; смысл зависит от места знака. В основной реализации пока оставим явное преобразование, чтобы связь типов была видна.

Список может хранить значения разных типов, но для числовой суммы держим в нём только int. Разнородный список не делает автоматически допустимыми сложение или сортировку его элементов. Выберите понятный контракт для содержимого своей коллекции.

## Задача и формат данных

Прочитать n чисел, затем вывести их количество, сумму и обратный порядок.

**Ввод:** n первой строкой, затем n целых чисел отдельными строками.

**Вывод:** Количество и сумма через пробел первой строкой; числа в обратном порядке через пробел второй строкой.

**Допустимые данные:** 0 <= n <= 1000; элементы от −10000 до 10000.

Вход сквозного примера:

```text

-1
5
```

Ожидаемый вывод:

```text

5 -1 3
```

| 4 | Сумма 7; обратные текстовые части 5, -1, 3 | Вывод: 3 7 и 5 -1 3 |

## Полная программа

```python

Метод append меняет список и возвращает None — отсутствие полезного возвращаемого значения. Не пишите numbers = numbers.append(value): так имя numbers перестанет обозначать список.

## Почему работает и сколько действий требуется

Все n значений добавляются по одному и сохраняются в порядке ввода; срез разворачивает именно эту последовательность. Чтение, суммирование и преобразование проходят элементы по одному. Работа и суммарная память линейны по n при данных ограниченных размерах чисел; копия среза и текстовые части тоже учтены.

## Границы и частые ошибки

Хранение всего ввода нужно для обратного порядка, но излишне для одной суммы. Не считайте срез бесплатным: он добавляет память для n ссылок на элементы.

# 28. Изменение списков, общие ссылки и копии

После урока вы сможете: Отличать новое имя того же списка от независимой копии.

Нужные знания: Список, append и индексы

## От задачи к способу решения

Строки неизменяемы, а списки **изменяемы**: можно записать `numbers[0] = 99` и заменить элемент в уже существующем объекте. Индекс по-прежнему должен существовать. Присваивание элементу не добавляет новую позицию в конец.

Теперь важна точная картина переменной: имя ссылается на объект. Запись `other = numbers` не копирует содержимое списка, а даёт второе имя того же объекта. Если сделать other.append(7), изменение будет видно через numbers. Если позже написать `other = []`, имя other переключится на другой объект, а numbers по-прежнему будет ссылаться на прежний список.

Для независимого плоского списка используем `numbers.copy()` или `numbers[:]`. Они создают новый список с теми же элементами. Плоский означает, что здесь элементы — числа, а не вложенные списки. Для вложенных списков копия внешнего списка ещё не копирует внутренние объекты: это **поверхностная копия**. Матрицы не являются темой данного урока, но такое ограничение нужно знать перед их использованием.

Сквозной пример: исходный список [2, 4, 6], новое первое значение 9. Сначала создаём edited = numbers.copy(). Затем edited[0] = 9. Исходный список остаётся [2, 4, 6], копия становится [9, 4, 6]. Если вместо copy написать обычное присваивание, оба имени покажут [9, 4, 6].

Другие методы: `insert(index, value)` вставляет элемент перед указанной позицией; `pop(index)` удаляет элемент и возвращает его, а без индекса удаляет последний; `remove(value)` удаляет первое равное значение и выдаёт ValueError, если его нет; `clear()` удаляет все элементы. append, insert, remove и clear изменяют объект и не возвращают новый список.

Не удаляйте элементы из списка в обычном проходе по нему без специального плана: позиции сдвигаются, и соседний элемент можно пропустить. Для отбора подходящих значений понятнее построить новый список. В следующем уроке сделаем именно так.

## Задача и формат данных

**Ввод:** Список целых в первой строке; новое первое значение во второй.

**Вывод:** Исходный список первой строкой, изменённая копия второй, элементы через пробел.

**Допустимые данные:** От 1 до 1000 элементов; числа и замена от −10000 до 10000.

Вход сквозного примера:

```text

9
```

Ожидаемый вывод:

```text

```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |

Копирование выполняется до замены. numbers и edited содержат одинаковые числовые значения, но внешние списки разные. Исходный список обещан непустым, поэтому индекс 0 допустим. Удаление последнего элемента через pop не подходит для замены первого.

copy отделяет структуру плоского списка, поэтому присваивание в edited не меняет numbers. Чтение, копирование и вывод требуют линейной работы по числу элементов. Помимо исходного списка хранится копия такой же длины; дополнительная память линейна.

# 29. Отбор, поиск и сортировка списка

После урока вы сможете: Сохранить подходящие элементы и объяснить, когда можно менять порядок.

Нужные знания: Циклы по спискам, append и копии

## От задачи к способу решения

**Отбор**, или фильтрация, оставляет элементы, удовлетворяющие правилу. Вместо удаления из исходного списка создадим пустой positive. Для каждого value при value > 0 добавим его. Так порядок входа пока сохраняется, а повторы не исчезают: два подходящих элемента — два добавления.

**Сортировка** переставляет элементы по выбранному порядку. `positive.sort()` меняет существующий список по возрастанию. `sorted(positive)` возвращает новый отсортированный список, оставляя исходный неизменным. `reverse=True` задаёт убывание в обоих вызовах. sort возвращает None, поэтому `positive = positive.sort()` уничтожит связь имени со списком.

Для входа 3, −1, 3, 0, 2 отбор даёт [3, 3, 2], затем сортировка [2, 3, 3]. Количество три, а не два: мы не считаем различные значения. Сортировка чисел int и текстовых записей str различается. У строк '10' и '2' порядок начинается с первого символа, поэтому '10' идёт раньше '2'. Для числового порядка преобразуйте ввод в int до сортировки.

**Линейный поиск** проходит элементы по очереди. Можно спросить `target in numbers`, если нужен только факт наличия. `numbers.index(target)` возвращает первый индекс, но при отсутствии выдаёт ValueError. Чтобы получить −1 при отсутствии, можно пройти индексы вручную, начать position = −1, при совпадении сохранить index и сделать break.

Сортировка допустима, когда порядок входа не является частью ответа. Если нужно вернуть первые положительные числа по времени поступления, sort нарушит задачу. Для поиска исходного номера максимума тоже нельзя сначала переставить значения и забыть старые номера.

Подбирайте операции по потребности: одной сумме сортировка не нужна; упорядоченному выводу нужна. На маленьком примере это почти незаметно, но лишняя сортировка увеличивает работу с линейного прохода до порядка n log n сравнений в худшем случае для готовой сортировки CPython.

Расшифруем эту оценку. n — число элементов, а log₂ n описывает число последовательных делений пополам. Для степеней двойки это точное число делений до 1: для 8 — 3, для 16 — 4. Для других n целое число шагов может требовать округления. Поэтому n log n растёт быстрее n, но медленнее n². Здесь это свойство готовой операции сортировки, а не вывод из одного вызова sort. CPython — обычная реализация Python, в которой проверен код курса. Реализацию сортировки писать сейчас не требуется; её описание находится в [материалах CPython](https://github.com/python/cpython/blob/3.11/Objects/listsort.txt). В оценках роста основание логарифма обычно опускают, потому что оно меняет только постоянный множитель.

## Задача и формат данных

Из целых чисел выбрать положительные и вывести их по возрастанию.

**Ввод:** Одна строка целых чисел через пробел, возможно пустая.

**Вывод:** Количество выбранных первой строкой, отсортированные выбранные числа второй.

**Допустимые данные:** До 1000 элементов, значения от −10000 до 10000; повторы сохраняются.

Вход сквозного примера:

```text

```

Ожидаемый вывод:

```text

2 3 3
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |

| 1 | 3 подходит, -1 нет, следующая 3 подходит | positive = [3, 3] |
| 2 | 0 не положителен, 2 подходит | positive = [3, 3, 2] |
| 3 | sort переставляет элементы по числовому возрастанию | positive = [2, 3, 3] |

## Полная программа

```python

    value = int(token)

        positive.append(value)

## Как читать реализацию

tokens хранит части исходной строки, value — очередное преобразованное число. positive сохраняет только подходящие числа. После sort порядок изменён намеренно. Сумма не вычисляется: ответ требует количество и конкретную последовательность.

## Почему работает и сколько действий требуется

Каждый положительный элемент добавляется один раз и никакой другой не добавляется. Сортировка меняет только порядок, сохраняя элементы и повторы. Для n входных элементов и k выбранных отбор линейный, сортировка до порядка k log k, общий худший порядок n log n. Хранение частей ввода, выбранных элементов и служебной памяти сортировки линейно.

## Границы и частые ошибки

Пустой список можно сортировать и выводить. Поиск index в пустом списке выдаст ValueError. Если нужен прежний порядок, пропустите сортировку.

# 30. Списковые включения: короткая запись знакомого цикла

После урока вы сможете: Читать включение как отбор и преобразование, не скрывая смысл за краткостью.

Нужные знания: Создание списка, отбор и арифметика

## От задачи к способу решения

Часто программа делает одну и ту же цепочку: создать список → пройти исходные элементы → при подходящем условии добавить преобразованный элемент. **Списковое включение** записывает эту цепочку одним выражением.

`[value ** 2 for value in numbers if value % 2 == 0]` читается по смыслу так: для каждого value из numbers, если оно чётное, включить value ** 2. Первая часть задаёт новый элемент, часть for — источник, часть if — отбор. Результат — новый список. Источник не изменяется.

Для [3, −2, 0, 4] число 3 не проходит проверку. −2 проходит и даёт 4. Ноль проходит и даёт 0. Четыре проходит и даёт 16. Получаем [4, 0, 16], в порядке исходных подходящих элементов, а не по возрастанию квадратов.

Строковый ввод тоже удобно преобразовать включением: `[int(token) for token in input().split()]`. Сначала input получает текст и split делит его на строковые части. Затем для каждой части int создаёт числовой элемент нового списка. Здесь нет if, потому что преобразуются все части.

Короткая форма полезна только после понимания длинной. Если в теле нужны несколько действий, служебный вывод, сложные ветви или выход через break, обычный for часто понятнее. Не превращайте весь алгоритм в одну строку ради внешней компактности.

Включение создаёт все элементы сразу. Оно не уменьшает память до постоянной и не делает цикл быстрее по порядку роста. Для суммы из потокового ввода хранение списка может вообще не понадобиться. Сравнивайте потребности задачи, а не длину записи.

Вложенные включения существуют, но требуют уже уверенного понимания порядка двух циклов. В этом курсе для таблиц оставляем явные циклы. Ошибка начинающего часто заключается не в незнании краткой формы, а в том, что она скрыла порядок вычислений и отбор.

## Задача и формат данных

Выбрать чётные числа и получить их квадраты в исходном порядке.

**Ввод:** Строка целых чисел через пробел, возможно пустая.

**Вывод:** Квадраты выбранных чисел через пробел.

**Допустимые данные:** До 1000 чисел, каждое от −10000 до 10000.

Вход сквозного примера:

```text

```

Ожидаемый вывод:

```text

```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | Прочитать все числовые элементы | numbers = [3, -2, 0, 4] |
| 2 | 3 нечётно, -2 чётно: включить квадрат -2 | result = [4] |
| 3 | 0 и 4 чётны: включить их квадраты по порядку | result = [4, 0, 16] |

## Полная программа

```python
numbers = [int(token) for token in input().split()]

print(*result)
```

## Как читать реализацию

Условие проверяет исходное value, а первая часть строит элемент результата. Имена token и value относятся к разным проходам. Вывод с распаковкой показывает числа без списка со скобками. Для восстановления включения напишите пустой result, for, if и append(value ** 2).

## Почему работает и сколько действий требуется

Включение повторяет ровно описанный явный цикл: каждый элемент проверен один раз, чётные преобразованы и добавлены. Для n небольших чисел работа линейна, исходный и итоговый списки требуют линейной памяти. Отсутствие выбранных элементов корректно даёт пустой result.

## Границы и частые ошибки

Включение не подходит для неизвестного бесконечного потока: оно пытается завершить построение списка целиком. Обработка ошибок int не исчезает из-за краткой записи.

# 31. Свои функции: отделяем действие и вызываем его

После урока вы сможете: Определить функцию с параметром и вызвать её несколько раз.

Нужные знания: Переменные, условия, циклы и готовые функции

## От задачи к способу решения

Повторяющиеся строки программы можно вынести в функцию. **Определение функции** описывает действие и даёт ему имя. **Вызов** выполняет это действие с конкретными данными. Они различаются: запись определения сама по себе не печатает приветствие.

`def greet(name):` вводит функцию greet. **Параметр** name — имя для данных, которые будут переданы при вызове. Тело функции пишется с отступом. Вызов `greet(first)` передаёт значение first как **аргумент**; внутри данного вызова оно доступно под параметром name.

Для Ани и Льва правило приветствия одинаковое. Можно написать два print, но тогда изменение формата пришлось бы внести в два места. Функция хранит одно описание: вывести Привет, затем имя, затем !. Оба вызова используют его. Это полезно не только для экономии строк: имя greet объясняет назначение действия.

Объявим функцию раньше вызовов. Python должен выполнить def и связать имя с функцией к тому моменту, когда встретит greet(first). Затем читаем два имени, вызываем greet для первого, потом для второго. После каждого вызова выполнение возвращается к следующей команде основной программы.

Имя параметра не обязано совпадать с именем переданной переменной. При greet(first) параметр name получает значение first; при greet(second) — значение second. Нельзя сделать вывод, что переменная name основной программы изменилась: у функции собственное пространство локальных имён, которое подробнее разберём дальше.

Наш greet создаёт вывод как действие. Такой эффект полезен для оформления сообщений, но не стоит прятать в нём чтение имени: тогда связь между аргументом и результатом исчезнет. Получать данные удобно в основной программе, а функции передавать уже готовое значение. Позже функция сможет возвращать рассчитанный ответ без печати.

Имена функций лучше выбирать по смыслу действия: greet, print_report, calculate_total. Не нужно выносить каждую строку в отдельную функцию. Хорошая функция имеет понятную работу и контракт: здесь принимает одно имя, выводит одну строку приветствия.

## Задача и формат данных

Для двух введённых имён вывести по персональному приветствию.

**Ввод:** Два имени на отдельных строках.

**Вывод:** Две строки вида Привет, имя!.

**Допустимые данные:** Длина каждого имени от 1 до 100 символов.

Вход сквозного примера:

```text

Лев
```

Ожидаемый вывод:

```text

Привет, Лев!
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | def создаёт функцию; тело пока не выполняется | Имя greet доступно для вызова |
| 2 | Прочитать два имени | first = Аня, second = Лев |
| 3 | greet(first): параметр name получает Аня | Привет, Аня! |
| 4 | greet(second): новый вызов получает Лев | Привет, Лев! |

```python

## Как читать реализацию

f-строка вставляет значение параметра name. Пустая строка в исходном коде отделяет определение от основной части для чтения; она не создаёт вывода. Круглые скобки в greet(first) необходимы для вызова: запись greet без скобок лишь обращается к объекту функции.

## Почему работает и сколько действий требуется

Оба имени по одному передаются одному правилу оформления, поэтому каждый вызов печатает нужную строку. Работа пропорциональна суммарной длине имён; они хранятся как строки. В каждый момент выполняется один короткий вызов, вложенность не растёт.

## Границы и частые ошибки

Функция вызывается столько раз, сколько указано вызовов. Один def не запускает тело. Чтобы напечатать n приветствий, вызов можно поставить в цикл.

# 32. Возвращаем результат: return, локальные имена и параметры

После урока вы сможете: Сделать вычисляющую функцию, использовать её ответ и объяснить область имён.

Нужные знания: def, вызовы и списки

## От задачи к способу решения

Функция может не печатать, а **возвращать** значение вызывающему коду. Команда `return expression` вычисляет expression, завершает текущий вызов и передаёт результат. Затем основная программа сама решает, печатать его, сохранить или использовать в другом расчёте.

Для цены 200 и скидки 15 процентов остаётся 85 процентов цены: 200 * 85 / 100 = 170. Определим discounted_price(price, percent). Параметры отвечают на два входных вопроса, результат — новая цена. Можно вызвать эту функцию в нескольких местах с разными аргументами без копирования формулы.

Разница с print принципиальна. Если функция только печатает 170, это сообщение на экране не становится числом в переменной вызывающего кода. Функция без выполненного return возвращает `None` — специальное значение отсутствующего результата. Поэтому `answer = print(170)` сначала печатает 170, а answer становится None.

**Область видимости** — часть программы, где доступно имя. Параметры и присваивания внутри функции создают локальные имена. После завершения вызова нельзя рассчитывать на доступ к его параметрам из основной части. Передавайте нужные данные явно и возвращайте результат. В этой программе внешняя переменная original_price передаётся внутреннему price, хотя имена различаются.

**Аргумент по умолчанию** позволяет не передавать одно значение. Запись `def discounted_price(price, percent=0):` задаёт нулевую скидку при вызове с одной ценой. По умолчанию не следует использовать изменяемый список: такой объект создаётся один раз при определении и может сохранять изменения между вызовами. Для нашего числового значения этой проблемы нет.

Передача списка не копирует его. Если функция выполнит append над переданным списком, изменение увидит вызывающий код. Чистая вычисляющая функция не меняет чужие данные и при тех же аргументах получает тот же ответ; такую функцию легче проверять отдельно. Для скидки выберем именно вычисляющую форму.

return может находиться в if и выполнять ранний выход. Команды после выполненного return в этом вызове уже не выполняются. Несколько return допустимы для разных случаев; важно, чтобы у всех разрешённых входов был определён нужный результат.

## Задача и формат данных

Вычислить стоимость товара после скидки в процентах.

**Ввод:** Целая цена и целый процент скидки на отдельных строках.

**Вывод:** Новая цена с двумя знаками после точки.

**Допустимые данные:** Цена от 0 до 1000000; процент от 0 до 100.

Вход сквозного примера:

```text

15
```

Ожидаемый вывод:

```text

```

## Пройдём пример руками

| 1 | Прочитать исходные данные | original_price = 200, discount = 15 |
| 2 | Вызов передаёт данные параметрам | price = 200, percent = 15 |

Аргумент по умолчанию в этой основной программе не используется, потому что оба значения заданы явно, но вызов discounted_price(200) тоже допустим.

После скидки p процентов остаётся 100 - p процентов цены, что прямо выражает формула. Для допустимого диапазона доля неотрицательна. Число действий и глубина вызова постоянны; для вывода применяется приближённая арифметика float и оговорённое форматирование.

# 33. Неверный ввод и проверка функций

После урока вы сможете: Обработать ожидаемую ошибку преобразования и проверить контракт функции.

Нужные знания: Функции, return, if и сообщения об ошибках

## От задачи к способу решения

В задачах раньше гарантировался правильный ввод. В программе для человека опечатка ожидаема. **Проверка ввода** отделяет допустимые данные от неправильных и даёт понятный ответ. Сначала проверим возможность получить целое число, затем его диапазон: это разные причины отказа.

`try` начинает блок, где возможна ожидаемая ошибка. `except ValueError` задаёт действие при конкретном исключении ValueError. `else` у try выполняется только если блок try закончился без исключения. Это другое применение слова else, отдельное от if и циклов.

Разместим внутри try только `age = int(text)`. Если введено abc или 18.5, преобразование невозможно: печатаем ЧИСЛО. Если преобразование удалось, в else проверяем отрезок от 0 до 120. Для 121 печатаем ДИАПАЗОН; для 18 — ПРИНЯТО.

Не пишите пустой общий except, который прячет любые ошибки. Опечатка в имени или неверный алгоритм требуют исправления кода, а не сообщения «плохой пользователь». Перехватываем только ту ошибку, которую ожидаем от оговорённого действия.

Вычисляющие функции удобно проверять **утверждениями assert**: `assert expression` требует, чтобы expression было истинным, иначе возникает AssertionError. Например, после отдельного определения is_even можно проверить assert is_even(0) и assert not is_even(3). Это проверка собственного кода, а не механизм защиты ввода: при оптимизированном запуске Python проверки assert могут отключаться.

Для каждой функции подготовьте случаи: обычный, минимальный, граничный и такой, который ломает правдоподобную ошибку. Для count_positive нужны пустой список, одни отрицательные, ноль и положительные. Проверка одного [1, 2] не обнаруживает ошибку >= 0 вместо > 0.

**Декомпозиция** — разделение программы на понятные части. Ввод и сообщения могут находиться снаружи, а функция in_age_range(age) отвечает только за числовое правило. Это позволяет тестировать правило без ожидания input. Контракт функции: принимает целое и возвращает bool; ошибки преобразования в её работу не входят.

## Задача и формат данных

Проверить ввод возраста: текст должен быть целым числом от 0 до 120.

**Ввод:** Одна произвольная строка длиной до 100 символов.

**Вывод:** ЧИСЛО для неподходящей числовой записи, ДИАПАЗОН для целого вне границ, ПРИНЯТО для допустимого возраста.

**Допустимые данные:** Принимается любой текст указанной длины; целое преобразуется стандартным int.

Вход сквозного примера:

```text
121
```

Ожидаемый вывод:

```text
ДИАПАЗОН
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | Получить текст 121 | text = 121 как строка |
| 2 | int успешно создаёт целое, except не выполняется | age = 121 |
| 3 | Число выше включённой верхней границы | in_age_range(age) = False |
| 4 | Выбрать сообщение об ошибке диапазона | ДИАПАЗОН |

## Полная программа

```python
def in_age_range(age):
    return 0 <= age <= 120

text = input()
try:
    age = int(text)
except ValueError:
    print('ЧИСЛО')
else:
    if in_age_range(age):
        print('ПРИНЯТО')
    else:
        print('ДИАПАЗОН')
```

## Как читать реализацию

## Почему работает и сколько действий требуется

# 35. Мини-проект: учебный генератор паролей

## От задачи к способу решения

Это упражнение на случайный выбор и сборку текста. random подходит для учебной игры, но не для настоящих секретных паролей: его последовательность можно предсказывать по состоянию. Для реальных секретов нужен специально предназначенный генератор, например модуль secrets. Здесь изучаем механику строки и не обещаем безопасность результата.

Зафиксируем **алфавит** — строку всех разрешённых символов. `random.choice(alphabet)` возвращает один случайно выбранный элемент непустой последовательности. Повторяя выбор length раз, получим length символов. Один и тот же символ может выпадать несколько раз: выбирать с повторениями разрешено.

Чтобы не наращивать неизменяемую строку на каждом шаге, будем добавлять выбранные символы в список parts. Затем `''.join(parts)` соединит их без разделителя. Функция generate_password(length) возвращает строку; основной код задаёт seed, вызывает её и печатает результат.

Воспроизводимый пример: в фактически проверенной среде Python 3.13.0 seed 7 и длина 8 дают u8jzPde0. Seed не является длиной или секретом; он выбирает начальное состояние случайной последовательности. Для учебного примера фиксированный seed позволяет сравнивать запуски. Совпадение конкретной последовательности разных версий random не является общим обещанием курса; отчёт фиксирует использованную среду.

Генератор не гарантирует хотя бы одну цифру, заглавную и строчную букву в каждой строке. Он только разрешает эти символы. Например, при длине 1 выполнить требование трёх категорий вообще невозможно. Проверять такой результат надо по нескольким уровням. При фиксированной среде и seed можно сравнить точный пример. Независимо от последовательности нужно проверить длину и принадлежность каждого символа разрешённому набору. Нельзя считать правильной только красивую строку из демонстрации: функция должна работать и при длине ноль.

Для length = 0 список частей пуст, join возвращает пустую строку, а print выводит только перевод строки. Это предусмотренный результат, не ошибка генерации.

## Задача и формат данных

Сгенерировать учебную строку из латинских букв обоих регистров и цифр.

**Ввод:** Seed и длина отдельными строками.

**Вывод:** Одна сгенерированная строка заданной длины.

# 36. Мини-проект: шифр Цезаря и круговой сдвиг

После урока вы сможете: Перевести буквенное правило в индексы и сохранить посторонние символы.

Нужные знания: Строки, остаток, функции и join

## От задачи к способу решения

Шифр Цезаря заменяет букву другой буквой через заданное число позиций алфавита. При сдвиге 2: a превращается в c, b в d, y в a, z в b. После конца алфавита движение продолжается с начала. Это учебное преобразование легко обратить и оно не защищает настоящую переписку.

Сначала работаем с одной строчной буквой. Дадим буквам номера от 0 до 25: a — 0, b — 1, ..., z — 25. После прибавления сдвига номер может выйти за границу. Остаток на 26 возвращает его в допустимый круг: для z и сдвига 2 получаем (25 + 2) % 26 = 1, то есть b.

`ord(character)` возвращает целочисленный код одной кодовой точки Unicode. `chr(number)` получает строку с кодовой точкой заданного кода. Латинские ASCII-буквы a–z идут подряд в таблице кодов. Поэтому номер буквы равен `ord(character) - ord('a')`, а новая буква получается через chr от начала алфавита плюс новый номер. Для прописных используем начало 'A' отдельно.

Нельзя применять такой расчёт ко всему Unicode: чужие буквы и знаки не обязаны находиться в этих непрерывных 26 позициях. Проверим сначала диапазон 'a' <= character <= 'z', затем прописной диапазон. Все остальные символы возвращаем неизменными. Русские буквы в этой конкретной программе не шифруются, потому что условие задаёт только латиницу.

Сквозной пример Az-z! со сдвигом 2 даёт Cb-b!. A сдвигается внутри прописного алфавита в C. z оборачивается в b. Дефис и восклицательный знак сохраняются. Это одновременно проверяет обе ветви регистров и сохранение посторонних символов.

Функция shift_character решает задачу одного элемента. Функция caesar проходит весь текст, собирает части и возвращает строку. Такое разделение позволяет сначала проверить буквы на границе, а затем переносить работу на любую длину текста.

Отрицательный сдвиг означает движение назад. При положительном делителе 26 остаток в Python неотрицателен: для a и −1 получаем номер 25, букву z. Для расшифровки можно вызвать тот же алгоритм с противоположным сдвигом; новое правило не требует отдельного перебора букв.

## Задача и формат данных

Сдвинуть латинские буквы на заданное число позиций, сохранив регистр.

**Ввод:** Сдвиг целым числом первой строкой, текст второй.

**Вывод:** Преобразованный текст одной строкой.

**Допустимые данные:** −1000000 <= shift <= 1000000; до 1000 символов; меняются только ASCII a–z и A–Z.

Вход сквозного примера:

```text
2
Az-z!
```

Ожидаемый вывод:

```text
Cb-b!
```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | A: номер 0, после сдвига 2, регистр сохраняется | C |
| 2 | z: (25 + 2) % 26 = 1 | Cb |
| 3 | Дефис не буква: сохранить, затем ещё z сдвинуть в b | Cb-b |
| 4 | ! не буква: сохранить | Cb-b! |

## Полная программа

```python
def shift_character(character, shift):
    if 'a' <= character <= 'z':
        start = ord('a')
    elif 'A' <= character <= 'Z':
        start = ord('A')
    else:
        return character
    position = ord(character) - start
    new_position = (position + shift) % 26
    return chr(start + new_position)

def caesar(text, shift):
    parts = []
    for character in text:
        parts.append(shift_character(character, shift))
    return ''.join(parts)

shift = int(input())
text = input()
print(caesar(text, shift))
```

## Как читать реализацию

start выбирается по регистру. position обозначает номер внутри своего алфавита, а не общий Unicode-код. new_position всегда от 0 до 25. Ранний return для постороннего символа не позволяет использовать не заданный start. caesar ничего не печатает, её результат выводит основная часть.

## Почему работает и сколько действий требуется

Для каждой латинской буквы вычисляется её номер, круговой сдвиг и обратное преобразование в букву того же регистра. Другие символы остаются неизменными. Каждый символ обработан один раз, значит время линейно по длине L; список частей и строка результата занимают линейную дополнительную память.

# 37. Мини-проект: системы счисления

После урока вы сможете: Объяснить позиционную запись и построить представление в другом основании.

Нужные знания: Цифры числа, while, индексы и функции

## От задачи к способу решения

В десятичной записи 243 означает 2 * 100 + 4 * 10 + 3. Разряды соответствуют степеням 10. **Основание системы счисления** задаёт число доступных цифр и вес каждого следующего разряда. В двоичной системе есть только 0 и 1, веса справа налево — 1, 2, 4, 8 и далее.

Например, двоичное 1101 — это 1 * 8 + 1 * 4 + 0 * 2 + 1 = 13. Само число не меняется от выбора записи: меняется способ показать его цифрами. В шестнадцатеричной системе нужны шестнадцать обозначений, поэтому после 0–9 используются A, B, C, D, E, F для значений 10–15.

Как получить цифры из десятичного значения? Для основания 10 мы брали остаток и делили на 10. То же правило действует для base: остаток remaining % base — младшая цифра, целое деление убирает этот разряд. Для 13 и основания 2 шаги дают остатки 1, 0, 1, 1. Их порядок справа налево, поэтому перед выводом разворачиваем список.

В строке digits = '0123456789ABCDEF' символ по индексу digit обозначает значение нужной цифры. Для остатка 10 берём A. Нельзя просто превращать остаток 10 через str: получится две позиции '10', а нужна одна цифра A.

Ноль разбираем отдельно: его запись '0'. Обычный while remaining > 0 не выполнится, поэтому без специального случая получилась бы пустая строка. Основание должно быть не меньше 2: при base = 1 деление не уменьшает положительное remaining, и цикл не завершится. Верхняя граница 16 согласована с длиной таблицы digits.

Python умеет эти преобразования и готовыми средствами: bin(number) показывает двоичную строку с префиксом 0b, hex(number) — шестнадцатеричную с префиксом 0x и строчными буквами. `int(text, base)` получает значение из текстовой записи в указанном основании. Однако сначала написанный вручную способ помогает понять, откуда берётся результат и почему требуется обратный порядок.

Сравните 13 в основаниях 2 и 16: 1101 и D. Обе записи можно снова прочитать через int с соответствующим основанием и получить 13. Это сильная проверка преобразования: мы сравниваем с независимым стандартным разбором записи.

Длина записи связана с числом делений. Для двоичного 13 рабочие значения идут 13 → 6 → 3 → 1 → 0, всего четыре шага. Если увеличить число примерно вдвое, добавляется около одного двоичного разряда, а не вдвое больше шагов. Логарифм по основанию base описывает число таких последовательных делений; точное число цифр для положительного number равно целой части этого логарифма плюс 1. Вычислять логарифм в программе не нужно: цикл сам определяет число шагов.

## Задача и формат данных

Перевести неотрицательное десятичное целое в основание от 2 до 16.

**Ввод:** Число и основание отдельными строками.

**Вывод:** Запись без префикса; цифры старше 9 — заглавные A–F.

**Допустимые данные:** 0 <= number <= 1000000000; 2 <= base <= 16.

Вход сквозного примера:

```text
13
2
```

Ожидаемый вывод:

```text

```

## Пройдём пример руками

| Шаг | Действие и причина | Состояние или результат |
| --- | --- | --- |
| 1 | 13 % 2 = 1, деление оставляет 6 | parts = ['1'], remaining = 6 |
| 2 | 6 % 2 = 0, деление оставляет 3 | parts = ['1', '0'], remaining = 3 |
| 3 | 3 % 2 = 1, деление оставляет 1 | parts = ['1', '0', '1'], remaining = 1 |
| 4 | 1 % 2 = 1, деление оставляет 0 | parts = ['1', '0', '1', '1'], remaining = 0 |
| 5 | Развернуть младшие цифры в привычный порядок | 1101 |

## Полная программа

```python
def to_base(number, base):
    if number == 0:
        return '0'
    digits = '0123456789ABCDEF'
    parts = []
    remaining = number
    while remaining > 0:
        digit = remaining % base
        parts.append(digits[digit])
        remaining //= base
    return ''.join(parts[::-1])

number = int(input())
base = int(input())
print(to_base(number, base))
```

## Как читать реализацию

remaining хранит часть, ещё не разобранную на разряды. parts хранит символы младших цифр сначала. Обратный срез меняет порядок, join убирает границы между частями. digits — таблица соответствия значений цифр их записи, её размер фиксирован.

## Почему работает и сколько действий требуется

На каждом шаге remaining = quotient * base + remainder. Остаток задаёт правильную младшую цифру, а quotient — остальные разряды. Повторение извлекает все цифры. При base >= 2 положительное remaining уменьшается и достигнет нуля. Для d цифр работа и дополнительная память пропорциональны d; d растёт примерно как логарифм number по основанию base. Это оценка для указанного диапазона обычных целых.

## Границы и частые ошибки

Отрицательные числа исключены; для них пришлось бы отдельно оформить знак и переводить модуль. Формат вывода требует заглавные A–F и не включает префиксы 0b или 0x.

```python
def money_text(kopecks):
    sign = ''
    if kopecks < 0:
        sign = '-'
    value = abs(kopecks)
    return f'{sign}{value // 100}.{value % 100:02d}'

def largest_purchase_index(purchases):
    if len(purchases) == 0:
        return -1
    best_index = 0
    for index in range(1, len(purchases)):
        if purchases[index][1] > purchases[best_index][1]:
            best_index = index
    return best_index

budget = int(input())
n = int(input())
purchases = []
for i in range(n):
    name = input()
    amount = int(input())
    purchases.append([name, amount])
total = 0
for purchase in purchases:
    total += purchase[1]
best_index = largest_purchase_index(purchases)
print('ИТОГО', money_text(total))
print('ОСТАТОК', money_text(budget - total))
if best_index == -1:
    print('НЕТ ПОКУПОК')
else:
    print('ПОКУПКА', purchases[best_index][0])
```

## Как читать реализацию
