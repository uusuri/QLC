# Python с нуля

Готовый начальный курс для человека, который ещё не программировал. Язык объяснений — русский, язык всех программ — Python.

## Как начать

Откройте [полный учебник](COURSE.md) или отдельный урок ниже. Первый урок объясняет подготовку и запуск. Для каждой программы сначала получите ответ руками, затем выполните её с данными примера. После чтения закройте реализацию и сделайте четыре задания. [Ответы и решения](ANSWERS.md) проверяйте после собственной попытки.

В каждом уроке есть цель, объяснение новых понятий, точный формат задачи, ручной проход, полная программа, разбор, обоснование, границы и практика. В папках уроков находятся запускаемые программы и решения задач.

## Основа и объём

38 законченных уроков, 152 задания с отдельными ответами, пять мини-проектов. Тематическая последовательность опирается на [«Поколение Python»: курс для начинающих](https://stepik.org/course/58852/promo). Объяснения, примеры и задания написаны самостоятельно. Это самостоятельный учебный материал; соответствие каждому отдельному шагу Stepik не заявляется.
