# Условие задачи в теории

Карточка появляется только по явной директиве. Обычный Markdown не меняется.

```markdown
:::problem Хватит ли мест?
## Условие
В зале `n` рядов по `m` мест. Хватит ли их для `k` человек?

## Ввод
Три целых числа `n m k`.

## Вывод
Напечатайте `YES`, если мест хватает, иначе `NO`.

## Ограничения
`1 ≤ n, m ≤ 100`, `1 ≤ k ≤ 10 000`.
:::
```

Обязательны заголовок после `:::problem` и четыре непустые секции с точными
названиями: `## Условие`, `## Ввод`, `## Вывод`, `## Ограничения`. В секциях
работают обычные абзацы, списки, таблицы, ссылки и блоки кода. Вложенные
`:::problem` запрещены. Директива не исполняет HTML.

Карточка ограничена 512 строками, 65 536 символами и заголовком в 160 символов.
Повреждённый закрытый блок показывается как исходный текст. Незакрытый или
слишком большой блок не поглощает следующий Markdown.

Условие и ограничения занимают всю ширину. Ввод/вывод стоят рядом от 640 px,
а на узком экране — друг под другом. Поддерживаются `dark` и `paper`.
