# QLC / Foundations

Визуальный источник — утверждённая Synthetic homepage. Большие серые панели, generic SaaS, glassmorphism, персонажи и оружие исключены. Спокойные поверхности учебного интерфейса: почти чёрные; насыщенная графика остаётся в art-slots и свободных полях.

## Палитра и контраст

| Роль | Значение | Применение |
|---|---|---|
| Canvas | #0A0A0A | Основной фон |
| Surface / Raised | #101210 / #171A16 | Небольшое различие вложенности |
| Paper | #F5F5EF | Основной текст |
| Secondary | #A6A6A0 | Пояснения и metadata |
| Lime | #C4FF00 | Primary CTA, подтверждённый прогресс |
| Cobalt | #4433EE | Selected fill, локальная графика |
| Control border | #66705D | Видимая граница input и track |
| Subtle line | #32372E | Разделители, не единственная граница control |
| Error / Warning / Info | #FF8074 / #E9D774 / #B3ACFF | Локальные семантические сигналы вместе с текстом и иконкой |

Lime background использует **ink text** (16.64:1), cobalt background — **paper text** (6.50:1). Paper на lime и ink на cobalt запрещены. Cobalt на dark не используется как самостоятельный контур важного control. У focus белая рамка2px с отступом; disabled не является единственным объяснением недоступности действия.

## Размеры и шрифты

Inter — основной UI. IBM Plex Mono — код и технические микроподписи. Body16/24; secondary14/22; card22/28; section28/36; page40/48 desktop и30/36mobile. Display64/68 предназначен только для отдельных публичных композиций; новую огромную типографику на всех страницах не вводить. Полные12стилей — в JSON.

Spacing:0,2,4,8,12,16,20,24,32,40,48,64,80,96. Радиусы:0 для графики,2для controls,4для отдельных контейнеров. Нет крупных скруглённых SaaS-плашек. Иконки24,32,48; интерактивная область не менее44px. ButtonS44/M48/L56. Текст переносится, контейнер растёт — шрифт не уменьшается ради вмещения.

Layouts: [layouts.md](layouts.md). Макеты1440и360; промежуточные768/390 проверяются при импорте/вёрстке. Автоматическое растяжение SVG не заменяет Auto Layout.

## Прогресс и motion

`value` — конечное число0…100, дробная часть влияет на геометрию. Отрицательные и слишком большие значения clamp; неизвестное значение — unavailable/indeterminate, не фиктивный0. Label округляется отдельно. Linear width=`trackWidth*value/100`. Circular использует непрерывную дугу; локальный SVG экспортирован явным arc, чтобы не зависеть от особенностей dash-import.

Переход значения240ms ease-out. При новом значении переход перенаправляется с текущего положения. Reduced motion — мгновенное обновление с сохранением результата и focus. XP reward может появляться480ms, не задерживая переход дальше. Нет постоянного мигания, анимации основного текста или глитча в редакторе.

Это контракт будущей TS-реализации. Статические SVG не содержат работающей логики progress или начисления XP.

## Variables

`data/design-tokens.json` содержит55токенов с типом, scopes и WEB syntax. Существующие пять Figma-цветов переиспользовать, семантические роли оформить aliases. Не назначать `ALL_SCOPES`; не привязывать декоративный cobalt к body text. Проверять типографику после импорта, поскольку локальные превью могли отрисоваться fallback-шрифтами.
