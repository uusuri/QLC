# QLC Design Kit → приложение

Источник: `QLC-Design-Kit/spec`, оригинальные SVG-экспорты и `synthetic-art.png`.
Исходный комплект сохранён без изменений. Компоненты для будущих функций не выдаются за действующие возможности продукта.

## Покрытие

| Экран | Реализация |
| --- | --- |
| Главная | Композиция desktop/mobile, оригинальная графика, курсы, метод, регистрация |
| Каталог `/courses` | Поиск, фильтры по действительным доступам, карточки с оригинальными обложками |
| Курс `/courses/[slug]` | Обложка, цена/доступ, раскрываемые модули, уроки и содержание задач |
| Урок `/lessons/[id]` | Тёмная типографическая поверхность, навигация по модулю, материал и практика |
| Задача | Monaco, черновик, подтверждение сброса, отправка и результат; на узких экранах три представления без размонтирования редактора |
| Профиль | Действительные курсы и решённые задачи; дробное заполнение прогресса, округление только подписи |
| Корзина | Состав заказа, итог, явно обозначенное тестовое открытие доступа |
| Вход и регистрация | Единые поля, кнопки, ошибки валидации, показ пароля; безопасный возврат после входа |
| Управление контентом | Общая палитра, типографика, поля, карточки и состояния всех этапов редактора |
| Системные состояния | Загрузка, пустые данные, ошибки, отсутствие доступа, 404 и общая ошибка страницы |

## Правила переноса

- Canvas `#0A0A0A`, surface `#101210`, paper `#F5F5EF`, lime `#C4FF00`, cobalt `#4433EE`.
- Локальные Inter и IBM Plex Mono; лицензии лежат в `public/fonts`.
- Иллюстрации курсов выбираются по теме; неизвестной теме соответствует обложка Computer Science.
- Графика метода извлечена без изменения контуров из `desktop-method.svg`.
- Прогресс считается по задачам: пустой знаменатель — недоступный прогресс, не фиктивные 0%.
- XP, достижения, уровни, таймеры, промокоды и будущие типы заданий не симулируются. Их исходники остаются в комплекте.
- Существующий backend пока выполняет тестовую покупку; интерфейс не изображает работающий платёжный провайдер.

## Проверка

Проверяются сборка, TypeScript, отсутствие переполнения и ошибок браузера на 360/768/1440 px. Защищённые состояния проверяются в отдельном браузере на перехваченных тестовых ответах — это проверка интерфейса, не реального платежа или judge.

Регрессионный сценарий `tests/design-kit-qa.cjs` требует Playwright и запущенного локального production preview (по умолчанию `http://127.0.0.1:3100`). `QLC_PLAYWRIGHT_MODULE`, `QLC_QA_URL` и `QLC_QA_OUTPUT` позволяют указать установку инструмента, адрес и папку отчёта. Публичный каталог читается из локального backend; checkout-fixture использует существующий курс с ID 1. Все клиентские API-запросы авторизованной тестовой сессии перехватываются, реальные изменения данных не выполняются.
