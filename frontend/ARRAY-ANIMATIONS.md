# Анимации массивов

В редакторе теории нажмите **«Массив»**. Задайте значения, выделения и указатели
первого шага, затем добавляйте шаги-копии. На каждом шаге можно изменить значения
ячеек, описание, выделения, указатели, диапазон и пару для обмена.

Кнопка **«Начать с другого массива»** заменяет все шаги после подтверждения.
При редактировании шагов длина массива остаётся постоянной. Поддерживается и
пустой массив `[]`.

**«Проверить воспроизведение»** открывает тот же проигрыватель, который видит ученик.
Есть переход назад и вперёд, выбор шага, пауза и скорость. Автозапуска нет;
при скрытии вкладки или выходе блока за пределы экрана воспроизведение
останавливается. Анимация не использует плавное движение ячеек; изменение системной
настройки уменьшения движения также останавливает проигрыватель.

После **«Вставить в теорию»** сохраните урок. Кнопка **«Изменить массив N»** вновь
открывает существующий блок. Изменяется только выбранная языковая версия;
соседний Markdown сохраняется. Пока открыт редактор массива, нельзя менять язык
и текст теории. Если данные всё же изменились извне, вставка отменяется с ошибкой.

## Формат qlc-array, версия 1

Это JSON с полными снимками, а не выполняемый код. Каждый шаг содержит все значения
массива. Возврат на предыдущий шаг не зависит от уже выполненных переходов.

````text
```qlc-array
{
  "version": 1,
  "title": "Обмен соседних элементов",
  "steps": [
    {
      "values": [3, 1, 2],
      "caption": "Сравниваем элементы с индексами 0 и 1. Отмечаем обмен.",
      "highlights": [0, 1],
      "pointers": [{"label": "i", "index": 0}, {"label": "j", "index": 1}],
      "range": {"from": 0, "to": 3},
      "swap": [0, 1]
    },
    {
      "values": [1, 3, 2],
      "caption": "Значения поменялись местами. Сравниваем следующую пару.",
      "highlights": [1, 2],
      "pointers": [{"label": "i", "index": 1}, {"label": "j", "index": 2}],
      "range": {"from": 1, "to": 3}
    }
  ]
}
```
````

- `values`: до 40 чисел в безопасном диапазоне JavaScript или строк до 32 символов.
  Число ячеек одинаково во всех шагах. Длинное значение можно прочитать во
  всплывающей подсказке; оно также полностью доступно экранному диктору.
- `highlights`: выделенные индексы от `0` до `n − 1`, без повторов.
- `pointers`: до 8 указателей. Названия произвольные, непустые и уникальные в шаге,
  до 20 символов; индекс от `−1` до `n`. Границы `−1` и `n` отображаются отдельно,
  но не являются ячейками массива.
- `range`: необязательный **полуинтервал `[from, to)`**. `from` входит, `to` не
  входит; `0 ≤ from ≤ to ≤ n`. Одинаковые границы обозначают пустой диапазон.
- `swap`: необязательная пара разных индексов реальных ячеек. Это только отметка
  обмена: изменённые значения нужно записать в следующем снимке самостоятельно.
- `caption`: до 1000 символов обычного текста; `title`: до 160.
- В блоке от 1 до 120 шагов; JSON не больше 250 000 символов.

`highlights`, `pointers` и `caption` можно не указывать: используются пустые
списки и пустая подпись. `range` и `swap` в таком случае отсутствуют. HTML и
JavaScript в строках никогда не исполняются. Для генерации Markdown используйте
`arrayFence`: она также экранирует обратные кавычки внутри JSON, чтобы подпись не
могла преждевременно закрыть блок. Графовые блоки `qlc-graph` не меняются.

## Проверки

```sh
cd frontend
node --test tests/arrayAnimation.test.cjs tests/graphAnimation.test.cjs tests/SafeMarkdown.test.cjs
npx tsc --noEmit --incremental false
```

Автотесты проверяют контракт, ограничения, граничные указатели и пустой диапазон,
самостоятельность снимков, безопасный рендеринг, вставку и повторное редактирование
с сохранением соседнего текста. Они не заменяют браузерную проверку кликов,
скрытия вкладки и адаптивной компоновки.
